OpenAI 모델을 내 컴퓨터에서 무료로: Ollama 설치 가이드

Ollama 설치부터 gpt-oss 첫 질문까지

Ollama는 오픈 AI 모델을 내 컴퓨터에서 돌려 주는 무료 프로그램이에요. OpenAI가 공개한 gpt-oss도 내려받아 쓸 수 있어요. 이름 끝이 :cloud인 모델은 내 컴퓨터가 아니라 서버에서 돌아가요.

Claude Code에 바로 붙여 넣기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요(무료 플랜 미포함, 공식 문서 2026-11-06 확인). 무료 플랜이면 이 부분은 건너뛰고 아래 순서대로 따라 하세요.
  • 여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 작업할 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.
  • Claude Code 설치: Windows PowerShell irm https://claude.ai/install.ps1 | iex · Mac curl -fsSL https://claude.ai/install.sh | bash
  • 데스크톱 앱: Windows / Mac
Claude Code에 붙여 넣기복사해서 붙여 넣기
내 컴퓨터에 Ollama를 설치하고 첫 모델까지 실행해 줘. 한 단계씩 하고, 각 단계 결과를 나에게 보여 줘.
1. 먼저 내 운영체제와 메모리(RAM) 크기를 확인해 줘.
2. 공식 설치 명령으로 Ollama를 설치해 줘.
   - Windows: irm https://ollama.com/install.ps1 | iex
   - macOS/Linux: curl -fsSL https://ollama.com/install.sh | sh
3. ollama --version 으로 설치를 확인해 줘.
4. 메모리가 16GB 이상이면 gpt-oss:20b(약 14GB), 그보다 적으면 gemma3:4b(약 3.4GB)를 추천하고, 내려받기 전에 나에게 물어봐 줘.
5. 이름 끝에 :cloud가 붙은 모델은 내 컴퓨터가 아니라 서버에서 도니까 고르지 마.
6. 모델을 받은 뒤 짧은 테스트 질문 하나로 동작을 확인하고, 다음에 내가 직접 쓰는 명령을 알려 줘.

AI에게 바로 맡기기

ChatGPT · Claude · Grok 어디든 붙여 넣으세요.

채팅 AI에 붙여 넣기 ([ ] 채우기)복사해서 붙여 넣기
내 컴퓨터에 Ollama를 설치하고, 내 사양에 맞는 AI 모델을 고르는 걸 처음부터 도와줘.
- 운영체제: [Windows 11 / macOS / Linux]
- 메모리(RAM): [8GB / 16GB / 32GB]
- 그래픽카드: [모름 / 내장 그래픽 / NVIDIA 이름]
하고 싶은 일: [회의록 요약 / 영어 메일 번역 / 공부 질문]

규칙:
1. 공식 사이트 ollama.com/download 기준으로, 내 운영체제에서 누를 버튼을 한 단계씩 알려 줘.
2. 내 메모리에 맞는 모델을 2개만 추천하고, 각각 내려받는 용량과 이유를 알려 줘.
   (참고: gpt-oss:20b는 약 14GB, 메모리 16GB부터. gemma3:4b는 약 3.4GB. gemma3:1b는 약 806MB)
3. 설치가 끝났는지 확인하는 방법과 정상일 때 보이는 화면을 알려 줘.
4. 이름 끝에 :cloud가 붙은 모델은 유료라서 추천하지 마.
5. 내가 오류 메시지를 붙여 넣으면 원인과 해결 순서를 짧게 알려 줘.
이 채팅 AI들이 내 컴퓨터에 직접 설치해 주지는 못해요. 단계를 알려 주는 도우미로 쓰세요.
STEP 02 · 먼저 이것만
2

이게 뭐예요?

  • 무엇: Ollama는 오픈 AI 모델을 내 컴퓨터에서 돌려 주는 무료 프로그램이에요 (GitHub 별 185,959개, MIT 라이선스, 2026-11-05 기준).
  • 할 수 있는 것: macOS·Windows 앱에서 모델을 내려받아 채팅하고, PDF나 텍스트 파일을 끌어다 놓고 질문할 수 있어요 (공식 블로그 2025-07-30).
  • OpenAI 모델: gpt-oss는 OpenAI가 공개한 모델이에요. 20b는 약 14GB이고 메모리 16GB부터 돌아가요. Apache 2.0 라이선스예요.
  • 비용: 내 컴퓨터에서 돌리는 로컬 모델은 무료예요. 이름 끝이 :cloud인 모델은 Ollama 서버에서 돌아가고 크레딧이나 유료 플랜이 필요해요.
  • 속도: 컴퓨터 사양에 따라 달라요. 큰 모델은 강한 그래픽카드가 없으면 느려요.
STEP 03 · 주의
3

꼭 알아 둘 점

  • 이름 끝에 :cloud가 붙은 모델은 내 컴퓨터가 아니라 Ollama 서버에서 돌아가요. 파일 내용이 서버로 가고, 크레딧이나 유료 플랜이 필요해요. 회사 문서처럼 밖으로 나가면 안 되는 파일은 :cloud가 없는 로컬 모델로만 쓰세요.
  • 속도는 내 컴퓨터 사양에 달려 있어요. 그래픽카드가 약하면 큰 모델은 느려요. 느리면 한 단계 작은 모델로 바꿔요.
  • 메모리가 모자라면 안 돌아가요. gpt-oss:20b는 메모리 16GB부터 돌아가요. 그보다 적으면 gemma3를 쓰세요.
  • 디스크 공간이 필요해요. gpt-oss:20b는 내려받는 데만 약 14GB예요.
  • 회사 문서는 회사 보안 규정을 먼저 확인하세요.

STEP 05 · 처음 하는 사람용
5

따라 하기

내 메모리 확인하기

  • Windows 11: 시작 → 설정 → 시스템 → 정보 → '설치된 RAM' 숫자를 봐요.
  • Mac: 화면 왼쪽 위 사과 메뉴 → '이 Mac에 관하여' → '메모리' 숫자를 봐요.

모델 고르기 (내 PC에 맞는 모델)

  • 메모리 16GB 이상: gpt-oss:20b (OpenAI 공개 모델) · 내려받는 용량 약 14GB
  • 메모리 8GB 정도: gemma3:4b (글·이미지 입력) · 약 3.4GB
  • 그보다 적거나 처음 테스트: gemma3:1b · 약 806MB
용량은 Ollama 라이브러리 표시값이에요. 실제로 필요한 메모리는 사용하는 길이(컨텍스트)에 따라 늘어날 수 있어요.

설치

  1. https://ollama.com/download 를 열어요.
  2. 내 운영체제를 골라 내려받아요. Windows는 설치 파일을 실행하고, Mac은 앱을 '응용 프로그램' 폴더로 옮겨요.
  3. Ollama 앱을 열어요.
  4. 이렇게 보이면 성공: 채팅창이 보이면 정상이에요.

명령어가 편하다면 공식 설치 명령도 있어요.

  • macOS·Linux 터미널: curl -fsSL https://ollama.com/install.sh | sh
  • Windows PowerShell: irm https://ollama.com/install.ps1 | iex

모델 받고 첫 질문

  • 앱: 채팅창의 모델 선택에서 위 '모델 고르기'의 모델을 골라요. 처음 쓰는 모델은 내려받기가 먼저 진행돼요. (화면 구성은 앱 버전에 따라 다를 수 있어요)
  • 터미널: ollama run gemma3:4b 처럼 입력하면 내려받은 뒤 바로 대화가 시작돼요.

파일 넣고 물어보기

앱 채팅창에 PDF나 텍스트 파일을 끌어다 놓고 아래 '바로 쓰는 질문 10개'처럼 물어봐요. 긴 문서는 설정에서 컨텍스트 길이를 늘릴 수 있지만 메모리를 더 써요.

STEP 06 · 복사해서 쓰기
6

바로 쓰는 질문 10개

  1. 이 문서 핵심만 3줄로 정리해 줘.
  2. 이 회의록에서 결정된 일, 담당자, 마감일만 표로 뽑아 줘.
  3. 이 메일을 정중한 영어로 바꿔 줘. 원래 뜻은 바꾸지 마.
  4. 이 계약서에서 내가 꼭 확인해야 할 조항 5개를 알려 줘. 법률 조언이 아니라는 점도 같이 적어 줘.
  5. 이 글을 초등학생도 이해하게 쉽게 다시 써 줘.
  6. 이 자료로 퀴즈 5문제를 만들고 정답은 맨 아래에 따로 적어 줘.
  7. 이 보고서의 숫자들이 서로 맞는지 확인하고, 이상한 곳을 알려 줘.
  8. 이 내용을 발표용 슬라이드 제목 6개로 나눠 줘.
  9. 이 문장에서 맞춤법과 띄어쓰기만 고쳐 줘.
  10. 이 문서를 읽고 내가 다음에 물어봐야 할 질문 5개를 추천해 줘.
작은 모델은 긴 문서나 복잡한 계산에서 틀릴 수 있어요. 중요한 내용은 원문과 꼭 대조하세요.
STEP 07 · 막히면
7

안 될 때

  • 답이 아주 느림 · 먼저 확인: 모델 크기와 내 메모리 → 한 단계 작은 모델로 바꿔요 (gemma3:4b → gemma3:1b)
  • 내려받기가 멈춤 · 먼저 확인: 디스크 여유 공간, 인터넷 연결 → 공간을 비우고 다시 시도해요
  • 모델 이름 오류 · 먼저 확인: 철자 (gpt-oss:20b) → https://ollama.com/library 에서 정확한 이름을 복사해요
  • 유료 안내가 뜸 · 먼저 확인: 모델 이름 끝이 :cloud인지 → 로컬 모델(이름에 :cloud 없음)을 골라요
