공고를 붙여 넣으면 점수와 맞춤 이력서 초안까지

career-ops는 채용 공고가 아직 열려 있는지 확인하고, 내 이력서 기준으로 적합도 점수(5점 만점)를 매겨요. 맞춤 이력서 PDF와 자기소개·답변 초안도 써 줘요. 제출은 내가 직접 눌러요.

무료 MIT · 지원자 평생 무료5점 적합도 점수제출 내가 직접
2026년 11월 9일 확인·Node.js + Claude Code(Pro 이상) 등 AI 도구·career-ops 무료(MIT)

STEP 00 먼저 이것만
0

이게 뭐예요?

  • 해 주는 것: 공고가 아직 열려 있는지 확인 → 내 이력서 기준 적합도 점수(5점 만점) → 맞춤 이력서 PDF와 자기소개·답변 초안.
  • 안 하는 것: 자동 지원, 이메일 발송. 초안만 쓰고 제출은 내가 눌러요(README).
  • 4.0점 미만 공고는 지원하지 말라고 말려요. 그래도 원하면 진행할 수 있어요.
  • 가격: 무료(MIT, GitHub 별 8.1만, 11/9). 지원자에게는 평생 무료라고 써 있어요. Claude Code는 유료 플랜이 필요해요. 무료·로컬 모델로 쓰는 안내 문서도 있어요.
README 기준으로 썼고 직접 돌려 보지는 않았어요.
STEP 01 PowerShell·터미널
1

설치

PowerShell·터미널에 넣기
npx @santifer/career-ops init
cd career-ops
claude
  • Node.js가 있어야 해요(npx가 같이 깔려요).
  • 마지막 줄은 Claude Code예요. README는 codex, opencode, qwen 같은 다른 AI 도구도 된다고 써요.
  • 처음 켜면 채팅으로 내 이력서, 원하는 일, 싫은 조건을 물어봐요. 설정 파일을 직접 고칠 필요는 없어요.
STEP 02 공고 넣기
2

공고 넣는 법

  • 채용 공고 링크나 공고 글을 그대로 붙여 넣어요(README).
  • 한국 채용 사이트 공고는 글을 복사해서 붙여 넣는 게 안전해요(추정).
  • 결과를 한국어로 받고 싶으면 처음에 이렇게 말해요.
처음에 붙여 넣기
앞으로 평가 결과, 이력서, 자기소개, 답변 초안을 모두 한국어로 써 줘. 내 이력서에 없는 경력이나 숫자는 절대 지어내지 마.
STEP 03 주의
3

꼭 알아 둘 점

  • career-ops는 Anthropic이 아닌 곳(career-ops-hq)에서 공개한 프로그램이에요. 깔면 내 컴퓨터에서 실행돼요. 설치 명령의 이름(@santifer/career-ops)이 이 가이드와 같은지 확인하고, 다른 중요한 파일이 없는 새 폴더에 깔아요.
  • AI가 쓴 이력서는 꼭 직접 읽어요. README도 모든 바꿔 쓴 문장을 다 검사하지는 못한다고 써요.
  • 기록은 내 컴퓨터에 남고, 이력서 내용은 내가 고른 AI 회사로만 가요(README). 주민번호·집 주소 같은 건 넣지 마세요.
  • PDF가 안 만들어지면: 직접 설치(git clone)했다면 npx playwright install chromium을 실행해요.
