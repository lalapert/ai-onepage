클로드가 내 말투로 쓰게: 글 세 개로 말투 스킬 만들기

내가 쓴 글 세 개 → 말투 규칙 파일(SKILL.md) → 압축해서 올리기. 무료 요금제도 돼요

클로드한테 가게 글을 맡기면 어느 가게나 같은 광고 문구처럼 나와요. 내가 쓴 글 세 개를 주고 그 말투를 스킬로 만들어 두면, 다음부터는 말투를 설명하지 않아도 그 말투로 써요. 11월 26일에 같은 부탁을 스킬 없이, 스킬 넣고 한 번씩 해 보니 8줄·해시태그 3개짜리 글이 세 문장이 됐어요.

글 3개 말투 규칙 13개무료 요금제 스킬 올리기 됨11/26 스킬 전후 직접 돌림
2026년 11월 26일 확인 · Claude 계정(Free 포함) · Create and edit files(코드 실행) 켜기 · 내가 쓴 글 3개 · Claude 스킬(Customize > Skills) · SKILL.md 한 파일 · zip으로 올림

STEP 00 · 먼저 이것만
0

스킬이 뭐예요?

스킬은 클로드가 일할 때 꺼내 보는 설명서 파일이에요. SKILL.md 한 파일이면 돼요. 맨 위에 이름(name)과 언제 쓰는지(description)를 적고, 그 아래에 규칙을 적어요.

  • description: 클로드가 이걸 보고 '지금 이 스킬을 꺼낼까'를 정해요. 200자까지
  • 본문: 말투 규칙과 내 원래 글을 넣어요. 스킬이 켜지면 클로드가 이 내용을 읽고 써요
  • 한 번 올려 두면 대화마다 말투를 다시 설명하지 않아도 돼요
핵심스킬은 Free·Pro·Max 모두 올릴 수 있어요. 다만 Create and edit files(코드 실행)가 켜져 있어야 스킬 메뉴가 보여요(11/26 도움말 확인).
STEP 01 · 1단계
1

내 글 세 개로 스킬 만들기

  1. 내가 직접 쓴 글 중에서 말투가 잘 드러난 글 세 개를 골라요. 짧아도 돼요(우리 예시는 70~112자).
  2. 클로드 앱에서 새 대화를 열고, 아래 부탁에 글 세 개를 붙여 넣어 보내요.
클로드에: 말투 스킬 만들기복사해서 붙여 넣기
아래 글 세 개가 내 말투야. 앞으로 클로드가 [우리 가게] 글을 쓸 때 이 말투로 쓰게 하는 스킬을 만들어 줘.
- 규칙은 세 글에 실제로 있는 것만 적고, 원문 세 편도 넣어 줘.
- 폴더 이름과 name은 영어 소문자와 하이픈으로 똑같이(예: my-shop-voice).
- description은 200자 안으로, '내 말투로'라는 말이 없어도 가게 글이면 쓰도록.
- 숫자·시각·개수는 내가 준 것만 쓰고, 모르면 묻도록.
- 마지막에 폴더째 zip으로 묶어서 줘.

[글 3]
  1. 클로드가 만든 SKILL.md를 한 번 읽어 봐요. 내 글에 없는 습관(이모지, 인사말 등)이 규칙에 들어갔으면 빼 달라고 해요.
  2. 이렇게 보이면 성공: my-shop-voice.zip처럼 압축 파일을 내려받았고, 그 안에 폴더 하나와 SKILL.md가 들어 있으면 성공이에요.
핵심앱에서 zip까지 만들어 주지 않으면, SKILL.md 내용을 메모장에 붙여 넣어 같은 이름의 폴더에 저장한 뒤 그 폴더를 압축하면 돼요.
STEP 02 · 2단계
2

압축 파일 올리기

  1. Settings > Capabilities에서 Code execution and file creation(새 화면 이름은 Create and edit files)을 켜요.
  2. 왼쪽 Customize > Skills로 가요.
  3. + 버튼 → Create skill → Upload a skill을 눌러 zip 파일을 올려요.
  4. 목록에 생긴 스킬이 켜져 있는지(토글) 봐요.
  5. 이렇게 보이면 성공: Customize > Skills 목록에 my-shop-voice가 보이고 토글이 켜져 있으면 성공이에요.
핵심업로드가 안 되면 넷 중 하나예요: zip이 너무 큼, 폴더 이름과 name이 다름, SKILL.md가 없음, 이름·설명에 못 쓰는 글자. zip 안에는 파일만 넣지 말고 폴더째 넣어요.
STEP 03 · 3단계
3

시험하고 고치기

스킬 이름을 말하지 말고 평소처럼 부탁해 봐요.

클로드에: 시험복사해서 붙여 넣기
우리 가게 인스타 글 써 줘. [이번 주 소식 한 줄].
  1. 말투가 안 바뀌었으면 "my-shop-voice 스킬로 써 줘"처럼 이름을 넣어 다시 부탁해요.
  2. 규칙을 바꾸고 싶으면 아래처럼 부탁하고, 새 zip을 다시 올려요.
클로드에: 규칙 고치기복사해서 붙여 넣기
my-shop-voice 스킬에 [해시태그는 두 개까지 붙여도 된다]는 규칙을 넣어 줘.
다른 규칙은 그대로 두고, 폴더째 zip으로 다시 묶어 줘.
STEP 04 · 11월 26일에 해 본 것
4

실제 결과

영상용으로 쓴 동네 빵집 예시 글 세 개를 주고 클로드에게 스킬을 만들게 했어요. 규칙 13개가 든 SKILL.md 한 파일이 나왔고, 압축하니 3.5KB였어요. 그다음 같은 부탁("우리 가게 인스타 글 써 줘. 이번 주 토요일에 밤 식빵 새로 나와. 하루 스무 개만 구워.")을 새 대화 두 개에 한 번씩 했어요.

  • 스킬 없이: 8줄, 해시태그 3개. 부탁에 없던 빵 설명("식빵 사이사이에 밤이 콕콕 박혀 있어요.", "결대로 쭉 찢어 드셔 보세요.")이 들어갔어요
  • 스킬 넣고: "이번 주 토요일에 밤 식빵이 새로 나와요. 하루 스무 개만 굽습니다. 다 나가면 그날은 끝이에요." 세 문장, 부탁에 있던 사실만
  • 부탁에 스킬 이름을 넣지 않았는데, 클로드가 스스로 my-shop-voice를 꺼내 썼어요(답 끝에 사용한 스킬을 적게 해서 확인)
핵심이 시험은 클로드 코드(같은 스킬 형식)에서 했어요. 앱(특히 무료 요금제)은 쓰는 모델이 달라 글이 조금 다르게 나올 수 있어요.
STEP 05 · 주의
5

꼭 알아 둘 점

  • 내가 직접 쓴 글로 만들어요. 다른 사람 글이나 다른 가게 글을 흉내 내는 스킬은 만들지 않아요.
  • 스킬 파일에 전화번호·주소·계좌 같은 개인정보나 비밀번호를 넣지 않아요.
  • 올린 스킬은 내 계정에만 있어요(Team·Enterprise는 공유 기능 따로).
  • 말투가 바뀌어도 가격·시간·개수는 꼭 직접 확인하고 올려요. 스킬에 '모르는 숫자는 묻기'를 넣어 두면 지어내는 일이 줄어요.
  • 남이 만든 스킬을 받을 때는 안에 든 파일을 먼저 읽어 보고 켜요(Claude 도움말 권고).
  • 영상 속 두 글은 11/26 클로드 코드에서 같은 부탁으로 실제로 받은 답이고, 예시 가게 글 세 개는 영상용으로 쓴 글이에요.
