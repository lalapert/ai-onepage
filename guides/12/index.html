내 가게 홈페이지가 링크로

채팅으로 가게 페이지를 만들고 Publish로 공개 링크 받기

STEP 00 제일 먼저
0

클로드 채팅에 바로 붙여 넣기

설치할 것은 없어요. claude.ai(웹)나 Claude 데스크톱 앱에서 새 채팅을 열고 아래 문장을 붙여 넣으세요. [ ] 칸만 내 가게 정보로 바꾸면 돼요.

클로드 새 채팅에 붙여 넣기 ([ ] 채우기)
우리 가게 홈페이지를 한 페이지짜리 웹페이지(아티팩트)로 만들어 줘.
- 가게 이름: [ ]
- 한 줄 소개: [ ]
- 메뉴와 가격: [메뉴1 0,000원 / 메뉴2 0,000원 ...]
- 영업시간과 쉬는 날: [ ]
- 주소: [ ]
- 가게 전화번호: [ ]
- 지도 링크(네이버 지도·카카오맵에서 '공유'로 복사): [ ]
- 예약·주문 링크(있으면): [ ]
- 원하는 분위기와 색: [예: 따뜻한 베이지, 깔끔하게]
조건:
1. 휴대폰 화면에서 먼저 보기 좋게 만들어 줘.
2. 맨 위에 가게 이름과 '전화하기' 버튼을 두고, 누르면 바로 전화가 걸리게 해 줘.
3. 내가 준 정보만 써. 가격, 후기, 수상 경력처럼 내가 안 준 정보는 지어내지 마. 빈칸은 [확인 필요]로 남겨 줘.
4. 사진은 넣지 말고 사진 자리만 표시해 줘.
5. 다 만들면 손님 입장에서 고칠 점 3가지를 짧게 말해 줘.
STEP 01 먼저 이것만
1

이게 뭐예요?

  • 무엇: 채팅 한 번으로 메뉴, 영업시간, 전화 버튼이 있는 한 페이지짜리 가게 소개 페이지를 만들고, 공개 링크로 손님에게 보내요.
  • 누구에게: 홈페이지가 없는 작은 가게, 1인 사업자, 프리랜서 소개 페이지가 필요한 사람.
  • 플랜:
    · 무료 플랜도 돼요. 채팅에서 만든 페이지는 'Publish' 버튼으로 공개 링크를 만들 수 있어요(Free·Pro·Max).
    · Team·Enterprise 플랜은 'Share & copy link' 방식이라 조직 설정에 따라 달라요.
  • 링크를 받은 손님: Claude 계정 없이 열어 보고 쓸 수 있어요(도움말 기준).
  • 안 되는 것:
    · 내 도메인 주소(가게이름.com)는 안 돼요. 링크는 claude.ai 주소예요.
    · 네이버·구글 검색에 내 가게 홈페이지로 등록하는 일과는 달라요.
    · 결제나 예약 시스템을 페이지 안에 직접 넣는 것은 이 가이드 범위 밖이에요.
STEP 02 주의
2

꼭 알아 둘 점

  • 'Unpublish'(공개 취소)를 누르면 같은 페이지는 다시 공개할 수 없어요.
    · 다시 공유하려면 새로 만들어야 해요.
    · 페이지에 저장된 데이터도 함께 지워져요(도움말).
  • 버튼이 'Publish'가 아니라 'Share'로 보이면 무료 플랜에서는 공개 링크가 안 될 수 있어요.
    · 도움말 기준으로 'Share' 방식에서 '링크가 있는 누구나'는 Pro 이상이에요.
    · Pro 이상에서 'Share → 링크가 있는 누구나'로 공유하면 대부분 계정 없이 열려요(도움말 11/5 갱신, 11/9 확인).
    · 채팅 안에서 만든 페이지인지 확인하세요.
  • 공개 링크는 누구나 볼 수 있어요. 가게 번호만 넣고, 개인 휴대폰 번호나 집 주소는 넣지 마세요.
  • AI가 없는 정보를 지어낼 수 있어요. 가격, 영업시간, 주소는 링크를 보내기 전에 한 번 더 확인하세요.
  • 페이지를 고친 뒤에는 이미 보낸 링크를 다시 열어 바뀐 내용이 보이는지 확인하세요. 고친 내용이 이미 보낸 링크에 그대로 반영되는지는 직접 확인하지 않았어요.
  • 휴대폰 앱(iOS·Android)에서는 공유 설정을 바꿀 수 없어요(도움말). 공개 링크는 PC 웹이나 데스크톱 앱에서 만드세요.
  • 페이지 안에 Claude 기능(AI 답변 등)을 넣은 경우: 손님이 그 기능을 쓰려면 가입하라는 안내가 떠요. 가게 소개 페이지는 Claude 기능 없이 만드는 걸 권해요.

STEP 04 처음 하는 사람용
4

따라 하기

페이지 만들기

  1. PC에서 claude.ai를 열고 로그인해요(없으면 무료로 가입).
  2. 왼쪽 위 새 채팅을 눌러요.
  3. 맨 위 '클로드 채팅에 바로 붙여 넣기'의 문장을 붙여 넣고 [ ] 칸을 채운 뒤 보내요.
  4. 정상이면 채팅 오른쪽에 페이지 미리보기(아티팩트)가 열려요.
  5. 미리보기에서 전화 버튼, 메뉴, 영업시간이 맞는지 확인해요.

말로 고치기 · 같은 채팅에 이어서 쓰면 돼요. 예:

  • 전화하기 버튼을 더 크게, 화면 아래에 계속 붙어 있게 해 줘
  • 메뉴를 표 말고 카드 모양으로 바꿔 줘
  • 색을 더 따뜻하게, 글자는 더 크게
  • 영업시간을 오전 11시~오후 9시, 월요일 휴무로 고쳐 줘

공개 링크 만들기

  1. 미리보기(아티팩트)를 열어요.
  2. 오른쪽 위 Publish를 눌러요.
  3. 공개 링크를 복사해요.
  4. 내 휴대폰으로 링크를 열어서 전화 버튼이 눌리는지 확인해요.
  5. 공개하면 왼쪽 메뉴 Artifacts에 들어가서, 나중에 채팅 밖에서도 찾을 수 있어요.

링크 쓰는 곳

  • 인스타그램 프로필 링크 칸, 카카오톡 채널 소개, 문자 안내, 가게 앞 QR 코드
  • QR 코드는 링크를 넣으면 만들어 주는 무료 사이트가 많아요. 만든 뒤 휴대폰으로 찍어서 열리는지 꼭 확인하세요.

(선택) 다른 사이트에 넣기

  • Publish 뒤 Get embed code를 누르면 다른 웹사이트에 붙여 넣을 코드가 나와요.
  • Allowed domains 칸에는 이 페이지를 넣을 사이트 주소를 쉼표로 나눠 적어요(도움말).
STEP 05 막히면
5

안 될 때

  • 미리보기가 안 열림 · 먼저 확인: 채팅 답에 페이지 카드가 있는지 → 아티팩트로 다시 만들어 줘라고 쓰기
  • Publish 버튼이 없음 · 먼저 확인: 휴대폰 앱인지, 버튼이 'Share'인지 → PC 웹에서 열기 → 'Share'만 보이면 '꼭 알아 둘 점' 참고
  • 손님이 링크를 못 엶 · 먼저 확인: 'Unpublish'를 눌렀는지 → 공개를 취소했다면 새로 만들어 다시 Publish
  • 내용이 틀림 · 먼저 확인: 가격·시간을 내가 준 대로 썼는지 → 내가 준 정보만 써라고 다시 말하고 고칠 곳 짚기
  • 전화 버튼이 안 눌림 · 먼저 확인: 번호에 하이픈·공백이 섞였는지 → 전화 버튼을 tel: 링크로 다시 만들어 줘
오류 상담용 문장 ([ ] 채우기)
클로드로 만든 가게 페이지가 [증상]이야. 내 플랜은 [무료/Pro], 쓰는 곳은 [PC 웹/데스크톱 앱/휴대폰 앱]이야. 원인과 고치는 순서를 쉬운 말로 알려 줘.
