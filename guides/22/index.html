STEP 00 먼저 이것만
0

이게 뭐예요?

  • Claude Code에 깔아 쓰는 스킬 5개예요. 스킬은 "이 일은 이렇게 해" 하고 클로드에게 미리 써 준 설명서 파일이에요. 깔아 두면 클로드가 그 방식대로 일해요.
  • 다섯 개 모두 GitHub에서 별(좋아요 같은 것)을 10만 개 넘게 받았어요.
  • 다섯 개 모두 무료로 받을 수 있어요. 다만 Claude Code는 유료 플랜이 필요해요.
  • 한꺼번에 다 깔 필요는 없어요. 1절 '다섯 개 한눈에'를 보고 나한테 필요한 것만 골라요.
STEP 01 골라 보기
1

다섯 개 한눈에

  • superpowers (별 31.7만)
    클로드가 바로 코드부터 짜지 않고, 기획 → 계획서 → 테스트 먼저 → 작업 순서로 일해요.
    이런 사람한테: 클로드가 자꾸 엉뚱하게 만들어서 다시 시키는 사람
  • Anthropic 공식 skills (별 19.4만)
    워드(.docx), 엑셀(.xlsx), PPT(.pptx), PDF를 진짜 파일로 만들고 고쳐요.
    이런 사람한테: 보고서·표·발표 자료를 자주 만드는 사람
  • claude-mem (별 11.7만)
    어제 한 작업을 기억해요. 새로 켤 때마다 처음부터 설명하지 않아도 돼요.
    이런 사람한테: 같은 프로젝트를 며칠씩 이어서 하는 사람
  • taste-skill (별 11.4만)
    뻔한 AI 홈페이지 대신, 실제 사진과 한 가지 디자인 규칙으로 페이지를 만들어요.
    이런 사람한테: 홈페이지·랜딩 페이지를 만드는 사람
  • impeccable (별 10.9만)
    "더 과감하게", "더 조용하게"처럼 말로 디자인을 고치고, AI 티 나는 곳을 검사해요.
    이런 사람한테: 이미 만든 화면을 다듬고 싶은 사람
STEP 02 처음 한 번
2

Claude Code 열기

  1. claude.ai/download에서 내 컴퓨터(Windows 또는 Mac)에 맞는 앱을 받아요.
  2. 받은 파일을 열어 설치하고, 앱을 켜서 로그인해요.
  3. 앱 왼쪽 위에 있는 Code 탭을 눌러요.
  4. 폴더를 고르라는 창이 뜨면, 작업할 폴더를 골라요. 처음이면 바탕화면에 새 폴더를 하나 만들어서 골라요.
  5. 이렇게 보이면 성공: 화면 아래에 글을 쓰는 칸이 생겨요.

터미널(까만 창에 글자로 명령을 치는 프로그램)을 쓸 줄 안다면 이렇게 해도 돼요.

  • Windows: PowerShell을 열고 irm https://claude.ai/install.ps1 | iex를 붙여 넣은 뒤 Enter
  • Mac: 터미널을 열고 curl -fsSL https://claude.ai/install.sh | bash를 붙여 넣은 뒤 Enter
  • 다 깔리면 claude라고 치고 Enter
STEP 03 가장 쉬운 방법
3

클로드에게 설치 맡기기

  1. 아래 상자 안 글을 복사해서, 깔고 싶은 것만 남기고 나머지 줄은 지워요.
  2. Claude Code 글 쓰는 칸에 붙여 넣고 Enter를 눌러요.
  3. 클로드가 "이 명령을 실행해도 될까요?" 하고 물으면, 내용을 읽고 허락 버튼을 눌러요.
  4. 이렇게 보이면 성공: 클로드가 스킬마다 "설치 완료"라고 정리해 줘요.
  5. 끝나면 앱을 껐다가 다시 켜요. 새로 깐 스킬은 다시 켜야 잡혀요.
1번에서 복사하기 (필요한 줄만 남기기)
아래 Claude Code 스킬을 설치해 줘. 하나씩 설치하고, 지금 뭘 하는지 쉬운 말로 알려 줘.
내 컴퓨터에 새로 깔아야 하는 게 있거나, 결제·회원가입이 필요한 단계가 나오면 하기 전에 나한테 먼저 물어봐.
- superpowers: https://github.com/obra/superpowers
- Anthropic 문서 스킬(document-skills): https://github.com/anthropics/skills
- claude-mem: https://github.com/thedotmack/claude-mem
- taste-skill: https://github.com/Leonxlnx/taste-skill
- impeccable: https://github.com/pbakaus/impeccable
다 되면 각각 잘 깔렸는지 확인해 줘.
STEP 04 명령을 하나씩 칠 때
4

직접 설치하기

Claude Code 글 칸에 아래 명령을 한 줄씩 붙여 넣고 Enter를 눌러요.

superpowers
/plugin install superpowers@claude-plugins-official
  • not found라고 나오면, 만든 사람이 따로 운영하는 장터를 먼저 등록하고 다시 설치해요.
superpowers (not found가 나올 때)
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
Anthropic 문서 스킬
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
claude-mem
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
taste-skill
/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill@taste-skill
impeccable
/plugin marketplace add pbakaus/impeccable
  • impeccable은 위 줄을 친 다음, 글 칸에 /plugin만 쳐서 열리는 목록에서 Impeccable을 골라 설치해요.
  • 이렇게 보이면 성공: 글 칸에 /plugin을 쳤을 때 설치한 이름이 목록에 보여요.
STEP 05 써 보기
5

처음 써 보기

  • superpowers: "로그인 화면 만들어 줘"처럼 평소대로 시켜요. 클로드가 바로 만들지 않고 먼저 질문하고 계획서를 보여 줘요. 계획서를 보고 "좋아"라고 하면 그때 만들어요.
  • 문서 스킬: "이 표로 엑셀 파일 만들어 줘", "이 내용으로 PPT 5장 만들어 줘"처럼 시켜요. 폴더에 진짜 파일이 생겨요.
  • claude-mem: 따로 할 일이 없어요. 오늘 일하고 내일 다시 켜면, 어제 한 일이 자동으로 이어져요.
  • taste-skill: "우리 동네 빵집 홈페이지 만들어 줘"처럼 시켜요.
  • impeccable: 프로젝트마다 처음 한 번 /impeccable init을 쳐요. 그다음 /impeccable critique the hero처럼 고칠 곳 하나를 골라 시켜요.
STEP 06 주의
6

꼭 알아 둘 점

  • Claude Code는 유료 플랜(Pro 이상)이 필요해요. 스킬은 무료여도 Claude Code를 쓰려면 플랜이 있어야 해요.
  • claude-mem은 설치 중에 결제 수단을 묻는 체험이 나올 수 있어요. 'claude-mem observer' 30일 무료 체험이에요. 고르지 않고 내 Anthropic 플랜으로 쓰는 선택지를 골라도 돼요. 결제 화면이 나오면 멈추고 다시 읽어 보세요.
  • claude-mem은 사용 통계를 기본으로 보내요(익명). 끄려면 npx claude-mem telemetry disable을 쳐요.
  • taste-skill은 Node 22 이상과 크롬(또는 엣지) 브라우저가 필요해요. 없으면 3절처럼 클로드에게 확인을 맡기세요.
  • 스킬을 많이 깔수록 클로드가 읽을 것이 늘어요. 지금 필요한 것부터 1~2개만 깔고 써 보세요.
  • 별 수는 11월 13일 기준이에요. 계속 바뀌어요.
