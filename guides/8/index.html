0

Claude Code에 바로 붙여 넣기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요(무료 플랜 미포함, 공식 문서 2026-11-06 확인). 무료 플랜이면 이 부분은 건너뛰고 아래 순서대로 따라 하세요.
  • 여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 그림이 있는 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.
  • Claude Code 설치: Windows PowerShell irm https://claude.ai/install.ps1 | iex · Mac curl -fsSL https://claude.ai/install.sh | bash
  • 데스크톱 앱: Windows / Mac
Claude Code에 붙여 넣기
어도비 스톡(Adobe Stock)에 올릴 AI 그림을 준비하고 싶어. 한 단계씩 하고 결과를 보여 줘.
1. 이 폴더 안의 JPG·PNG 파일 크기(가로 × 세로)를 표로 보여 주고, 400만 화소(4MP)가 안 되는 파일을 표시해 줘.
2. PNG는 JPG로 바꿔야 해. 바꾸기 전에 나한테 먼저 물어보고, 원본은 지우지 마.
3. 그림을 하나씩 보고 짧고 정확한 영어 제목과 키워드 초안을 표로 만들어 줘. 작가 이름, 실존 인물, 브랜드, 캐릭터 이름은 넣지 마.
4. 그림 안에 글자, 서명, 워터마크가 있거나 손가락·얼굴이 어색한 그림이 있으면 따로 알려 줘.
5. 서로 아주 비슷한 그림이 4장 이상이면 알려 줘. 어도비는 비슷한 것을 3장까지만 올리라고 해.
STEP 01 아이디어와 프롬프트
1

AI에게 바로 맡기기

팔릴 만한 그림 아이디어와 프롬프트 만들기 (ChatGPT · Claude · Grok에 붙여 넣기)

채팅 AI에 붙여 넣기 ([ ] 채우기)
Adobe Stock에 올릴 AI 그림을 만들고 싶어. 아이디어와 프롬프트를 같이 짜 줘.
- 쓰는 그림 AI: [ChatGPT / Adobe Firefly / 기타]
- 관심 분야: [음식 / 사무실 / 자연 / 계절 행사 / 배경 텍스처]
- 원하는 장 수: [10장]

규칙:
1. 광고·블로그·발표 자료에 바로 쓸 수 있는 장면 위주로 골라 줘.
2. 프롬프트에 작가 이름, 'OO 화풍', 실존 인물, 유명 캐릭터, 브랜드, 로고, 글자를 넣지 마.
3. 그림마다 영어 제목 1개와 키워드 초안을 붙여 줘.
4. 만든 뒤 확인할 점(손가락·얼굴 오류, 이상한 조명, 그림 속 글자)을 체크리스트로 알려 줘.
5. 판매나 수익을 약속하는 말은 하지 마.
채팅 AI는 그림을 대신 올리거나 팔아 주지는 못해요. 아이디어와 점검을 도와주는 도우미로 쓰세요.
STEP 02 먼저 이것만
2

이게 뭐예요?

  • 무엇: Adobe Stock은 사진·일러스트·영상을 올려 두면 사람들이 사 가는 사이트예요. 생성형 AI로 만든 그림·벡터·영상도 받아요(공식 가이드, 2026-06-11 갱신).
  • 얼마: 팔릴 때마다 가격의 33%(사진·벡터·일러스트), 영상은 35%가 내 몫이에요(공식, 2026-10-27 갱신). 공식 예시: 월 29.99달러에 사진 10장인 플랜이면 한 장에 약 0.99달러예요.
  • 누가: 만 18세 이상, 쓰는 이메일과 전화번호, 정산 받을 계정이 있으면 가입할 수 있어요.
  • 정산: 쌓인 금액이 25달러가 넘고, 첫 판매 후 45일이 지나면 받을 수 있어요. 한국은 Payoneer로 받아요.
STEP 03 주의
3

꼭 알아 둘 점

  • 팔린다는 보장은 없어요. 올린 그림은 검수(심사)를 거치고, 거절될 수도 있어요.
  • 쓰는 그림 AI의 약관부터 확인하세요. 상업적 이용과 스톡 판매를 허용하는 툴이어야 해요. 어도비는 이걸 대신 확인해 주지 않아요.
  • 'Created using generative AI tools' 체크는 필수예요. 가상 인물이나 가상 장소가 나오면 'People and Property are fictional'도 켜요.
  • 남의 것은 금지예요. 프롬프트·제목·키워드에 작가 이름, 실존 인물, 유명 캐릭터, 브랜드를 쓰면 안 돼요. 어기면 그림이 지워지거나 계정이 정지될 수 있어요.
  • 그림 안에 글자, 서명, 워터마크가 있으면 안 돼요. 손가락·얼굴이 이상하거나 조명이 어색하면 거절 사유가 돼요.
  • 크기를 키울 때 화질이 나빠지면 안 돼요. 작은 그림을 억지로 늘리면 거절될 수 있어요.
  • 비슷한 그림은 3장까지만 올리세요. 너무 많이 올리면 스팸으로 봐요.
  • 세금 정보를 꼭 넣으세요. 세금 서류가 없으면 최대 30%까지 미리 떼고 줄 수 있어요(거주 국가에 따라 달라요).

STEP 05 처음 하는 사람용
5

따라 하기

  1. contributor.stock.adobe.com에 들어가요. Adobe 계정이 없으면 Join now, 있으면 Link my Adobe ID를 눌러요.
  2. 이메일과 전화번호를 인증해요.
  3. 위쪽 Contributor Account에서 이름, 주소, 정산 방법(한국은 Payoneer), 세금 정보를 넣고 Save changes를 눌러요.
  4. 올릴 그림을 준비해요. JPG, 4MP 이상, 글자·워터마크 없음, 손가락·얼굴 오류 없음.
  5. Upload에서 그림을 올려요.
  6. 그림마다 제목, 키워드, 카테고리를 넣어요. 메타데이터 칸에서 Created using generative AI tools를 켜요. 가상 인물·장소가 나오면 People and Property are fictional도 켜요.
  7. 제출(Submit)하고 검수 결과를 기다려요.
  8. 팔리면 대시보드에서 수익을 확인해요. 25달러가 넘고 첫 판매 후 45일이 지나면 정산을 요청해요.
버튼 이름과 위치는 바뀔 수 있어요. 화면에 보이는 이름을 따라가세요.
STEP 06 막히면
6

안 될 때

  • 검수에서 거절 · 먼저 확인: 글자·워터마크, 손가락·얼굴 오류, 화질 → 문제 있는 부분을 고치거나 다시 만들어서 올려요
  • 지식재산 문제로 거절 · 먼저 확인: 프롬프트·제목·키워드의 작가·인물·캐릭터·브랜드 이름 → 그런 이름을 빼고 다시 만들어요
  • 업로드가 안 됨 · 먼저 확인: 파일 형식 → 사진은 JPG로 바꿔서 올려요
  • 정산 요청이 안 됨 · 먼저 확인: 금액과 날짜 → 25달러 이상, 첫 판매 후 45일이 지났는지 확인해요
