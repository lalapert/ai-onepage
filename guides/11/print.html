Claude Code에 바로 붙여 넣기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요(무료 플랜 미포함, 공식 문서 2026-11-06 확인).
  • 여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 내 가게·서비스 작업 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.
  • Claude Code 설치: Windows PowerShell irm https://claude.ai/install.ps1 | iex · Mac curl -fsSL https://claude.ai/install.sh | bash
  • 데스크톱 앱: Windows / Mac
Claude Code에 붙여 넣기복사해서 붙여 넣기
마케팅 스킬 모음 marketingskills(github.com/coreyhaines31/marketingskills)를 이 폴더에 설치하고 첫 세팅까지 해 줘. 한 단계씩 하고, 명령을 실행하기 전에 무엇을 하는지 먼저 말해 줘.
1. node와 npx가 있는지 확인해 줘. 없으면 Node.js 설치 방법만 알려 주고 멈춰.
2. 아래 명령으로 설치해 줘. 끝의 -a claude-code를 빼면 Claude Code가 못 읽는 폴더에 깔릴 수 있어.
   npx skills add coreyhaines31/marketingskills -a claude-code
3. .claude/skills/ 폴더에 스킬이 들어갔는지 목록으로 보여 줘.
4. product-marketing 스킬로 내 제품 소개 문서를 같이 만들자. 질문을 하나씩 해 줘. 다른 스킬들이 이 문서를 먼저 읽어.
5. 광고 계정이나 분석 도구 연결은 지금 하지 마.
6. 실제 돈이 나가거나 공개로 올라가는 일(광고 집행, 게시, 메일 발송)은 하기 전에 나한테 먼저 물어봐.
STEP 01 · 설치 후 붙여 넣기
1

바로 쓰는 질문 10개

괄호 안은 그 질문에 쓰이는 스킬 이름이에요. 질문에 스킬 이름을 같이 적으면 더 잘 골라 써요.

설치 후 Claude Code에 붙여 넣기 ([ ] 채우기)복사해서 붙여 넣기
1. (copywriting) 우리 [가게/서비스] 첫 화면 문구를 다시 써 줘. 지금 문구는 [ ]야. 3가지 버전으로.
2. (cro) 이 상세페이지를 점검해 줘: [링크 또는 파일]. 고칠 곳을 중요한 순서로 5개만.
3. (ad-creative) 인스타 광고 문구 5개 써 줘. 타깃은 [ ], 혜택은 [ ].
4. (pricing) 지금 가격은 [ ]이고 경쟁 상품은 [ ]야. 가격 구성(기본·추천·프리미엄)을 제안해 줘.
5. (seo-audit) 내 블로그 [주소]의 검색 노출 문제를 점검하고 고칠 순서를 알려 줘.
6. (ai-seo) ChatGPT나 Claude 같은 AI 검색에 우리 서비스가 소개되려면 뭘 고쳐야 할까?
7. (emails) 처음 가입한 고객에게 보낼 안내 메일 3통을 순서대로 써 줘.
8. (social) 이번 주 인스타 게시물 5개 주제와 첫 문장을 짜 줘.
9. (launch) 새 메뉴/상품 [ ] 출시 계획을 2주 일정으로 짜 줘.
10. (marketing-ideas) 돈 안 드는 홍보 아이디어 10개를 우리 업종 [ ]에 맞게 골라 줘.
결과는 초안이에요. 숫자·후기·효과 같은 내용은 실제로 확인된 것만 남기고 고치세요.
STEP 02 · 먼저 이것만
2

이게 뭐예요?

  • 무엇: 마케팅 대행사를 운영하는 마케터가 만든 AI 에이전트용 마케팅 스킬 모음이에요. 스킬은 AI에게 '이 일은 이런 순서로 하라'는 마케팅 틀을 알려 주는 문서예요. GitHub 별 5만 8천 개가 넘어요(2026-11-07 기준).
  • 몇 개: 53개예요(README 표 기준). 광고 문구(copywriting), 전환율 점검(cro), 가격(pricing), 검색 노출(seo-audit, ai-seo), 광고 소재(ad-creative), 영업 메일(cold-email) 등.
  • 얼마: 스킬 모음은 무료(MIT 라이선스)예요. 쓰는 에이전트 요금은 따로예요(Claude Code는 Pro 이상).
  • 어디서: Claude Code, OpenAI Codex, Cursor, Windsurf처럼 Agent Skills를 읽는 코딩 에이전트에서 써요. 일반 ChatGPT·Claude 채팅창에 바로 설치하는 방식은 아니에요.
  • 시작점: product-marketing 스킬이 기본이에요. 다른 스킬이 이 스킬이 만든 제품 소개 문서를 먼저 읽고 일해요.
STEP 03 · 주의
3

꼭 알아 둘 점

  • Claude Code 안에서 설치를 시키면 끝에 -a claude-code를 붙이세요. 안 붙이면 .agents/skills/ 폴더에만 깔릴 수 있는데, Claude Code는 그 폴더를 읽지 않아요(README 안내).
  • /plugin 명령은 내 컴퓨터의 대화형 Claude Code에서만 돼요. 웹판 Claude Code나 GitHub Actions에서는 'isn't available in this environment'가 떠요. 그때는 npx 방식으로 설치하세요.
  • 매출을 보장하지 않아요. 스킬은 마케팅 순서를 잡아 주는 틀이에요. 결과 문구는 내가 확인하고 고쳐야 해요.
  • README의 Partners(파트너) 도구는 선택이에요. 유료 연동 서비스라 설치에 필요 없어요.
  • 광고 계정 연결은 나중에, 읽기 전용부터 하세요. README에 계정 연결 안내(tools/SETUP.md)가 있지만, 처음에는 연결하지 않아도 스킬을 다 쓸 수 있어요.
  • 스킬이 만든 광고는 내가 확인한 뒤 내 손으로 올리세요. 광고 계정을 연결하더라도 광고 집행·예산 변경·게시 권한은 주지 마세요. 테스트할 때는 예산 칸에 실제 금액을 넣지 마세요.
  • 영업 메일(cold-email)은 초안만 받으세요. 자동 발송을 연결하면 한 번에 여러 사람에게 나갈 수 있어요. 한국에서는 받는 사람의 명시적인 사전 동의 없이 영리 목적 광고 메일을 보내면 안 돼요(정보통신망법 제50조, 2026-11-07 확인). 오후 9시~오전 8시 발송은 동의를 따로 받아야 해요.
  • 광고 문구는 사실만 넣으세요. 확인 안 된 효과, 가짜 후기, 근거 없는 '1위' 같은 말은 빼세요.

STEP 05 · 처음 하는 사람용
5

따라 하기

  1. Node.js를 설치해요(이미 있으면 건너뛰기).
  2. 내 가게·서비스 작업 폴더를 만들고, 그 폴더에서 PowerShell·터미널을 열어요.
  3. 설치 명령을 입력해요: npx skills add coreyhaines31/marketingskills
  4. 어디에 깔지 물어보면 Claude Code를 골라요. 스킬이 .claude/skills/에 들어가요.
  5. 같은 폴더에서 Claude Code를 열고, product-marketing 스킬로 제품 소개 문서부터 만들어요.
  6. 위 '바로 쓰는 질문 10개'를 하나씩 붙여 넣어 써 봐요.

몇 개만 깔고 싶으면 npx skills add coreyhaines31/marketingskills --skill cro copywriting, 목록만 보려면 --list를 붙여요.

버튼 이름과 질문 순서는 바뀔 수 있어요. 화면에 보이는 대로 따라가세요.

안 될 때

  • 'npx' 명령을 못 찾아요 · 먼저 확인: Node.js 설치 → Node.js를 설치하고 터미널을 새로 열어요
  • /plugin isn't available in this environment · 먼저 확인: 웹판·원격 환경인지 → npx 방식으로 설치해요
  • 답이 우리 가게와 안 맞아요 · 먼저 확인: 제품 소개 문서 → product-marketing 스킬로 소개 문서를 먼저 만들어요
