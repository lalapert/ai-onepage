스킬 켜는 법과 내 스킬 만들기

스킬은 Claude가 특정 작업을 일정한 방식으로 하도록 넣어 두는 지시·스크립트·자료 폴더예요. ‘코드 실행과 파일 만들기’를 켜 두면 Excel, Word, PowerPoint, PDF를 진짜 파일로 받아요. 내 규칙은 SKILL.md로 올려 두면 돼요.

무료부터 Claude 앱에서 스킬기본 4개 엑셀·워드·PPT·PDFSKILL.md 내 규칙 올리기

Claude Code에 바로 붙여 넣기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요(무료 플랜 미포함, 공식 문서 2026년 11월 6일 확인). 무료 플랜이면 이 단계는 건너뛰고 아래 순서대로 따라 하세요.
  • 여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 작업할 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.
  • Claude Code 설치: Windows PowerShell irm https://claude.ai/install.ps1 | iex · Mac curl -fsSL https://claude.ai/install.sh | bash
  • 데스크톱 앱: Windows / Mac
Claude Code에 붙여 넣기복사해서 붙여 넣기
Anthropic이 공개한 문서 스킬(엑셀·워드·파워포인트·PDF)을 Claude Code에 설치하고 확인해 줘.
1. 아래 두 명령을 차례로 실행해 줘.
   /plugin marketplace add anthropics/skills
   /plugin install document-skills@anthropic-agent-skills
2. /skills 로 설치된 스킬 목록을 보여 줘.
3. 이 폴더에 '테스트_발표.pptx'를 슬라이드 3장(표지 / 핵심 3가지 / 다음 할 일)으로 만들어 줘.
4. 파일이 생겼는지 확인하고 위치를 알려 줘. 파이썬 라이브러리 같은 게 더 필요하면 설치 전에 나에게 먼저 물어봐 줘.
STEP 01 · 어디서 실행하나
1

두 가지 실행법: Claude 앱 vs Claude Code

같은 스킬이라도 어디서 실행하느냐에 따라 결과가 다를 수 있어요. A는 Claude 앱(웹·데스크톱 채팅), B는 Claude Code(앱의 Code 탭 / PowerShell·터미널)예요.

  • 어디서 돌아가나
    A. Claude 앱: Anthropic 쪽 격리된 실행 환경
    B. Claude Code: 내 컴퓨터
  • 켜는 법
    A. Claude 앱: 설정 › Capabilities에서 '코드 실행과 파일 만들기'(새 화면 'Create and edit files') 켜기
    B. Claude Code: STEP 00 명령으로 설치, 또는 ~/.claude/skills/[스킬이름]/SKILL.md에 넣기
  • 내 스킬 올리기
    A. Claude 앱: Customize › Skills › + › Create skill › Upload a skill (ZIP)
    B. Claude Code: 폴더째 ~/.claude/skills/(나만) 또는 프로젝트의 .claude/skills/(팀 공유)
  • 인터넷
    A. Claude 앱: 설정에 따라 막히거나 일부만 열림
    B. Claude Code: 내 컴퓨터의 다른 프로그램과 같음
  • 필요한 프로그램
    A. Claude 앱: 미리 깔린 것만
    B. Claude Code: 내 컴퓨터에 없으면 설치해야 함
  • 플랜
    A. Claude 앱: STEP 04 참고
    B. Claude Code: Pro 이상
앱에서 올린 스킬은 같은 계정으로 로그인한 Claude Code에 한 방향으로 동기화돼요(공식 도움말, Claude Code 2.1.273 이상). 이 차이는 공식 문서에 적힌 실행 환경 차이까지만 적었어요. 같은 스킬이 두 곳에서 똑같이 나오는지는 직접 비교하지 않았어요.
STEP 02 · AI에게 맡기기
2

AI에게 바로 맡기기

① 내 스킬 초안 만들기: Claude에 붙여 넣으세요.

① Claude에 붙여 넣기 ([ ] 채우기)복사해서 붙여 넣기
나만의 Claude 스킬을 만들고 싶어. 아래 정보로 SKILL.md 파일 내용을 만들어 줘.
- 스킬 이름(영어 소문자와 하이픈): [my-deck]
- 언제 쓰는지 한 문장: [우리 팀 발표 자료를 만들 때]
- 꼭 지킬 규칙: [표지는 남색 / 글꼴은 Pretendard / 슬라이드마다 핵심 한 줄 / 마지막 장은 다음 할 일]
형식:
1. 맨 위에 --- 로 감싼 name, description 두 줄.
2. 그 아래 규칙, 예시, 하지 말 것.
3. 다 쓰면, 이 파일을 넣은 폴더를 ZIP으로 압축해 Customize → Skills에 올리는 순서를 알려 줘.

② 기본 스킬로 파일 받기: 평소처럼 부탁하세요.

② 평소처럼 부탁하기 ([ ] 채우기)복사해서 붙여 넣기
3분기 실적 발표 PPT를 만들어 줘. 슬라이드 7장, 표지 / 매출 요약 / 지역별 비교 / 잘된 점 / 아쉬운 점 / 다음 분기 계획 / 질문 순서. 숫자는 [첨부 엑셀]에서만 가져오고, 없으면 빈칸으로 남겨 줘.
STEP 03 · 먼저 이것만
3

한눈에 보기

  • 무엇: 스킬은 Claude가 특정 작업을 일정한 방식으로 하도록 넣어 두는 지시·스크립트·자료 폴더예요. Anthropic이 공개한 저장소 anthropics/skills는 GitHub 별 187,524개예요(2026년 11월 5일 기준).
  • 누가: 공식 도움말 기준 Free, Pro, Max, Ultra, Team, Enterprise 플랜에서 쓸 수 있어요. ‘코드 실행과 파일 만들기’가 켜져 있어야 해요.
  • 기본 스킬: Excel, Word, PowerPoint, PDF. 켜 두면 Claude가 필요할 때 알아서 사용해요.
  • 내 스킬: SKILL.md를 넣은 폴더를 ZIP으로 압축해 올리면 돼요.
핵심설정 하나 켜면 PPT·엑셀·워드·PDF를 진짜 파일로 받아요. 내 규칙은 SKILL.md로 올려 둬요.
STEP 04 · 주의
4

꼭 알아 둘 점

  • 남이 만든 스킬은 안의 코드가 그대로 실행될 수 있어요. 공식 도움말도 믿을 수 있는 출처의 스킬만 설치하고, 올리기 전에 폴더 속 파일을 열어 읽어 보라고 안내해요.
  • '코드 실행과 파일 만들기'가 꺼져 있으면 스킬이 동작하지 않아요. 회사·학교 계정은 관리자가 막아 둘 수도 있어요.
  • 내 스킬 올리기(ZIP)의 플랜 안내가 공식 문서끼리 달라요. 도움말은 무료 플랜도 된다고 하고, 개발자 문서는 Pro 이상이라고 해요(2026년 11월 6일 확인). 무료에서 업로드 메뉴가 안 보이면 플랜 때문일 수 있어요.
  • Claude Code에서 쓰려면 Pro 이상 플랜이 필요해요. 앱과 Claude Code는 실행 환경이 달라서 결과가 다를 수 있어요(STEP 01 비교).
  • 메뉴 이름은 앱 버전과 언어에 따라 달라요. 'Create and edit files'처럼 다르게 보일 수 있어요.
  • 만든 파일은 꼭 열어서 확인하세요. 숫자나 이름이 틀릴 수 있어요. 첨부한 자료에 없는 숫자는 빈칸으로 두라고 부탁하면 덜 틀려요.
STEP 05 · 처음 하는 사람용
5

파일 만들기와 스킬 켜기

파일 만들기 켜기 (개인 플랜)

  1. Claude 앱 또는 claude.ai에서 Settings(설정)를 열어요.
  2. Capabilities로 가요.
  3. Code execution and file creation을 켜요. 새 설정 화면에서는 이름이 Create and edit files예요.

스킬 켜기

  1. Customize → Skills로 가요.
  2. 쓰고 싶은 스킬 옆 스위치를 켜요.
  3. 이제 “PPT 만들어 줘”처럼 부탁하면 Claude가 해당 스킬을 써서 파일을 만들어요.
Team·Enterprise는 관리자가 Organization settings → Plugins & skills에서 먼저 허용해야 해요.
STEP 06 · 내 규칙 올리기
6

내 스킬 올리기

  1. STEP 02의 ① 문장으로 SKILL.md 내용을 받아요.
  2. 컴퓨터에 스킬 이름과 같은 폴더를 만들고 그 안에 SKILL.md로 저장해요.
  3. 폴더를 ZIP으로 압축해요.
  4. Customize → Skills → + → Create skill → Upload a skill에서 ZIP을 올려요.
  5. 목록에 생기면 스위치를 켜요.
STEP 07 · 복사해서 쓰기
7

내 스킬 템플릿

아래를 SKILL.md로 저장하고 내 규칙으로 바꿔 쓰세요.

SKILL.md 템플릿복사해서 붙여 넣기
---
name: my-deck
description: 우리 팀 발표 자료(PPT)를 만들 때 사용한다. 표지 색, 글꼴, 슬라이드 구성 규칙을 따른다.
---

# 우리 팀 발표 자료 규칙

## 반드시
- 표지 배경은 남색, 글꼴은 Pretendard
- 슬라이드마다 맨 위에 핵심 한 줄
- 마지막 장은 '다음 할 일'과 담당자

## 하지 말 것
- 출처 없는 숫자 넣기
- 한 장에 글머리표 6개 넘기기
STEP 08 · 막히면
8

안 될 때

  • Skills 메뉴가 안 보임: 코드 실행·파일 만들기가 켜졌는지 확인해요. Settings → Capabilities에서 켜고 다시 Customize → Skills.
  • 스킬이 회색: 같은 설정을 확인해요. 팀 플랜이면 관리자 설정이에요. 개인은 Capabilities 확인, 팀은 관리자에게 요청해요.
  • 스킬을 안 씀: 스킬 스위치와 description 문장을 확인해요. “my-deck 스킬로 만들어 줘”처럼 이름을 직접 말해요.
  • 업로드 실패: 폴더 이름 = 스킬 이름인지, SKILL.md가 있는지 확인해요. 이름을 맞추고 다시 압축해요.
