클로드가 만드는 화면에서 AI 티를 빼 주는 디자인 스킬

AI에게 아무 말 없이 홈페이지를 시키면 크림색 배경, 얇은 글씨, 알약 버튼 같은 비슷한 디자인이 계속 나와요. impeccable은 이런 버릇을 짚어 주고 고쳐요. 말로 디자인을 고치는 명령 24개와 AI 티를 잡는 검사 규칙 62개가 들어 있어요.

STEP 00 먼저 이것만
0

이게 뭐예요?

  • 클로드가 만드는 화면에서 AI 티를 빼 주는 디자인 스킬이에요. 스킬은 "이 일은 이렇게 해" 하고 클로드에게 미리 써 준 설명서 파일이에요.
  • AI에게 아무 말 없이 홈페이지를 시키면 비슷한 디자인이 계속 나와요. 크림색 배경, 얇은 글씨, 동그란 알약 버튼, 보라→파랑 그라데이션 같은 것들이에요. impeccable은 이런 버릇을 짚어 주고 고쳐요.
  • "더 과감하게(bolder)", "더 조용하게(quieter)"처럼 말로 디자인을 고치는 명령 24개와, AI 티를 잡는 검사 규칙 62개가 들어 있어요.
  • 무료예요(Apache 2.0). 다만 Claude Code는 유료 플랜이 필요해요.

STEP 02 처음 한 번
2

Claude Code 열기

  1. claude.ai/download에서 내 컴퓨터(Windows 또는 Mac)에 맞는 앱을 받아요.
  2. 받은 파일을 열어 설치하고, 앱을 켜서 로그인해요.
  3. 앱 왼쪽 위에 있는 Code 탭을 눌러요.
  4. 폴더를 고르라는 창이 뜨면, 고칠 홈페이지가 들어 있는 폴더를 골라요. 처음이면 바탕화면에 새 폴더를 하나 만들어서 골라요.
  5. 이렇게 보이면 성공: 화면 아래에 글을 쓰는 칸이 생겨요.
STEP 03 설치
3

impeccable 깔기

  1. Claude Code 글 쓰는 칸에 아래 줄을 붙여 넣고 Enter를 눌러요.
  2. 이어서 글 칸에 /plugin만 치고 Enter를 눌러요. 목록이 열려요.
  3. 목록에서 Impeccable을 골라 설치해요.
  4. 앱을 완전히 껐다가 다시 켜요.
  5. 이렇게 보이면 성공: 글 칸에 /impeccable을 쳤을 때 명령 목록이 보여요.
1번에서 붙여 넣을 줄
/plugin marketplace add pbakaus/impeccable

이 방법이 어려우면 아래 글을 통째로 붙여 넣고 클로드에게 맡겨요.

클로드에게 설치 맡기기
https://github.com/pbakaus/impeccable
이 디자인 스킬을 Claude Code에 설치해 줘. 설치하면서 뭘 하는지 쉬운 말로 알려 주고, 내 컴퓨터에 새로 깔아야 하는 게 있으면 먼저 물어봐.
다 되면 /impeccable 명령이 되는지 확인해 줘.
STEP 04 처음 한 번
4

내 프로젝트 알려 주기

  1. 글 칸에 /impeccable init을 치고 Enter를 눌러요.
  2. 클로드가 내 코드를 읽고, 알아서 알 수 없는 것만 물어봐요. 누구를 위한 서비스인지, 무엇을 해야 하는지 같은 것이에요. 쉬운 말로 답하면 돼요.
  3. 이렇게 보이면 성공: 폴더에 PRODUCT.md라는 파일이 생겨요. 이후 모든 명령이 이 파일을 읽어요.
  4. 이미 정해 둔 색·글꼴이 있으면 /impeccable document도 한 번 쳐요. DESIGN.md가 생겨서 앞으로 바꿀 때도 내 스타일을 지켜요.
STEP 05 한 곳씩
5

써 보기

한 곳씩 고치는 게 가장 잘 돼요. 페이지 전체보다 "맨 위 큰 영역", "가격 카드"처럼 한 곳을 골라요.

  1. 먼저 점수부터 받아 봐요: /impeccable critique the hero (hero는 맨 위 큰 영역이라는 뜻이에요)
  2. 클로드가 디자인 점수와, 먼저 고칠 것 순서를 알려 줘요.
  3. 고쳐 달라고 해요:
    · 너무 밋밋하면 /impeccable bolder the hero
    · 너무 시끄러우면 /impeccable quieter the hero
    · 마지막 다듬기는 /impeccable polish the hero
  4. 영어 명령이 어려우면 그냥 우리말로 써도 돼요: /impeccable 맨 위 영역을 다시 만들어 줘
  5. 이렇게 보이면 성공: 화면을 새로고침하면 바뀐 디자인이 보여요.

자주 쓰는 명령

  • critique: 디자인 점수와 고칠 순서
  • audit: 접근성·속도·화면 크기 대응 검사(급한 것부터 P0~P3)
  • bolder / quieter: 더 과감하게 / 더 조용하게
  • distill: 필요 없는 것 빼기
  • typeset: 글꼴·크기 정리
  • polish: 내보내기 전 마지막 다듬기
  • 전체 목록은 글 칸에 /impeccable만 치면 보여요.
STEP 06 선택
6

AI 티 검사만 따로 해 보기

  • 클로드에게 "impeccable 검사기로 이 폴더 AI 티 검사해 줘"라고 하면 돼요.
  • 직접 하려면 터미널에서 npx impeccable detect src/처럼 폴더를 넣어요. Node가 필요해요.
  • 이 검사는 AI를 부르지 않고 정해진 규칙 62개로만 봐요. API 키(다른 서비스 비밀번호 같은 것)가 필요 없어요.
STEP 07 주의
7

꼭 알아 둘 점

  • 이미 있는 화면을 다듬을 때 가장 잘해요. 빈 폴더에서 새 페이지를 만드는 건 더 어려운 일이라고 설명서에 적혀 있어요.
  • 'live 모드'의 적용 기능은 처음엔 쓰지 마세요. 브라우저에서 고른 수정을 적용할 때, 대화 중인 클로드가 없으면 다른 AI 프로그램을 승인 확인 없이 실행할 수 있다고 설명서에 적혀 있어요. 익숙해진 뒤 내 프로젝트에서만 써요.
  • 영상 속 비교 그림은 설명서에 실린 예시예요. 같은 결과가 꼭 나오지는 않아요. 요청과 프로젝트에 따라 달라요.
  • Claude Code 말고도 Cursor, Codex 같은 다른 코딩 도구에서도 돼요.
