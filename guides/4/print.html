내 브랜드 이름으로 5초짜리 로고 오프닝 MP4를 만들어 줘.
브랜드 이름: [내 브랜드 이름]
색: [배경색], [글자색], [강조색]
용도: 릴스나 영상 시작에 넣을 짧은 오프닝

파일을 만들고 실행할 수 있는 현재 작업 폴더에서 진행해 줘.
먼저 운영체제, Node.js, 브라우저 렌더 도구, FFmpeg 사용 가능 여부를 확인해 줘.
도구가 없으면 필요한 설치와 이유를 설명하고 내 승인을 받은 뒤 진행해 줘.

첫 장면은 도형이 들어오고, 이어서 글자가 모여 브랜드 이름을 완성해 줘.
마지막 1초는 이름을 읽을 수 있도록 정지해 줘.
이미지·영상 생성 API 없이 코드로 직접 그리는 2D 모션으로 만들어 줘.
1080×1080, 60fps, 5초, H.264 MP4 파일 logo_opener.mp4로 렌더해 줘.

코드만 주고 끝내지 말고, 파일 생성·전체 재생 또는 디코딩·길이·해상도를 확인해 줘.
첫 장면과 마지막 장면에서 글자가 잘리거나 겹치지 않는지도 확인해 줘.
이름과 색을 나중에 쉽게 바꿀 수 있도록 원본 코드도 남겨 줘.
실패하면 완료했다고 하지 말고 실패한 단계와 다음 방법을 알려 줘.

브랜드 이름과 색 세 가지를 바꾸고 Codex에 붙여 넣으세요. 이 요청은 코드를 작성하고 실행하는 작업이라 파일 실행 환경이 필요해요.

일반 대화창에서 문장만 보내면 반드시 MP4가 나오는 것은 아니에요.
STEP 01 · 시작 전에
1

준비물과 비용

  • PC에서 사용할 수 있는 Codex 클라이언트와 ChatGPT 계정
  • 작업용 빈 폴더 하나. 예: logo-motion
  • 애니메이션을 그릴 브라우저와 영상을 저장할 FFmpeg. 설치 여부는 STEP 00 프롬프트로 먼저 확인할 수 있어요.

Codex는 무료·Go를 포함한 ChatGPT 플랜에서 제공되지만 사용량 한도는 달라요. Codex Cloud는 별도 이용 조건이 있으며 Free·Go에 포함되지 않아요. 대상 계정·워크스페이스 설정은 공식 안내와 계정 화면을 확인하세요. Codex 이용 안내

이번 예제는 별도의 영상 생성 API를 사용하지 않았어요. Codex의 사용량과 실행 환경은 필요하며, 모든 작업이 무제한 무료라는 뜻은 아니에요. 생성·수정·렌더에 걸리는 시간도 환경과 요청에 따라 달라요.
STEP 02 · 1단계
2

Codex에서 빈 작업 폴더를 여세요

PC의 Codex 클라이언트에서 로그인하고 작업 폴더를 선택해요. 처음 설치한다면 공식 Codex 안내의 시작하기에서 사용하려는 클라이언트의 설치 안내를 따라가세요.

터미널 사용이 익숙하다면 Codex CLI에서도 할 수 있어요. 설치한 뒤 빈 폴더에서 codex를 실행하고 로그인해요.

Codex CLI가 설치되어 있지 않은 상태에서 이 명령만 입력하면 실행되지 않아요.
STEP 03 · 2단계
3

세 가지를 정하세요

  • 이름: 이번 예제는 ai.onepage. 내 채널·상호·프로젝트 이름으로 바꿔요.
  • 색: 이번 예제는 크림색 / 검정 / 빨강. 브랜드 색 2~3개로 바꿔요.
  • 움직임: 이번 예제는 도형 진입 → 글자 등장 → 이름 정지. 원하는 장면 순서로 바꿔요.

기존 브랜드를 모방하기보다는 본인의 이름과 시각 요소로 만드세요. 한글 이름도 요청할 수 있지만, 한글 글꼴이 렌더 환경에 있는지 확인하도록 덧붙이는 게 좋아요.

STEP 04 · 3단계
4

맨 위 프롬프트를 보내세요

중간에 설치나 실행 권한을 묻는다면 무엇을 설치하는지, 선택한 작업 폴더에서 진행하는지 확인하고 승인하세요. API 키를 공개하거나 대화에 비밀번호를 붙여 넣을 필요는 없어요.

처음 결과가 밋밋하면 장면을 구체적으로 바꿔 달라고 요청해요.

결과가 밋밋할 때 이어서 붙여 넣기복사해서 붙여 넣기
첫 1초에는 빨간 도형이 왼쪽에서 들어오게 해 줘.
가운데 장면에서 브랜드 이름은 한 글자씩 빠르게 등장하게 해 줘.
마지막 1초는 배경과 이름을 고정하고, 글자를 더 크게 보여 줘.
같은 길이와 파일 형식으로 다시 렌더해 줘.
STEP 05 · 4단계
5

MP4 파일을 열어 확인하세요

완료 답변에서 logo_opener.mp4 파일을 찾아 다운로드하거나 작업 폴더에서 열어요. 글자만 보이는 소스 파일이나 미리보기 링크만 받았다면 이어서 말하세요.

MP4 파일이 없을 때 붙여 넣기복사해서 붙여 넣기
미리보기와 코드 외에 실제 재생 가능한 MP4 파일도 필요해.
지금 작업한 애니메이션을 5초 MP4로 렌더하고,
파일 경로, 길이, 해상도, 전체 디코딩 검사 결과를 알려 줘.

직접 확인할 항목은 세 가지예요.

  • 파일이 실제로 열리고 처음부터 끝까지 재생되는가?
  • 브랜드 이름의 철자와 색이 맞는가?
  • 마지막 1초 동안 이름이 잘리지 않고 충분히 읽히는가?
STEP 06 · 예제
6

이번에 직접 만든 예제

ai.onepage의 원본 로고 오프닝 5초 영상을 직접 만들었어요. Codex에서 원본 애니메이션 코드를 작성하고 Chromium으로 프레임을 렌더한 뒤 FFmpeg로 MP4를 만들었어요.

핵심실제 파일은 1080×1080 / 60fps / H.264 / 5.000초예요. 예제 MP4에는 소리가 없고, 릴스 본편의 내레이션·음악은 별도 편집이에요.
이 결과는 제작 과정에서 구성을 다듬은 예제예요. 같은 프롬프트를 한 번 입력하면 똑같은 영상이 나온다는 보장은 없어요.
STEP 07 · 릴스용
7

세로 영상에 넣으려면

이 예제는 정사각형 로고 영상이에요. 처음부터 릴스 화면 전체를 채우려면 프롬프트의 1080×1080을 1080×1920으로 바꾸고, “중요한 글자는 화면 중앙에 배치해 줘”라고 추가하세요.

이미 만든 영상은 편집 앱에 가져와 크기와 위치를 조절하면 돼요.

STEP 08 · 막히면
8

막힐 때

  • “FFmpeg를 찾을 수 없다”: 설치 위치와 실행 경로를 확인해 달라고 요청하세요.
  • 코드만 출력한다: 파일을 실행할 수 있는 Codex 환경인지 확인하고 MP4 렌더를 다시 요청하세요.
  • 한글이 네모로 나온다: 한글 지원 글꼴을 사용할 수 있는지 확인해 달라고 하세요.
  • 렌더가 너무 느리다: 해상도를 먼저 낮춰 미리 확인한 뒤 최종 해상도로 다시 뽑으세요.
  • 사용 한도에 도달한다: 계정의 한도·초기화 안내를 확인하세요.
