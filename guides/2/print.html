Docling: PDF 표를 CSV로 꺼내기

글자를 선택할 수 있는 PDF 속 표를 CSV로 저장하기

Docling은 PDF 같은 문서의 구조를 분석하는 오픈소스 도구예요. 내 컴퓨터 CPU로 PDF 속 표를 꺼내 엑셀이나 구글 스프레드시트에서 여는 CSV로 저장해요.

AI에게 먼저 부탁하기

아래 문장을 통째로 복사해 ChatGPT, Claude 또는 Grok에 붙여 넣으세요.

ChatGPT · Claude · Grok에 붙여 넣기복사해서 붙여 넣기
나는 컴퓨터 초보자야. Docling으로 내 PDF에 있는 표를 CSV로 바꾸고 싶어.
먼저 내 운영체제가 Windows인지 Mac인지 물어보고, Python이 설치되어 있는지 확인하는 방법부터 알려줘.
아래 조건을 지켜 한 번에 한 단계씩 안내해 줘.

- 먼저 텍스트를 선택할 수 있는 PDF 한 개로 테스트해. 스캔본이면 OCR이 별도로 필요하다고 알려줘.
- 공식 설치 문서 https://docling-project.github.io/docling/getting_started/installation/ 와 공식 표 내보내기 예제 https://github.com/docling-project/docling/blob/main/docs/examples/export_tables.py 를 참고해.
- 가상환경 만들기, 활성화, docling==2.146.0 설치, PDF와 파이썬 파일을 같은 폴더에 두기, 실행, 결과 확인까지 빠짐없이 설명해.
- 명령은 내 운영체제에 맞춰 복사하기 쉽게 따로 보여 주고, 어디에 입력하는지 알려줘.
- 생성된 CSV의 열 이름, 누락된 행, 병합 셀, 숫자와 기호를 원본 PDF와 비교하도록 안내해.
- 내 PC에 접근할 수 없으면 직접 설치하거나 변환했다고 주장하지 마. 오류가 나면 전체 오류 문구를 요청하고 민감정보는 가리라고 해.
- 개인정보가 들어간 문서나 비밀번호를 보내 달라고 하지 마.
이 문장은 도움을 요청하는 거예요. AI가 내 컴퓨터를 직접 조작할 수 있는지는 사용하는 앱과 권한에 따라 달라요.
STEP 01 · 먼저 이것만
1

이 도구로 무엇을 하나요?

Docling은 PDF 같은 문서의 구조를 분석하는 오픈소스 도구예요. 이 가이드는 글자를 선택할 수 있는 PDF 안의 표를 CSV로 저장하는 방법이에요.

CSV는 엑셀이나 구글 스프레드시트에서 열 수 있는 표 파일이에요. 사진을 찍은 스캔 PDF는 OCR 설정이 필요하고, 아래 예제에선 OCR을 껐어요.

실제 확인한 범위: 직접 만든 한 장짜리 가상 구매내역 PDF를 CPU로 처리했어요. 표 1개가 추출됐고 숫자는 일치했지만 자동 열 이름을 직접 고쳤고 긴 대시가 하이픈으로 바뀌었어요. 20개 셀 중 19개가 문자열까지 일치한 한 사례이며 정확도를 보장하지 않아요. 영상은 실제 입출력을 바탕으로 만든 설명 화면이며 앱 실시간 녹화가 아니에요.
핵심글자를 선택할 수 있는 PDF 한 개로 먼저 시험하고, 나온 CSV는 꼭 원본과 비교해요.
STEP 02 · 시작 전에
2

준비하기

  • Windows 또는 Mac 컴퓨터, 인터넷, 여유 저장 공간이 필요해요. 설치와 첫 실행 시 모델 파일을 내려받을 수 있어요.
  • 테스트할 PDF를 준비해요. 글자를 마우스로 선택할 수 있는 PDF를 먼저 써 보세요. 민감정보가 없는 파일을 권장해요.
  • 이 가이드는 Python 3.12와 Docling 2.146.0으로 시험했어요. 로컬 CPU 실행 자체에는 별도 유료 추론 API가 필요하지 않지만 컴퓨터 자원과 다운로드가 필요해요. 외부 AI/API를 연결하면 별도 요금이 생길 수 있어요.

3

Python 설치 확인하기

  1. Windows: 시작 메뉴에서 PowerShell을 검색해 열어요. Mac: Spotlight에서 터미널을 검색해 열어요.
  2. Windows에서는 아래 첫 줄, Mac에서는 둘째 줄을 입력하고 Enter를 눌러요.
Windows는 첫 줄만, Mac은 둘째 줄만복사해서 붙여 넣기
py --version
python3 --version

Python 3.12가 보이면 다음 단계로 가요. 없거나 다른 버전이면 Python 공식 다운로드에서 Python 3.12 계열을 설치해요. Windows 설치 화면에 “Add Python to PATH”가 나오면 선택하세요. 터미널을 닫았다 다시 열고 버전을 확인해요.

STEP 04 · 설치
4

작업 폴더와 가상환경 만들기

  1. 바탕화면에 docling-test 폴더를 만들어요.
  2. 터미널에 cd 를 입력하고(마지막에 공백 포함) 폴더를 터미널 창으로 끌어다 놓은 다음 Enter를 눌러요. 이후 명령은 이 창에서 입력해요.
  3. 아래에서 내 컴퓨터에 맞는 명령만 복사해 한 줄씩 실행해요.
Windows PowerShell복사해서 붙여 넣기
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install "docling==2.146.0"
Mac 터미널복사해서 붙여 넣기
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install "docling==2.146.0"
설치가 끝나면 같은 터미널을 계속 사용해요. PowerShell 실행 정책 오류가 나면 보안 설정을 임의로 바꾸지 말고 오류 문구를 AI에 보여 주세요. 시스템 설정 변경 전에는 내용을 확인하세요. Mac Intel의 PyTorch 호환성은 공식 설치 안내를 확인해요.
STEP 05 · 파일 두 개
5

PDF와 실행 파일 준비하기

  1. 테스트 PDF를 docling-test 폴더에 복사하고 이름을 sample_report.pdf로 바꿔요. 원본을 보관하고 복사본으로 시험하세요.
  2. Windows에서는 메모장, Mac에서는 텍스트 편집기(일반 텍스트 모드)를 열어요.
  3. 아래 코드를 복사해 붙여 넣고 같은 폴더에 extract_tables.py라는 이름으로 저장해요. Windows 메모장은 파일 형식을 “모든 파일”로 선택해 .txt가 뒤에 붙지 않게 해요.
extract_tables.py로 저장복사해서 붙여 넣기
from pathlib import Path
from docling.document_converter import DocumentConverter, PdfFormatOption
from docling.datamodel.base_models import InputFormat
from docling.datamodel.pipeline_options import PdfPipelineOptions

options = PdfPipelineOptions()
options.do_ocr = False
options.enable_remote_services = False
converter = DocumentConverter(format_options={
    InputFormat.PDF: PdfFormatOption(pipeline_options=options)
})
result = converter.convert("sample_report.pdf")
for i, table in enumerate(result.document.tables, 1):
    df = table.export_to_dataframe(doc=result.document)
    df.to_csv(f"table_{i}.csv", index=False, encoding="utf-8-sig")
Path("document.md").write_text(
    result.document.export_to_markdown(), encoding="utf-8"
)
print(f"표 {len(result.document.tables)}개를 찾았습니다.")
STEP 06 · 실행
6

실행하고 확인하기

같은 터미널에서 아래 한 줄을 입력해요.

같은 터미널에 입력복사해서 붙여 넣기
python extract_tables.py

처음에는 모델 다운로드로 시간이 걸릴 수 있어요. 끝나면 같은 폴더에 table_1.csv 등의 파일이 생겨요. document.md에는 문서의 Markdown 변환 결과가 저장돼요.

표가 여러 개면 CSV도 여러 개 생길 수 있고, 감지된 표가 없으면 CSV가 생기지 않아요.

핵심CSV를 엑셀이나 스프레드시트로 열어 원본과 열 이름, 빠진 행, 병합 셀, 숫자, 기호를 비교하세요. 0, 1 같은 열 이름이 있더라도 첫 행을 무조건 지우지 말고 머리글인지 확인해요.
STEP 07 · 막히면
7

문제가 생겼나요?

  • python 또는 py를 찾지 못함: Python 설치와 버전 확인 후 터미널을 다시 열어요.
  • No module named docling: 가상환경을 다시 활성화한 같은 창에서 설치 명령을 실행해요.
  • 파일을 찾지 못함: 터미널이 작업 폴더에 있는지, PDF 이름이 정확한지, .pdf가 중복되지 않았는지 확인해요.
  • 표가 안 나옴: PDF가 이미지 스캔인지, 표가 실제로 감지됐는지 확인해요. 스캔본은 별도 OCR 설정이 필요해요.
  • 오류가 계속되면 전체 오류를 복사해 AI에게 질문하세요. 파일 경로에 이름 등 개인정보가 들어 있다면 가리고 보내세요.
