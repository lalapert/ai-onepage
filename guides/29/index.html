서치어드바이저 등록 3단계: 내 주소, 확인 태그, 사이트맵

클로드로 만든 제 정리 사이트를 네이버에서 site: 검색으로 찾아봤더니 0건이었어요(11월 20일). 이유는 네이버 가이드에 그대로 있었어요. 사이트 등록은 호스트 단위만 돼서, 주소 뒤에 폴더가 붙은 사이트나 클로드 공유 링크는 내 사이트로 등록할 수가 없어요.

STEP 00 먼저 이것만
0

왜 안 나와요?

네이버는 새 사이트를 알아서 다 찾아오지 않아요. 네이버 서치어드바이저(웹마스터 도구)에 내 사이트를 등록하고, 내 사이트가 맞다는 걸 확인받아야 검색 로봇이 제대로 다녀가요.

그런데 가이드에 따르면 사이트 등록은 호스트 단위만 돼요. www.mysite.com, blog.mysite.com은 되고 www.mysite.com/myid처럼 뒤에 붙은 주소는 안 돼요.

그래서 아이디.github.io/폴더 같은 주소나 클로드 공유 링크(claude.ai 아래 주소)는 내 사이트로 등록할 수 없어요. 확인 태그를 그 주소의 첫 페이지에 넣을 수 없기 때문이에요.

핵심주소 앞부분이 내 것인 사이트라면, 아래 3단계로 등록할 수 있어요. 등록은 무료예요.
STEP 01 시작 전에
1

내 주소부터 확인

  1. 네이버 검색창에 site:내주소를 넣어 검색해요(예: site:mystore.com). 결과가 0건이면 아직 네이버에 안 들어간 거예요.
  2. 내 주소에 / 뒤 폴더가 붙어 있는지 봐요. 붙어 있으면 1단계부터 해요.
  3. 이렇게 보이면 성공: 주소 앞부분(호스트)이 내 것이면 2단계로 바로 가도 돼요.
STEP 02 1단계
2

내 사이트만의 주소

  • 내 도메인(예: mystore.com)을 사서 연결하거나
  • 주소 앞부분이 내 이름인 호스팅을 써요(예: 깃허브 페이지는 아이디.github.io가 내 주소)
도메인 가격과 호스팅 연결 방법은 업체마다 달라요. 클로드에게 '지금 내 사이트 파일을 아이디.github.io 주소로 옮기는 순서 알려 줘'처럼 물어보면 단계별로 알려 줘요.
STEP 03 2단계
3

등록하고 확인 태그 붙이기

  1. 네이버 서치어드바이저(searchadvisor.naver.com)에 네이버 아이디로 들어가 웹마스터 도구를 열어요.
  2. 사이트 등록에 내 주소(호스트)를 넣어요.
  3. 소유 확인에서 HTML 태그 방식을 고르면 <meta name="naver-site-verification" content="…"> 한 줄을 줘요.
  4. 그 한 줄을 클로드에게 붙여 달라고 하고(아래 첫 번째 말), 바뀐 파일을 사이트에 다시 올린 뒤 확인을 눌러요.
  5. 이렇게 보이면 성공: 소유 확인이 끝나면 내 사이트가 목록에 떠요.
클로드에게: 확인 태그 넣기
내 사이트 index.html의 <head> 안에 이 태그를 그대로 넣어 줘. 다른 곳은 고치지 마.
<meta name="naver-site-verification" content="(네이버가 준 값)">
메뉴 이름은 가이드 기준이에요. 화면은 바뀔 수 있어요. HTML 파일 업로드 방식도 있어요.
STEP 04 3단계
4

로봇 허용과 사이트맵 내기

클로드에게: 사이트맵 만들기
내 사이트 주소는 https://mystore.com 이야. 지금 있는 페이지로 sitemap.xml을 만들어 줘. 주소는 모두 https:// 로 시작하는 전체 주소로 적어 줘.
클로드에게: robots.txt 만들기
내 사이트 맨 위 폴더에 둘 robots.txt를 만들어 줘. 모든 검색 로봇을 허용하고, 마지막 줄에 사이트맵 주소(https://mystore.com/sitemap.xml)를 적어 줘.
  1. 만든 파일 두 개를 사이트 맨 위 폴더에 올려요.
  2. 웹마스터 도구의 요청 → 사이트맵 제출에 사이트맵 주소를 넣어요.
  3. 이렇게 보이면 성공: 가이드 기준으로 검색 로봇이 다녀간 뒤 최대 1주일 안에 검색에 반영돼요. 그 뒤 site: 검색으로 다시 확인해요.
STEP 05 11월 20일에 해 본 것
5

실제 결과

네이버 웹문서 검색에 site:lalapert.github.io를 넣었더니 "검색결과가 없습니다"가 나왔어요. 이 정리 사이트 주소가 lalapert.github.io/ai-onepage처럼 폴더가 붙은 꼴이라, 이 주소 그대로는 등록할 수 없었어요.

사이트맵은 이 사이트의 실제 페이지 29개(첫 화면 + 가이드 28편)로 만들어 봤어요. 아직 robots.txt와 sitemap.xml이 없어서(둘 다 404) 이것부터 붙일 거예요.

STEP 06 주의
6

꼭 알아 둘 점

  • 등록해도 바로 뜨지 않아요. 가이드 기준 로봇이 다녀간 뒤 최대 1주일이 걸려요. 그 전에 결과가 없다고 다시 등록할 필요는 없어요.
  • 페이지에 <meta name="robots" content="noindex">가 있으면 검색에서 빠져요. 클로드에게 '내 사이트에 noindex가 있는지 찾아 줘'라고 물어보세요.
  • 사이트맵 주소는 https://로 시작하는 전체 주소로 써야 해요. 상대 주소나 다른 호스트 주소는 수집하지 않는다고 가이드에 적혀 있어요.
  • 확인 태그 값은 내 사이트 전용이에요. 다른 사람에게 보내거나 공개 글에 올리지 마세요.
  • 구글에도 나오게 하려면 Google Search Console에 따로 등록해야 해요(등록 방법은 비슷해요).
