STEP 00 설치와 0원 세팅을 대신
0

Claude Code에 바로 붙여 넣기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요(무료 플랜 미포함, 공식 문서 2026-11-06 확인). 무료 플랜이면 이 부분은 건너뛰고 아래 '따라 하기' 순서대로 따라 하세요.
  • 여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 작업할 빈 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.
  • Claude Code 설치: Windows PowerShell irm https://claude.ai/install.ps1 | iex · Mac curl -fsSL https://claude.ai/install.sh | bash
  • 데스크톱 앱: Windows / Mac
Claude Code에 붙여 넣기
MoneyPrinterTurbo(공식 저장소 github.com/harry0703/MoneyPrinterTurbo)로 세로 쇼츠를 만들어 보고 싶어. 한 단계씩 하고, 명령을 실행하기 전에 무엇을 하는지 먼저 말해 줘.
1. 내 컴퓨터의 파이썬 버전을 확인해 줘. 3.11 이상이 아니면 설치 방법만 알려 주고 멈춰.
2. 이 폴더에 가상환경(.venv)을 만들고 공식 패키지 mpt를 설치해 줘(python -m pip install mpt). PyPI에 있는 'MoneyPrinterTurbo'라는 이름의 패키지는 공식이 아니니까 설치하지 마.
3. mpt webui로 화면을 띄워 줘.
4. 돈 안 드는 설정을 알려 줘: 음성은 Edge TTS, 영상 소스는 Pixabay, 대본 AI는 Ollama. Ollama가 없으면 설치 방법과 내 PC 사양에 맞는 작은 모델을 추천해 줘.
5. API 키는 내가 화면에 직접 넣을게. 채팅에 키를 보내라고 하지 마.
6. 다 되면 만들어진 영상 파일 위치를 알려 줘.
7. 유료 API 키를 쓰거나 TikTok·Instagram·YouTube 자동 업로드를 켜는 설정은, 켜기 전에 나한테 먼저 물어봐.

공식 README에는 AI 에이전트에게 설치부터 영상 생성까지 맡기는 문장도 있어요. 아래 문장 다음 줄에 만들 주제를 적어요.

공식 README의 에이전트용 문장
Use this Skill: https://raw.githubusercontent.com/harry0703/MoneyPrinterTurbo/main/docs/skill/SKILL.md
이 방법은 에이전트가 설치와 실행을 알아서 하니, 실행 전에 무엇을 하는지 꼭 읽고 허락하세요.

STEP 02 먼저 이것만
2

이게 뭐예요?

  • 무엇: 주제나 키워드를 넣으면 대본, 영상 소스, 자막, 배경음악을 붙여 짧은 영상을 만들어 주는 무료 오픈소스 프로그램이에요. GitHub 별 14만 개가 넘어요(2026-11-07 기준, MIT 라이선스).
  • 얼마: 프로그램은 무료예요. Edge TTS(음성), Pixabay(영상 소스), Ollama(내 PC에서 도는 AI)를 쓰면 돈 안 들이고도 돌릴 수 있어요. ChatGPT·Claude 같은 클라우드 AI나 유료 음성·AI 영상 서비스를 고르면 그 서비스 요금이 나와요.
  • 누가: Windows는 압축을 풀고 실행하는 원클릭 파일이 있어요. Mac·Linux는 파이썬 3.11 이상으로 설치해요. 최소 사양은 CPU 4코어, 메모리 4GB이고 그래픽카드는 없어도 돼요.
  • 결과: 세로 9:16(1080×1920), 가로 16:9, 정사각 1:1로 뽑을 수 있어요. TikTok·Instagram·YouTube Shorts로 바로 올리는 기능도 있어요.
STEP 03 주의
3

꼭 알아 둘 점

  • 그대로 찍어낸 영상은 유튜브 수익이 안 나요. 유튜브는 같은 틀로 대량 생산한 영상, 사진만 넘기는 영상, 내 관점 없는 일반 템플릿 AI 영상을 '진정성 없는 콘텐츠'로 보고 수익 창출 대상에서 뺐어요. 내 목소리, 해설, 직접 찍은 화면을 넣으세요. 올릴 때 'AI 사용'은 '예'로 표시해요(공개해도 수익 자격에는 영향 없음).
  • Pexels는 지금 새 키를 안 줘요. Pexels API 공식 페이지에 '새 API 키 발급이 일시 중단'이라고 나와 있어요(2026-11-07 확인). 처음이면 Pixabay 키를 쓰세요. 가입하고 로그인하면 API 문서 페이지에 내 키가 보여요.
  • Pixabay 소스 규칙: 무료이고 출처 표기도 필요 없어요. 다만 손대지 않은 원본 그대로 되팔기, 상표·로고가 보이는 소스로 상품 광고하기, 알아볼 수 있는 사람을 나쁘게 쓰기, 속이는 용도는 금지예요.
  • Edge TTS 음성은 키 없이 무료지만, 수익용 영상에 써도 되는지 마이크로소프트가 밝힌 조건은 찾지 못했어요(확인 못 함). 수익 채널이면 내 목소리를 녹음하거나 상업 이용이 명시된 음성 서비스를 쓰는 게 안전해요.
  • 테스트할 때는 자동 업로드를 켜지 마세요. TikTok·Instagram·YouTube Shorts로 바로 올리는 기능이 있어요. 만든 영상을 직접 다 보기 전에는 연결하지 마세요. 한 번 올라간 영상은 되돌리기 어려워요.
  • 유료 키는 사용 한도부터 정하세요. 클라우드 AI·유료 음성·AI 영상 서비스 키를 넣기 전에, 그 서비스 대시보드에서 한 달 예산(사용 한도)을 먼저 걸어 두세요. 대량으로 돌리면 요금이 빠르게 쌓여요. 처음엔 0원 조합(Edge TTS·Pixabay·Ollama)으로 테스트하세요.
  • 공식 패키지 이름은 mpt예요. PyPI의 'MoneyPrinterTurbo' 패키지는 제3자가 올린 거예요.
  • README에 후원사 유료 서비스 링크가 많아요. AI 영상 생성, 모델 게이트웨이 등은 선택이에요. 0원 세팅에는 필요 없어요.
  • 인스타그램에 올릴 때도 AI로 만든 영상이면 'AI 정보' 표시를 켜세요.

STEP 05 처음 하는 사람용
5

따라 하기

Windows (원클릭)

  1. Releases 최신 버전 페이지에서 Assets를 펼치고 .7z 파일을 받아요. 'Source code (zip)'은 받지 마세요. 거기엔 start.bat이 없어요.
  2. 압축을 풀어요. 폴더 경로에 한글이나 띄어쓰기가 없는 곳(예: C:\mpt)이 안전해요.
  3. update.bat을 먼저 더블클릭해 최신 코드로 올려요.
  4. start.bat을 더블클릭하면 브라우저에 화면이 열려요. 하얀 화면만 보이면 크롬이나 엣지로 여세요.
  5. 기본 설정에서 영상 소스는 Pixabay를 고르고 내 키를 넣어요. 음성은 Edge TTS, 대본 AI는 Ollama(또는 쓰는 AI)를 골라요.
  6. 주제를 넣거나, 위 'AI에게 바로 맡기기'에서 만든 대본을 붙여 넣고 영상을 만들어요.

Mac · Linux · 파이썬으로 설치

  1. 빈 폴더에서 가상환경을 만들어요. Mac·Linux: python3 -m venv .venv → source .venv/bin/activate / Windows PowerShell: python -m venv .venv → .venv\Scripts\Activate.ps1
  2. python -m pip install mpt
  3. mpt webui를 입력하면 브라우저가 열려요.
  4. 만든 영상은 Windows %LOCALAPPDATA%\MoneyPrinterTurbo, Mac ~/Library/Application Support/MoneyPrinterTurbo 안의 storage/tasks 폴더에 있어요.
  5. 업데이트: python -m pip install --upgrade mpt
버튼 이름과 위치는 바뀔 수 있어요. 화면에 보이는 이름을 따라가세요.
STEP 06 막히면
6

안 될 때

  • start.bat이 없어요 · 먼저 확인: 받은 파일이 Source code(zip)인지 → Releases 페이지 Assets에서 .7z를 다시 받아요
  • 화면이 하얗게만 떠요 · 먼저 확인: 브라우저 → 크롬이나 엣지로 주소를 다시 열어요
  • pip 설치가 실패해요 · 먼저 확인: python --version → 3.11 이상으로 설치하고 가상환경을 다시 만들어요
  • 영상 소스를 못 가져와요 · 먼저 확인: 영상 소스 키 → Pexels 키가 없으면 Pixabay로 바꾸고 키를 다시 넣어요
  • 대본이 안 만들어져요 · 먼저 확인: 대본 AI 설정 → Ollama가 켜져 있는지, 모델을 받았는지 확인해요
  • 영상 파일을 못 찾겠어요 · 먼저 확인: 데이터 폴더 → '따라 하기'에 적힌 storage/tasks 폴더를 열어요
