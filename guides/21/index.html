STEP 00 먼저 이것만
0

이게 뭐예요?

  • 클로드에게 영상 한 편을 통째로 만들게 하는 도구예요. 대본, 그림, 음악, 목소리까지 클로드가 만들어요.
  • 영상 스타일이 99가지 있어요(11월 12일 기준). 수채화, 우키요에(일본 옛 판화), 네온 간판, 픽셀 게임 같은 것들이에요. 하나 고르고 한 문장만 쓰면 돼요.
  • 이런 도구를 플러그인이라고 불러요. 클로드에 끼워서 새 기능을 더하는 확장 기능이에요.
  • 플러그인은 무료예요. 대신 Claude 유료 플랜이 필요하고, 영상 한 편에 시간과 사용량이 꽤 들어요(7절).
STEP 01 시작 전에
1

준비물

준비물왜 필요해요?어디서 받아요?
Claude 유료 플랜(Pro 이상)이 플러그인은 Claude Code에서 돌아가요. Claude Code는 유료 플랜에서만 돼요.claude.ai에 로그인 → 설정에서 내 플랜 확인
Claude 데스크톱 앱Claude Code를 여는 가장 쉬운 방법이에요.claude.ai/download
Node 20 이상, ffmpeg 7 이상, Python 3.11 이상영상을 그리고 이어 붙이는 프로그램들이에요. 3절에서 클로드에게 확인과 설치를 맡겨요.직접 받을 필요 없어요
STEP 02 처음 한 번
2

Claude Code 열기

  1. claude.ai/download에서 내 컴퓨터(Windows 또는 Mac)에 맞는 앱을 받아요.
  2. 받은 파일을 열어 설치하고, 앱을 켜서 로그인해요.
  3. 앱 왼쪽 위에 있는 Code 탭을 눌러요.
  4. 폴더를 고르라는 창이 뜨면, 바탕화면에 새 폴더(예: my-film)를 하나 만들어서 골라요. 완성된 영상이 이 폴더에 생겨요.
  5. 이렇게 보이면 성공: 화면 아래에 글을 쓰는 칸이 생겨요.

터미널(까만 창에 글자로 명령을 치는 프로그램)을 쓸 줄 안다면 이렇게 해도 돼요.

  • Windows: PowerShell을 열고 irm https://claude.ai/install.ps1 | iex를 붙여 넣은 뒤 Enter
  • Mac: 터미널을 열고 curl -fsSL https://claude.ai/install.sh | bash를 붙여 넣은 뒤 Enter
  • 다 깔리면 claude라고 치고 Enter
STEP 03 붙여 넣기 한 번
3

플러그인 깔기

  1. Claude Code의 글 쓰는 칸에 아래 상자 안 글을 통째로 복사해서 붙여 넣어요.
  2. Enter를 눌러요.
  3. 클로드가 "이 명령을 실행해도 될까요?" 하고 물으면, 내용을 읽고 허락 버튼을 눌러요.
  4. 클로드가 설치가 끝났다고 말하면, 글 칸에 /effort high라고 치고 Enter를 눌러요. 설명서가 이 설정을 권해요. 클로드가 더 꼼꼼하게 일해요.
  5. 이렇게 보이면 성공: 글 칸에 빗금 /를 쳤을 때 뜨는 목록에 lemo-opuscar가 보여요.
1번에서 Claude Code에 붙여 넣기
https://github.com/lemomo-ai/lemo-opuscar
이 플러그인 설치해 줘.
먼저 내 컴퓨터에 Node 20 이상, ffmpeg 7 이상, Python 3.11 이상이 있는지 확인해 줘.
없거나 버전이 낮으면 무엇을 깔아야 하는지 쉬운 말로 알려 주고, 깔기 전에 나한테 먼저 물어봐.
다 되면 /lemo-opuscar:lemo-opuscar 가 되는지 확인해 줘.

목록에 안 보이면

  • 앱을 완전히 껐다가 다시 켜고, 다시 /를 쳐 봐요.
  • 그래도 없으면 글 칸에 "lemo-opuscar 플러그인이 설치됐는지 확인해 줘"라고 써요.
STEP 04 하나 고르기
4

스타일 고르기

  1. 스타일 갤러리를 열어요.
  2. 마음에 드는 그림을 눌러요. 그 스타일로 만든 짧은 데모 영상이 나와요.
  3. 스타일 영어 이름을 적어 둬요(예: Watercolor, Ukiyo-e, Neon Tubes, Pixel RPG, Red Paper-Cut, Stained Glass, Low-Poly Island).
STEP 05 한 문장
5

첫 영상 만들기

  1. 아래 상자 안 글을 복사해서, [ ] 안을 내 것으로 바꾼 뒤 붙여 넣어요.
  2. 클로드가 처음에 한 번 몇 가지를 물어봐요. 주제에서 정하기 어려운 것, 내 목소리나 음악 파일이 있는지 같은 것이에요. 답해 주면 돼요.
  3. 스토리보드가 나오면 보고 "좋아" 또는 고칠 점을 말해요.
  4. 30분~1시간 기다려요. 그동안 앱을 끄지 마세요.
  5. 이렇게 보이면 성공: 2절에서 고른 폴더에 영상 파일(.mp4), 자막 파일(.srt), 쓴 자료 목록(CREDITS)이 생겨요.
1번에서 붙여 넣기 ([ ] 채우기)
[스타일 영어 이름] 스타일로 [영상 주제] 이야기 30초 영상 만들어 줘.
인스타 릴스용으로 1080×1920 세로로 해 줘.
처음이니까 스토리보드(주요 장면 그림)를 먼저 보여 줘.

뭘 할지 모르겠으면: 글 칸에 /lemo-opuscar:lemo-opuscar만 쳐요. 어떤 말로 할지부터 물어보고, 순서대로 안내해 줘요.

STEP 06 선택
6

나만의 스타일 만들기

  1. 글 칸에 "I want to change the Ukiyo-e style into my own version."처럼 써요. 바꾸고 싶은 스타일 이름을 넣으면 돼요.
  2. 클로드가 브랜드 색, 글꼴, 캐릭터를 하나씩 물어봐요.
  3. 15~30초짜리 시험 영상이 나와요. 마음에 들면 "저장해 줘"라고 해요.
  4. 이렇게 보이면 성공: 다음에 스타일을 고를 때 내 스타일이 목록 맨 위에 나와요.
STEP 07 주의
7

꼭 알아 둘 점

  • 오래 걸리고 사용량이 많이 들어요. 영상 한 편에 30분~1시간이 걸려요. Claude 사용량(토큰: 클로드가 읽고 쓰는 글의 양)도 꽤 써요. 사용량 한도가 빠듯하면 짧은 영상부터 해 보세요.
  • 기본은 가로 영상이에요. 그냥 두면 1920×1080 가로로 나와요. 릴스·쇼츠용이면 "1080×1920 세로로"라고 꼭 말하세요.
  • 한국어 목소리는 기본으로 들어 있지 않아요. 기본 목소리 도구는 영어와 중국어만 안내돼 있어요. 한국어 내레이션은 내가 녹음한 파일을 주는 게 가장 확실해요. 클로드가 그 녹음을 그대로 쓰고 자막 시간을 맞춰요. 한국어 자동 목소리가 되는지는 직접 확인하지 못했어요.
  • 세 스타일은 그림 만드는 도구가 따로 필요해요. Manga Panels, Text Flash Cuts, Comic History Cartoon이에요. 나머지는 없어도 돼요.
  • 영상 만드는 AI는 쓰지 않아요. 장면을 코드로 한 장씩 그려서 이어 붙여요. 그래서 실제 사람이 찍은 것 같은 영상은 나오지 않아요.
  • 만든 영상은 내 것이에요. 상업용으로 써도 되고 출처를 안 밝혀도 돼요. 다만 영상에 넣은 남의 음악이나 사진은 그 자료의 규칙을 따라요. 스타일 설명서 자체를 묶어서 파는 건 안 돼요.
  • Claude에 맞춰 만든 도구예요. 다른 AI로 돌리면 스타일이 잘 안 나올 수 있다고 설명서에 적혀 있어요.
STEP 08 막히면
8

그래도 안 되면

  • 영상이 안 뽑히면 ffmpeg 버전부터 확인해요. 글 칸에 "ffmpeg 버전 확인해 줘"라고 써요. 6.x면 7 이상으로 바꿔야 해요. 클로드에게 "ffmpeg 7 이상으로 바꾸는 방법 알려 주고, 바꾸기 전에 물어봐"라고 하면 돼요.
  • 다른 오류는 아래 글을 복사해서 [ ]를 채운 뒤 붙여 넣어요.
Claude Code에 붙여 넣기 ([ ] 채우기)
lemo-opuscar로 [스타일 이름] 영상을 만들다가 이런 오류가 나왔어: [오류 문구 그대로]
내 컴퓨터는 [Windows / Mac]이야.
왜 그런지, 어떻게 고치는지 쉬운 말로 한 단계씩 알려 줘.
