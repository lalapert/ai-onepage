조문 찾기·인용 검사

법제처 원문을 찾아 조 번호까지 붙이고, 없는 조항은 걸러 내요

전세가 끝났는데 보증금을 안 준다고 물었더니, 클로드가 주택임대차보호법 제3조의3(임차권등기명령) 원문을 찾아 왔어요. 일부러 틀린 조항을 섞은 답을 넣었을 땐 없는 항 두 개를 바로 짚어 냈고요. 둘 다 11월 17일에 실제로 돌린 결과예요.

STEP 00 먼저 이것만
0

무엇이 달라져요?

그냥 물으면 클로드는 법제처 원문을 보지 않고 답해요. 그래서 답에 나온 조 번호와 항 번호가 진짜인지 대화 안에서는 확인할 길이 없어요.

korean-law-mcp를 연결하면 클로드가 법제처 국가법령정보센터에서 지금 시행 중인 조문 원문을 가져와 근거로 붙여요. 답이나 글에 나온 조항이 실제로 있는지 대조하는 인용 검사도 할 수 있어요.

핵심claude.ai는 주소 한 줄이면 연결돼요. 법제처 키가 없어도 시작할 수 있어요.
STEP 01 시작 전에
1

준비물

준비물왜 필요해요?어디서 받아요?
Claude 계정무료 요금제도 사용자 지정 커넥터를 1개까지 붙일 수 있어요(1개 제한은 무료 요금제에만 적혀 있어요).claude.ai
(선택) 법제처 Open API 인증키없으면 다 같이 쓰는 한도로 돌아가요. 자주 쓰면 내 키를 넣는 게 안정적이에요. 무료예요.open.law.go.kr 회원가입 → Open API 사용 신청
STEP 02 가장 쉬워요
2

claude.ai에 주소 한 줄로 연결

  1. claude.ai 왼쪽 아래 내 이름 → 설정(Customize) → 커넥터(Connectors)로 가요.
  2. + 추가 → 사용자 지정 커넥터 추가(Add custom connector)를 눌러요.
  3. 이름은 아무거나(예: korean-law), 주소는 https://mcp.gomdori.app/law를 넣어요. 키가 있으면 끝에 ?oc=내키를 붙여요.
  4. 추가한 뒤 커넥터 구성에서 도구를 항상 허용으로 두면 매번 승인하지 않아도 돼요(처음엔 승인 창을 보며 쓰는 것도 괜찮아요).
  5. 채팅창 왼쪽 아래 + → 커넥터에서 korean-law가 켜져 있는지 보고, 근로기준법 제60조 알려줘처럼 물어봐요.
  6. 이렇게 보이면 성공: 답에 '법령 검색', '조문 원문' 같은 도구를 쓴 표시가 뜨고, 조문 원문과 시행일이 같이 나와요.
주소와 단계는 korean-law-mcp 설명서와 Claude 도움말(11/17 확인) 그대로예요. 화면 이름은 앱 버전에 따라 조금 다를 수 있어요.
STEP 03 클로드 코드를 쓴다면
3

플러그인 두 줄로 연결

  1. 클로드 코드에서 /plugin marketplace add chrisryugj/korean-law-mcp
  2. 이어서 /plugin install korean-law@korean-law-marketplace
  3. 법제처 키를 물으면 넣거나 비워 두고 넘어가요(비우면 공용 한도).
  4. 이렇게 보이면 성공: 근로기준법 제74조 알려줘라고 했을 때 korean-law 도구가 불려요.
설명서에 따르면 이 플러그인은 내 컴퓨터에 프로그램을 깔지 않고 공개 서버(mcp.gomdori.app)에 연결해요. 설치 중 Permission denied (publickey)가 뜨면 설명서의 해결법을 따르세요.
STEP 04 이렇게 물어보세요
4

법 이름이나 상황을 구체적으로 넣고, 조 번호와 원문을 붙여 달라고 하면 정확해져요.

상황으로 조문 찾기 (클로드에 붙여 넣기, [ ] 채우기)
korean-law 커넥터로 찾아 줘.
상황: [전세 계약이 끝났는데 집주인이 보증금을 안 돌려줘요]
관련 법 조문을 찾아서 조 번호, 원문, 시행일을 붙이고 쉬운 말로 설명해 줘.
원문에서 확인 못 한 건 확인 못 했다고 말해 줘.

없는 조항이 있으면 몇 항까지 있는지도 알려 줘.

STEP 05 11월 17일에 돌려 본 것
5

실제 결과

조문 찾기: 주택임대차보호법 제3조의3(임차권등기명령)을 찾아 왔어요. ①항은 "임대차가 끝난 후 보증금이 반환되지 아니한 경우 … 임차권등기명령을 신청할 수 있다", ⑤항은 임차권등기를 마친 뒤에는 이사로 대항요건을 잃어도 "이미 취득한 대항력이나 우선변제권을 상실하지 아니한다"예요(시행 2026.1.2 기준).

인용 검사: 제가 일부러 틀린 조항 2개를 섞은 글을 넣었어요. 결과는 '법령 인용 4건, 실존 2, 오류 2'였어요.

  • ✓ 주택임대차보호법 제4조(임대차기간 등) 제2항: 실존
  • ✓ 주택임대차보호법 제3조의3(임차권등기명령): 실존
  • ✗ 제7조(차임 등의 증감청구권) 제3항: 없음(최대 제2항)
  • ✗ 제8조(보증금 중 일정액의 보호) 제4항: 없음(최대 제3항)
글에 법 이름을 빼고 '제7조 제3항'만 쓰면 오류가 아니라 '확인 필요'로 나왔어요. 검사할 때는 법 이름이 들어간 글을 넣으세요. 그리고 '할 일 5단계'처럼 넓게 물었을 때는 상관없는 판례(세금 사건)가 섞여 나왔어요. 법 이름을 넣어 물으면 정확해져요.
STEP 06 주의
6

꼭 알아 둘 점

  • korean-law-mcp는 Anthropic이 아닌 곳(개인 개발자, 구청 공무원)에서 공개한 도구예요. 커넥터 주소가 설명서(github.com/chrisryugj/korean-law-mcp)에 적힌 https://mcp.gomdori.app/law와 같은지 확인하고, 처음엔 개인정보가 없는 일반 질문으로 써 보세요.
  • 질문은 그 공개 서버를 거쳐요. 계약서 원문, 이름, 주소, 주민등록번호 같은 개인정보는 넣지 마세요. 서버를 거치기 싫으면 설명서의 '내 컴퓨터에 직접 설치' 방법이 있어요.
  • 법률 판단은 사람에게 확인하세요. 조문을 찾아 주는 도구지, 내 사건의 결론을 내려 주는 도구가 아니에요. 금전·소송 문제는 대한법률구조공단(☎132) 같은 전문 상담을 받으세요.
  • 법은 바뀌어요. 답에 나온 시행일을 보고, 중요한 건 국가법령정보센터 원문을 직접 확인하세요.
  • 키 없이 쓰면 모두가 함께 쓰는 한도라 붐빌 때 막힐 수 있어요. 자주 쓰면 내 키를 넣으세요.
  • 무료 요금제는 사용자 지정 커넥터가 1개까지예요. 다른 커넥터를 이미 쓰고 있으면 하나를 빼야 해요.
