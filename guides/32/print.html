코드 트리, 클로드 공식 스킬로 그리기

Anthropic 공식 예시 스킬 algorithmic-art: 빛으로만 그린 크리스마스 트리

요즘 자주 보이는 '코드 트리'는 코드가 그린 움직이는 그림이에요. 클로드에는 코드로 그림을 그리는 공식 스킬(algorithmic-art)이 있어서, 스킬을 켜고 한 줄만 쓰면 그림 규칙 → 코드 → 바로 보이는 화면까지 나와요. 숫자(시드)를 바꾸면 다른 트리, 문구 칸에 쓰면 글자가 바뀌어요.

무료 플랜도 스킬 켜기 · 11/22 도움말공식 스킬 anthropics/skills · Apache 2.0보내기 화면 녹화

STEP 00 · 먼저 이것만
0

이게 뭐예요?

스킬은 클로드에게 "이 일은 이렇게 해" 하고 미리 써 준 설명서예요. algorithmic-art는 Anthropic이 직접 만들어 공개한 예시 스킬로, 그림을 코드로 그려요.

  • ① 그림 규칙: 어떤 원리로 그릴지 글로 먼저 써요(예: 해바라기 씨처럼 137.5도씩 돌며 전구를 놓기)
  • ② 코드: 그 규칙 그대로 p5.js 코드를 짜요
  • ③ 화면: 바로 띄워 주고, 왼쪽 칸에서 시드·전구 수·문구를 바꿀 수 있어요
핵심같은 시드는 언제나 같은 트리를 그려요. 마음에 드는 번호를 적어 두면 다시 그대로 볼 수 있어요.
STEP 01 · 1단계
1

스킬 켜기 (처음 한 번)

  1. claude.ai(웹)나 Claude 데스크톱 앱에서 설정 › 기능을 열어요.
  2. 파일 만들기(영어 화면은 Create and edit files, 예전 이름은 Code execution and file creation)를 켜요.
  3. 맞춤 설정 › 스킬(Customize › Skills)로 가서 algorithmic-art를 켜요.
  4. 이렇게 보이면 성공: 스킬 목록에서 algorithmic-art 옆 스위치가 켜져 있으면 성공이에요.
핵심Claude 도움말에는 무료(Free), Pro, Max, Ultra 플랜 모두 예시 스킬을 켤 수 있다고 나와요(11/22 확인). 스킬 메뉴가 안 보이면 '파일 만들기'가 꺼져 있는 거예요.
STEP 02 · 2단계
2

한 줄로 그리기

새 대화를 열고 아래 글을 붙여 넣어요. [ ]만 내 것으로 바꿔요.

클로드에게: 트리 그리기복사해서 붙여 넣기
algorithmic-art 스킬로 빛나는 크리스마스 트리를 그려 줘.
밤하늘 배경, 전구가 반짝이고 천천히 돌아가게. 눈도 조금 내리게.
아래에 제목 [MERRY CHRISTMAS]와 문구 [올해도 고마웠어요]를 넣고, 둘 다 바꿀 수 있는 입력 칸도 만들어 줘.
세로 화면(4:5)으로 해 줘.
  1. 클로드가 먼저 그림 규칙 글을 쓰고, 이어서 코드를 짜요. 기다리면 오른쪽에 화면이 떠요.
  2. 왼쪽 Seed의 Next를 눌러 마음에 드는 트리를 골라요.
  3. 문구 칸에 보낼 말을 써요. 그림 아래 글자가 바로 바뀌어요.
  4. 이렇게 보이면 성공: 오른쪽 화면에서 트리가 돌고, 내가 쓴 문구가 아래에 보이면 성공이에요.
STEP 03 · 3단계
3

고치고 보내기

클로드에게: 고치기복사해서 붙여 넣기
트리를 [더 크게 / 금색 위주로 / 눈을 더 많이] 바꿔 줘.
문구 글꼴은 [손글씨 느낌]으로 해 줘.
  1. 마음에 들면 화면을 크게 열고, 휴대폰 화면 녹화로 10초쯤 찍어요.
  2. 찍은 영상을 카톡이나 DM으로 보내요.
핵심Pro 이상이면 화면 위 '공유'에서 '링크가 있는 사람 누구나'를 골라 링크로 보낼 수도 있어요. 무료 플랜은 링크 공유가 안 돼요(11/22 도움말 기준).
STEP 04 · Claude Code를 쓴다면
4

클로드 코드에서 쓰기

Claude Code(유료 플랜)에서는 공식 저장소를 플러그인으로 깔아요. 깃허브 README에 나온 명령 그대로예요.

Claude Code에 입력복사해서 붙여 넣기
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills

깔고 나서 "algorithmic-art 스킬로 크리스마스 트리 그려 줘"라고 하면 HTML 파일로 만들어 줘요. 브라우저로 열면 돼요.

STEP 05 · 주의
5

꼭 알아 둘 점

  • Anthropic이 만든 공식 예시 스킬이에요. 다만 저장소 설명에 '보여 주기·배우기 용도'라고 적혀 있어요. 결과는 대화마다 조금씩 달라요.
  • 캐럴 음악은 넣지 마세요. 녹화 영상에 유명한 노래를 깔면 저작권 문제가 생길 수 있어요.
  • 스킬 메뉴가 안 보이면 설정 › 기능의 '파일 만들기'부터 켜요. 회사(Team·Enterprise) 계정은 관리자가 막아 두었을 수 있어요.
  • 파일 만들기는 사용량을 평소보다 많이 써요(도움말 기준). 무료 플랜은 몇 번 고치면 한도에 닿을 수 있어요.
  • 영상 속 트리·그림 규칙·코드·뷰어는 11/22에 이 스킬 방식대로 실제로 만든 결과예요. 설정 화면은 설명용 그림이에요.
