구글 Gemma 4를 내 컴퓨터에서 공짜로: Ollama 설치와 사용법

구글 딥마인드의 오픈 모델을 Ollama로 돌리기

Gemma 4(젬마 4)는 구글 딥마인드가 만든 오픈 모델이에요. Ollama에 ollama run gemma4 한 줄을 넣으면 내 컴퓨터에서 돌아가요. 글과 사진을 넣으면 글로 답해서, 영수증·표 사진도 읽게 할 수 있어요.

무료 내 컴퓨터에서 실행한 줄 ollama run gemma4사진 영수증·표 읽기

STEP 00 · 먼저 이것만
0

이게 뭐예요?

  • 무엇: 구글 딥마인드가 만든 오픈 모델 Gemma 4(젬마 4)를 Ollama로 내 컴퓨터에서 돌려요. 글과 사진을 넣으면 글로 답해요.
  • 누구에게: ChatGPT 같은 AI를 사용료 없이, 내 파일을 인터넷에 올리지 않고 쓰고 싶은 사람.
  • 가격: 내 컴퓨터에서 돌리면 무료예요. 이름에 cloud가 붙은 모델만 Ollama 클라우드에서 돌아가요('꼭 알아 둘 점' 참고).
  • 인기: Ollama에서 2,880만 번 내려받았어요(11/9, Ollama 다운로드 수. 사용자 수가 아니에요).
이 가이드를 쓰면서 직접 돌려 보지는 않았어요. 속도와 답의 질은 컴퓨터 사양과 모델 크기에 따라 달라요.
STEP 01 · Ollama가 있으면
1

바로 따라 하기

Ollama가 없으면 먼저 허브 7번 'OpenAI 모델을 내 컴퓨터에서 무료로: Ollama 설치 가이드' 가이드로 설치하세요. PowerShell(Windows)이나 터미널(Mac)에 아래 한 줄을 넣어요.

PowerShell·터미널에 넣기복사해서 붙여 넣기
ollama run gemma4
  • 처음 한 번 모델을 내려받아요. 기본(gemma4)은 e4b 모델이고 6.6GB부터예요.
  • >>> 표시가 나오면 한국어로 물어보면 돼요. 끝낼 때는 /bye.

노트북이나 메모리가 적은 컴퓨터는 제일 작은 모델부터 받으세요.

메모리가 적으면 이것부터복사해서 붙여 넣기
ollama run gemma4:e2b
STEP 02 · 주의
2

꼭 알아 둘 점

  • 이름에 cloud가 붙은 모델은 내 컴퓨터에서 돌지 않아요. gemma4:cloud, gemma4:31b-cloud는 Ollama 클라우드에서 돌아가요. Ollama 클라우드는 무료 범위 없이 쓴 만큼 내는 방식이에요(11/9 확인). 무료로 쓰려면 cloud가 없는 이름을 고르세요.
  • 모델 크기만큼 디스크를 써요. 아래 '어떤 모델을 고를까'를 보고 여유 공간을 먼저 확인하세요.
  • 메모리가 부족하면 느리거나 안 돌아가요. 구글 문서 기준으로 4비트 모델을 올리는 데 E2B 약 2.9GB, E4B 약 4.5GB 메모리가 들어요. 대화가 길어지면 더 들어요. 느리면 허브 13번 '올라마가 느릴 때: 원인 찾기와 빨라지는 3가지' 가이드를 보세요.
  • 답이 틀릴 수 있어요. 작은 모델일수록 더 그래요. 영수증 금액, 날짜 같은 숫자는 원본과 꼭 맞춰 보세요.
  • 사진은 질문보다 먼저 넣으세요. Ollama 모델 설명에 있는 권장 순서예요.
  • 상업적으로 쓸 거면 Gemma 이용 약관을 직접 확인하세요. 구글 문서는 '책임 있는 상업적 사용'을 허용한다고 써요.
STEP 03 · 크기 고르기
3

어떤 모델을 고를까

ollama.com 11/9 기준이에요. 이름 · 내려받는 용량 · 대화 길이 · 설명 순서로 적었어요.

  • gemma4:e2b · 4.6GB~7.5GB · 128K · 가장 작음. 노트북·휴대기기용으로 만든 모델
  • gemma4:e4b (기본) · 6.6GB~9.5GB · 128K · ollama run gemma4 하면 이것
  • gemma4:12b · 7.7GB~8.0GB · 256K · 작업용 컴퓨터용
  • gemma4:26b · 16GB~19GB · 256K · 작업용. 여러 전문가 중 일부만 쓰는 구조(MoE)
  • gemma4:31b · 19GB~20GB · 256K · 가장 큼
모든 모델이 글과 사진을 받아요(Ollama 표기: Text, Image). 용량에 범위가 있는 건 컴퓨터 종류(예: Mac용 MLX)에 따라 받는 파일이 달라서예요(추정).
STEP 04 · 처음 하는 분
4

설치 확인하고 모델 받기

1) Ollama 설치 확인

  • PowerShell이나 터미널에 ollama --version을 넣어요. 버전 숫자가 나오면 설치된 거예요.
  • 안 나오면 허브 7번 'OpenAI 모델을 내 컴퓨터에서 무료로: Ollama 설치 가이드' 가이드로 설치해요.
  • 오래전에 설치했다면 새 모델이 안 받아질 수 있어요. Ollama를 최신으로 업데이트하세요(추정).

2) 모델 받고 대화하기

PowerShell·터미널에 넣기복사해서 붙여 넣기
ollama run gemma4:e2b
  • 받은 모델 보기: ollama list
  • 지우기: ollama rm gemma4:e2b
STEP 05 · 영수증, 표
5

사진 읽히기

  • Ollama 앱(Windows·Mac): 대화창에 사진을 끌어다 놓고 아래 문장을 보내요.
  • 터미널: 질문 맨 앞에 사진 파일 경로를 넣어요. 파일 이름은 영어로, 띄어쓰기 없이 두는 게 안전해요(추정).
터미널에서 넣는 예복사해서 붙여 넣기
ollama run gemma4:e2b "./receipt.jpg 이 영수증을 표로 정리해 줘"
바로 쓰는 문장복사해서 붙여 넣기
이 사진 속 영수증을 표로 정리해 줘.
- 칸: 날짜 | 가게 | 품목 | 수량 | 금액
- 사진에서 안 보이는 칸은 비워 두고 [확인 필요]라고 써 줘
- 마지막 줄에 합계를 쓰고, 영수증에 적힌 합계와 다르면 알려 줘
STEP 06 · 정리
6

다 쓰고 나서

  • 모델은 마지막으로 쓴 뒤 기본 5분 동안 메모리에 남아요(Ollama FAQ).
  • 바로 내리려면 ollama stop gemma4:e2b.
STEP 07 · 막히면
7

안 될 때

  • ollama를 찾을 수 없음 · 설치했는지 → Ollama 설치 가이드(허브 7번) → PowerShell·터미널 다시 열기
  • 받다가 멈춤, 디스크 부족 · 디스크 여유 공간 → 더 작은 모델(e2b)로 → 모델 저장 위치를 다른 드라이브로(환경 변수 OLLAMA_MODELS)
  • 답이 너무 느림 · ollama ps의 PROCESSOR 칸 → 올라마가 느릴 때 가이드(허브 13번)
  • 사진을 못 읽음 · 파일 경로, 이름의 띄어쓰기 → 영어 이름으로 바꾸고 경로를 질문 맨 앞에
  • cloud가 붙은 모델이 돌아감 · ollama list의 이름 → cloud 없는 이름으로 다시 받기
오류 상담용 문장 ([ ] 채우기)복사해서 붙여 넣기
Ollama로 gemma4를 쓰는데 [증상/오류 문구 그대로]가 나와. 운영체제는 [ ], 메모리는 [ ]GB, 그래픽카드는 [있음/없음]이야. 원인과 고치는 순서를 쉬운 말로 알려 줘.

8

다음에 해 볼 것

  • 같은 질문을 e2b와 e4b에 해 보고 답과 속도 비교하기
  • 사진 대신 화면 캡처(표, 그래프)를 넣고 요약시키기
  • Ollama 모델 페이지에는 Claude Code와 잇는 명령(ollama launch claude --model gemma4)도 있어요. 사양 조건을 아직 확인 중이라 이 가이드에서는 다루지 않았어요.
