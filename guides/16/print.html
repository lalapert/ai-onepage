맞장구만 치던 클로드가 아이디어 심사: roast 스킬 설치와 사용법

다섯 자리로 나눠 공격하고, 판사가 판정해요

roast는 클로드를 다섯 자리로 나눠 같은 아이디어를 따로 공격하게 하고, 마지막에 판사가 GO·RESHAPE·KILL로 판정하는 무료 스킬이에요. 판정 뒤에는 48시간 안에 해 볼 가장 싼 시험까지 짜 줘요.

STEP 00 · 먼저 이것만
0

이게 뭐예요?

  • 무엇: 클로드를 다섯 자리로 나눠 같은 아이디어를 따로 공격하게 하고, 마지막에 판사가 하나로 판정해요.
  • 판정: GO(진행) · RESHAPE(고쳐서 다시) · KILL(접기). 판정 뒤에 48시간 안에 해 볼 가장 싼 시험까지 짜 줘요.
  • 누구에게: 사업 아이디어, 부업, 새 상품을 만들기 전에 냉정한 의견이 필요한 사람.
  • 가격: 스킬은 무료(MIT)예요. claude-skills(GitHub 별 2.9만+, 스킬 400개 넘는 모음)에 들어 있어요.

다섯 자리 (묻는 질문 · 웹 검색)

  • 비평가 (Critic) · 무엇이 이걸 죽이나 · 안 함
  • 지지자 (Champion) · 잘되면 얼마나 커지나 · 안 함
  • 분석가 (Analyst) · 논리가 정말 맞나 · 쓰지 않게 막아 둠
  • 조사관 (Investigator) · 실제 시장은 뭐라고 하나(근거, 경쟁자) · 꼭 함
  • 고객 (Customer) · 내가 진짜 돈을 낼까 · 안 함
핵심판사는 점수를 평균 내지 않아요. 고객과 비평가에 가장 무게를 두고, 지지자는 가장 가볍게 봐요. 살 사람이 없거나, 치명적인 약점이 드러나거나, 논리가 깨지면 GO를 주지 않아요(README).
Anthropic 공식 기능이 아니라 개발자가 공개한 무료 스킬이에요. 판정은 참고용이고, 결정은 내가 해요.
STEP 01 · Pro 이상이면
1

Claude Code에 바로 넣기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요. 무료 플랜이면 아래 'claude.ai 웹에서 쓰기'로 가세요.

여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 작업할 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.

Claude Code 입력창에 한 줄씩 넣어요.

Claude Code 입력창에 넣기복사해서 붙여 넣기
/plugin marketplace add alirezarezvani/claude-skills
/plugin install roast@claude-code-skills

2

심사 맡기는 문장

클로드에 붙여 넣기 ([ ] 채우기)복사해서 붙여 넣기
roast this idea: [내 아이디어 한두 문장]

결과는 한국어로 정리해 줘. 다섯 명의 의견을 한 줄씩, 판정(GO/RESHAPE/KILL)과 이유, 48시간 안에 해 볼 가장 싼 시험을 표로 보여 줘.

Claude Code에서는 /cs-roast로도 시작할 수 있어요.

STEP 03 · 주의
3

꼭 알아 둘 점

  • 공식 기능이 아니에요. 개발자가 GitHub에 공개한 스킬이에요.
  • 판정은 참고용이에요. 시장 크기 같은 숫자는 조사관이 찾은 출처를 직접 열어 확인하세요.
  • 보안 검사에서 경고가 1개 있어요. skills.sh 보안 검사에서 Snyk가 '중간' 경고(W011)를 냈어요. 다른 두 검사(Gen Agent Trust Hub, Socket)는 통과했어요. 경고 내용: 조사관이 웹에서 가져온 글에 AI를 속이는 문장이 섞여 있으면, 클로드가 그걸 지시로 받아들일 위험이 있어요(간접 프롬프트 주입).
  • 그래서 아이디어 설명에 회사 비밀, 고객 개인정보, 비밀번호를 넣지 마세요. 결과에 '이 링크를 열어', '이 명령을 실행해' 같은 말이 나오면 따르지 마세요.
  • claude.ai 웹에서는 다섯 명이 동시에 돌지 않고 차례로 돌 수 있어요(추정). Claude Code에서는 다섯 명을 하위 에이전트로 동시에 돌려요(README).
  • 웹 검색이 꺼져 있으면 조사관이 시장 근거를 못 찾아요.
  • 한 번 심사에 답을 여러 번 만드는 셈이라 사용량을 빨리 써요(추정).

STEP 05 · Pro 이상
5

Claude Code에서 쓰기

  1. Claude Code를 열어요(위 'Claude Code에 바로 넣기'의 여는 법).
  2. 그 두 줄을 한 줄씩 넣어요. 첫 줄은 스킬 모음을 등록하고, 둘째 줄은 roast만 설치해요.
  3. '심사 맡기는 문장'을 보내요. 목록에 roast가 안 보이면 Claude Code를 껐다 켜 보세요.
STEP 06 · 무료 플랜도 됨
6

claude.ai 웹에서 쓰기

  1. claude.ai 설정에서 코드 실행 기능을 켜요. 스킬은 코드 실행이 켜져 있어야 돌아가요(도움말).
  2. claude-skills GitHub 페이지에서 초록색 Code → Download ZIP으로 전체를 받고 압축을 풀어요.
  3. 풀린 폴더에서 productivity/roast/skills/roast 폴더를 찾아요. 안에 SKILL.md가 있어요.
  4. 그 roast 폴더 하나만 다시 ZIP으로 압축해요. Windows는 폴더 오른쪽 클릭 → 압축(ZIP), Mac은 오른쪽 클릭 → 압축.
  5. claude.ai 왼쪽 메뉴 Customize → Skills에서 ZIP을 올리고 켜요.
  6. 새 채팅에서 웹 검색을 켜고 '심사 맡기는 문장'을 보내요.
STEP 07 · 판정 뒤에
7

결과 읽는 법

  • 판정만 보지 말고 고객과 비평가 자리를 먼저 읽어요. 판사도 이 둘에 가장 무게를 둬요.
  • 48시간 시험을 실제로 해 본 뒤, 결과를 같은 채팅에 붙여 넣고 다시 심사받아요.
STEP 08 · 막히면
8

안 될 때

  • /plugin 명령이 안 됨 · Claude Code인지(웹 채팅이 아닌지) → Claude Code에서 다시. 웹이면 'claude.ai 웹에서 쓰기'
  • install에서 roast를 못 찾음 · 첫 줄(marketplace add)을 먼저 했는지 → 첫 줄부터 다시
  • 웹에서 ZIP 업로드 실패 · ZIP 맨 위에 roast 폴더와 SKILL.md가 있는지 → roast 폴더 하나만 다시 압축
  • 스킬이 안 불림 · 코드 실행, 스킬 켜짐 → 설정 확인 → 'roast this idea:'로 시작
  • 조사관이 근거를 못 찾음 · 웹 검색이 켜졌는지 → 켜고 다시
오류 상담용 문장 ([ ] 채우기)복사해서 붙여 넣기
roast 스킬을 쓰는데 [증상/오류 문구 그대로]가 나와. 쓰는 곳은 [Claude Code/claude.ai 웹], 플랜은 [무료/Pro]야. 원인과 고치는 순서를 쉬운 말로 알려 줘.
