클로드로 만든 영상에 효과음 252개: earshot 설치와 사용법

AI 코딩 도구에 '귀'를 달아 주는 무료 오픈소스

코드로 만든 효과음 252개(휙, 쿵, 딸깍, 톡 등)를 영상 컷에 맞춰 넣어요. 소리와 화면이 맞는지는 AI가 직접 듣고 확인해요. earshot을 Claude Code에 연결해서 쓰는 법을 정리했어요.

STEP 00 · 먼저 이것만
0

이게 뭐예요?

  • 무엇: AI 코딩 도구에 '귀'를 달아 주는 무료 오픈소스예요. 코드로 만든 효과음 252개(휙, 쿵, 딸깍, 톡 등)를 영상 컷에 맞춰 넣고, 소리와 화면이 맞는지 AI가 직접 듣고 확인해요.
  • 누구에게: Claude Code로 영상(제품 소개, 짧은 영상, 게임 화면)을 만드는 사람.
  • 필요한 것: Claude Code(Pro 이상 유료), uv, ffmpeg. 그래픽카드는 필요 없어요. CPU만 써요(README).
  • 무료 범위: earshot 자체는 무료예요(MIT). 효과음 만들기(sfx, kit)는 모델도 인터넷도 필요 없어요. 듣고 평가하는 기능(describe, timeline 등)은 처음 한 번 모델 약 1.1GB를 받아요.
핵심효과음은 코드로 만들고, 맞는지는 AI가 들어서 확인해요. 마지막 확인은 내 귀로 해요.
STEP 01 · Pro 이상이면
1

Claude Code에 설치와 연결 맡기기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요(무료 플랜 미포함, 공식 문서 2026년 11월 6일 확인). 무료 플랜이면 이 단계는 건너뛰고 아래 'uv와 ffmpeg 깔기'부터 순서대로 따라 하세요. 다만 earshot을 AI가 직접 쓰게 하는 연결(MCP)은 Claude Code 같은 코딩 도구가 있어야 해요.

여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 작업할 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.

  • Claude Code 설치(Windows PowerShell): irm https://claude.ai/install.ps1 | iex
  • Claude Code 설치(Mac): curl -fsSL https://claude.ai/install.sh | bash
Claude Code에 붙여 넣기복사해서 붙여 넣기
earshot(https://github.com/Leonxlnx/earshot)을 설치하고 Claude Code에 연결해 줘. 한 단계씩 하고, 명령을 실행하기 전에 무엇을 하는지 먼저 말해 줘.
1. 내 운영체제를 확인하고 uv, ffmpeg, ffprobe가 설치돼 있는지 확인해 줘. 없으면 공식 설치 방법을 알려 주고, 설치하기 전에 나에게 물어봐.
2. uv tool install "earshot[mcp] @ git+https://github.com/Leonxlnx/earshot" 로 earshot을 설치해 줘.
3. earshot doctor 로 설치 상태를 확인해 줘. 듣기 모델(약 1.1GB)은 내려받기 전에 나에게 물어봐.
4. claude mcp add earshot --scope user -e EARSHOT_THREADS=3 -- earshot mcp 로 Claude Code에 연결하고, 연결됐는지 확인해 줘.
5. 시험으로 earshot sfx list --kind whoosh 를 실행해서 쓸 수 있는 '휙' 소리 목록을 보여 줘.
6. earshot sfx render whoosh_fast/crisp -o test_whoosh.wav --dur 0.8 로 소리 하나를 만들고, 파일이 생겼는지 확인해 줘.
7. Gemini 기능(llm)은 쓰지 마. API 키를 파일에 적으라고 하지 마.
STEP 02 · 설치가 끝나면
2

영상에 효과음 넣기를 맡기는 문장

설치와 연결이 끝난 뒤, 효과음을 넣을 영상이 있는 폴더에서 Claude Code에 붙여 넣으세요.

Claude Code에 붙여 넣기 ([ ] 채우기)복사해서 붙여 넣기
이 영상 [내 영상.mp4] 에 효과음을 넣어 줘. earshot을 써.
1. 먼저 영상을 보고 장면이 바뀌는 순간(컷)과 글자가 나타나는 순간을 시간 순서로 표로 정리해 줘.
2. earshot kit init 으로 키트를 만들어 줘. 배경 음악이 있으면 launch, 없으면 calm 프리셋을 써.
3. 컷에는 휙(whoosh), 글자가 뜰 때는 톡(ui_pop), 강조할 때는 쿵(cut_hit)을 넣어 줘. 같은 소리가 너무 촘촘하게 붙지 않게 해 줘.
4. 넣은 뒤 earshot timeline 으로 소리와 화면 컷이 맞는지 확인하고, 어긋난 곳은 고쳐 줘.
5. 원본 영상은 덮어쓰지 말고 [내 영상]_sfx.mp4 로 새로 저장해 줘.
6. 마지막에 어떤 시간에 어떤 소리를 넣었는지 표로 보여 줘.
STEP 03 · 주의
3

꼭 알아 둘 점

  • Claude Code가 유료예요. earshot은 무료지만, AI가 직접 쓰게 하려면 Claude Code 같은 코딩 도구가 필요해요.
  • 듣기 모델이 약 1.1GB예요. 명령을 한 번씩 따로 실행하면 매번 모델을 불러오느라 20~40초가 걸려요. MCP로 연결해 두면 한 번 불러온 뒤 계속 켜져 있어요(README).
  • 취향은 판단하지 못해요. README에 따르면 소리의 느낌, 감정, 라이선스, 말소리 내용은 판단하지 못하고, 14kHz 이상은 듣지 못해요. 마지막 확인은 내 귀로 하세요.
  • 효과음 은행(bank)은 코드로 만든 소리예요. 함께 들어 있는 real-sound 스킬은 실제 녹음을 찾아 쓰는 방식이에요. 그 녹음마다 라이선스를 따로 확인해야 해요. 상업용으로 쓰기 전에 LICENSE와 docs/CREDITS_FIT.md를 직접 확인하세요. 우리는 코드가 MIT라는 것까지만 확인했어요.
  • Gemini 기능(llm)은 선택이에요. 내 Gemini API 키가 필요하고, 키를 파일에 직접 적지 말라고 README에 쓰여 있어요.
  • Windows에서는 직접 해 보지 않았어요. 설치가 막히면 아래 '안 될 때'를 보세요.
  • 느린 컴퓨터에서는 MCP 연결이 시간 초과로 끊길 수 있어요. README는 MCP_TIMEOUT=60000으로 Claude Code를 켜라고 안내해요.

STEP 05 · 처음 하는 분
5

uv와 ffmpeg 깔기

1) uv 설치

  • Windows: PowerShell을 열고 powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  • Mac: 터미널을 열고 curl -LsSf https://astral.sh/uv/install.sh | sh
  • 설치가 끝나면 PowerShell이나 터미널을 껐다 켜고 uv --version을 입력해요. 버전 숫자가 나오면 정상이에요.

2) ffmpeg 설치

  • Windows: ffmpeg.org/download.html → Windows EXE Files에 있는 빌드 사이트에서 받아요. 압축을 푼 뒤 bin 폴더를 PATH에 넣어야 해요. 어려우면 위 'Claude Code에 설치와 연결 맡기기'의 문장으로 Claude Code에 맡기세요.
  • Mac: Homebrew가 있으면 brew install ffmpeg
  • 확인: ffmpeg -version, ffprobe -version이 둘 다 버전을 보여 주면 정상이에요.
STEP 06 · 설치
6

earshot 설치하고 Claude Code에 연결

1) earshot 설치

PowerShell·터미널에 넣기복사해서 붙여 넣기
uv tool install "earshot[mcp] @ git+https://github.com/Leonxlnx/earshot"
earshot doctor
  • earshot doctor가 설치 상태를 보여 줘요.
  • 듣기 기능까지 쓰려면 earshot doctor --fetch로 모델 약 1.1GB를 미리 받아요.

2) Claude Code에 연결 (MCP)

PowerShell·터미널에 넣기복사해서 붙여 넣기
claude mcp add earshot --scope user -e EARSHOT_THREADS=3 -- earshot mcp

연결한 뒤 Claude Code를 새로 열고 earshot 도구가 보이는지 확인해 줘라고 물어봐요.

첫 효과음 만들어 보기

PowerShell·터미널에 넣기복사해서 붙여 넣기
earshot sfx list --kind whoosh
earshot sfx render whoosh_fast/crisp -o w.wav --dur 0.8 --apex 0.32
earshot sfx check w.wav
  • --dur는 길이(초), --apex는 가장 큰 순간(초)이에요.
  • sfx check는 튀는 소리, 잘린 꼬리, 클리핑이 있는지 검사해요.

안 될 때

  • earshot을 찾을 수 없음 · uv 설치 뒤 터미널을 다시 열었는지 → 터미널 재시작 → uv tool list에 earshot이 있는지 확인
  • ffmpeg 오류 · ffmpeg -version이 되는지 → 'uv와 ffmpeg 깔기' 다시, Windows는 PATH 확인
  • 모델 받다가 멈춤 · 디스크 여유, 인터넷 → earshot doctor --fetch 다시 실행
  • Claude Code에 도구가 안 보임 · claude mcp list에 earshot이 있는지 → 연결 명령 다시 → Claude Code 새로 열기 → 느리면 MCP_TIMEOUT=60000
  • 소리가 영상과 안 맞음 · timeline 확인을 했는지 → earshot timeline으로 다시 확인하고 고쳐 줘
