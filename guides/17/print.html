클로드가 브라우저를 대신 클릭: agent-browser 설치와 사용법

Vercel이 만든 무료 오픈소스 브라우저 도구

agent-browser는 AI가 웹페이지를 열고(open), 화면을 읽어 버튼마다 번호를 붙이고(snapshot), 그 번호로 누르는(click) 도구예요. 같은 사이트에서 같은 클릭을 매일 반복하는 사람에게 맞아요.

STEP 00 · 먼저 이것만
0

이게 뭐예요?

  • 무엇: AI가 웹페이지를 열고(open), 화면을 읽어 버튼마다 번호를 붙이고(snapshot), 그 번호로 누르는(click) 도구예요.
  • 누구에게: 같은 사이트에서 같은 클릭을 매일 반복하는 사람(가격 확인, 표 정리 등).
  • 가격: 도구는 무료예요(Apache-2.0, GitHub 별 4.8만, 11/9). Claude Code는 Pro 이상 유료 플랜이 필요해요.
README 기준으로 썼고 직접 돌려 보지는 않았어요.
STEP 01 · PowerShell·터미널
1

설치

PowerShell·터미널에 넣기복사해서 붙여 넣기
npm install -g agent-browser
agent-browser install
  • 두 번째 줄은 처음 한 번 테스트용 크롬(Chrome for Testing)을 받아요.
  • Mac은 brew install agent-browser 뒤 agent-browser install도 돼요.
  • 클로드에 붙이기(스킬): npx skills add vercel-labs/agent-browser
STEP 02 · 말로 시키기
2

Claude Code에 붙여 넣는 문장

Claude Code에 붙여 넣기 ([ ] 채우기)복사해서 붙여 넣기
agent-browser를 써서 [사이트 주소]에서 [할 일]을 해 줘.
- 페이지를 열 때마다 snapshot -i로 화면을 먼저 읽고, 번호(@e1 등)로 눌러.
- 로그인, 결제, 개인정보 입력이 필요하면 멈추고 나한테 물어봐.
- 끝나면 단계마다 무엇을 했는지 표로 보여 줘.
STEP 03 · 주의
3

꼭 알아 둘 점

  • agent-browser는 Anthropic이 아닌 곳(vercel-labs)에서 공개한 도구예요. 깔면 클로드가 내 컴퓨터에서 브라우저를 직접 움직여요. 설치 이름이 vercel-labs/agent-browser가 맞는지 확인하고, 처음엔 로그인이 필요 없는 사이트에서 써 보세요.
  • 로그인·결제는 맡기지 마세요. 비밀번호와 카드 정보는 AI에게 주지 않는 게 안전해요.
  • 사이트 이용 약관을 먼저 확인하세요. 자동 접속을 막는 사이트도 있어요.
  • 페이지가 바뀌면 예전 번호는 못 써요. snapshot -i를 다시 해야 해요(README).
  • 쿠키 배너가 버튼을 가리면 클릭이 실패로 나와요. 배너를 닫고 다시 snapshot 해요(README).
STEP 04 · 명령어로
4

직접 해 보기

PowerShell·터미널에 한 줄씩 넣기복사해서 붙여 넣기
agent-browser open example.com
agent-browser snapshot -i
agent-browser click @e1
agent-browser get url
agent-browser close
STEP 05 · 막히면
5

안 될 때

  • agent-browser를 찾을 수 없음 → Node.js(npm)가 깔려 있는지, 터미널을 다시 열었는지 확인해요.
  • 클릭이 안 됨 → 배너를 닫고 snapshot -i를 다시 해요.
오류 상담 문장 ([ ] 채우기)복사해서 붙여 넣기
