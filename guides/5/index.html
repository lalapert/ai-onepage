STEP 01 AI에게 맡기기

AI에게 바로 맡기기

가리기(Redact)용 패턴 만들기: ChatGPT · Claude · Grok에 붙여 넣으세요.

ChatGPT · Claude · Grok에 붙여 넣기 ([ ] 채우기)
Stirling PDF의 자동 가리기(Automatic Redaction)에서 'Use Regex'로 쓸 정규식을 만들어 줘.
지울 정보: [주민등록번호 / 휴대폰 번호 / 계좌번호 / 이메일]
문서에 실제로 적힌 모양 예시(가짜 값으로): [000000-0000000]
조건:
1. 정보마다 정규식 1개와, 무엇을 잡고 무엇을 못 잡는지 한 줄 설명.
2. 너무 넓게 잡아서 다른 숫자까지 지우지 않게 해 줘.
3. 테스트용 가짜 예시 3개와, 잡히면 안 되는 예시 2개도 같이 줘.

참고용 시작 패턴 (실제 문서로 꼭 테스트하세요)

  • 주민등록번호: \d{6}-?[1-4]\d{6}
  • 휴대폰 번호: 01[016789]-?\d{3,4}-?\d{4}
  • 이메일 (공식 문서 예시): [\w.-]+@[\w.-]+\.\w+
STEP 02 먼저 이것만
2

한눈에 보기

  • 무엇: Stirling PDF는 합치기, 나누기, 압축, 서명, 가리기, 페이지 정리 등 50가지 넘는 PDF 도구를 담은 편집기예요(GitHub 별 95,774개, 2026년 11월 5일 기준. 오픈코어).
  • 비용: 공식 안내 기준 편집기는 개인 사용 무료예요. 대량 자동 처리(Processor)는 500회까지 무료, 이후 1회당 1센트예요.
  • 내 컴퓨터에서: 처음 켤 때 ‘Continue without signing in’을 고르면 Local Only 모드가 돼요. 이 모드에서는 도구가 내 컴퓨터에서 돌아가고 파일이 업로드되지 않아요.
  • 안 되는 것 (Local Only): OCR(글자 인식), 워드·파워포인트 변환 등 구름 표시가 붙은 도구는 Stirling Cloud나 서버가 필요해요. 이때 파일이 서버로 전송돼요.
핵심로그인 없이 쓰면(Local Only) 파일이 업로드되지 않아요. 구름 표시가 붙은 도구만 서버를 거쳐요.
STEP 03 주의
3

꼭 알아 둘 점

  • 구름 표시가 붙은 도구는 서버를 거쳐요. OCR(글자 인식), 워드·파워포인트 변환 같은 도구는 Stirling Cloud나 서버가 필요하고, 이때 파일이 서버로 전송돼요. 주민번호·계약서 같은 민감한 파일에는 쓰지 마세요.
  • 가리기(Redact)는 되돌릴 수 없어요. 덮는 게 아니라 글자 자체를 지워요. 가리기 전에 원본 파일을 꼭 하나 복사해 두세요.
  • 로그인 없이 쓰기(Local Only)에서는 구름 표시 도구를 못 써요. 대신 파일이 업로드되지 않아요.
  • 대량 자동 처리(Processor)는 무료 횟수가 있어요. 공식 안내 기준 500회까지 무료이고, 그 뒤로는 1회당 1센트예요.
  • 예전 버전 Windows 앱에서는 첫 화면에 '로그인 없이 계속하기'가 안 보였다는 보고가 있어요. 최신 버전을 받으세요.

STEP 05 처음 하는 사람용
5

설치하고 처음 켜기

설치

  • Windows: 위 '바로 받기'의 설치 파일(win-installer.exe)을 받아 실행 → 관리자 권한 허용 → 시작 메뉴에서 Stirling PDF 열기. 창이 안 뜨면 Microsoft Edge WebView2 Runtime을 설치하고 다시 열어요.
  • Mac: DMG를 받아 열고 Stirling PDF를 ‘응용 프로그램’으로 끌어다 놓기 → 열기. 막히면 시스템 설정 → 개인정보 보호 및 보안 → ‘그래도 열기’.
  • Linux: 공식 문서의 .deb / .rpm / AppImage 명령을 그대로 써요.

첫 실행: 로그인 없이 쓰기

  1. ‘Sign in to Stirling’ 화면이 나와요.
  2. Continue without signing in을 눌러요 → Local Only 모드.
  3. 나중에 바꾸려면 Settings → Connection Mode.
  4. 도구에서 ‘Backend starting up...’이 보이면 몇 초 기다려요.
STEP 06 자주 쓰는 도구
6

자주 쓰는 도구 6개

  • 합치기 (Merge): 여러 파일 하나로. 순서를 먼저 정리하고 합쳐요.
  • 나누기 (Split): 일부 페이지만 따로. 페이지 번호로 나눠요.
  • 압축 (Compress): 메일 첨부 용량 줄이기. ‘line art’ 변환 옵션은 서버가 필요해요.
  • 서명 (Sign): 서명 넣기. 원본을 남겨 두고 사본에 서명해요.
  • 가리기 (Redact): 개인정보 지우기. 다음 STEP 07 참고.
  • 페이지 정리 (Page operations): 순서 바꾸기·회전·삭제. 저장 전 미리보기로 확인해요.
도구 이름은 앱 언어 설정에 따라 다르게 보일 수 있어요.
STEP 07 개인정보 지우기
7

가리기 (Redact)

가리기는 글자를 덮는 게 아니라 지워요. 시작 전에 원본을 복사해 두세요.
  • 자동: Redaction Method → Automatic → Words to Redact에 지울 단어 입력 → Add → Redact. 패턴은 Advanced → Use Regex.
  • 글자가 하나도 안 남게: Advanced → Convert PDF to PDF-Image (대신 글자 선택·검색이 안 돼요).
  • 직접 표시: Manual → 지울 부분 선택 → Apply Redactions → Save Changes.
핵심저장한 파일을 다시 열어 지운 글자가 복사·검색되지 않는지 확인해요.
STEP 08 막히면
8

안 될 때

  • 도구에 구름 표시, 로그인 요구: Local Only에서 안 되는 도구인지 확인해요. 다른 방법을 쓰거나, 서버로 보내도 되는 파일인지 먼저 판단해요.
  • Windows에서 창이 안 뜸: WebView2 설치 여부를 확인해요. Microsoft Edge WebView2 Runtime 설치 후 다시 실행해요.
  • Mac에서 열리지 않음: 보안 차단 메시지를 확인해요. 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.
  • 가린 글자가 복사됨: 자동 패턴이 안 맞았는지 확인해요. 패턴을 고치거나 PDF-Image 변환 옵션을 써요.
STEP 09 주의
9

그 밖에 알아 둘 점
