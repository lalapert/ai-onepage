STEP 00 먼저 이것만
0

이게 뭐예요?

챗GPT를 처음 쓸 때 먼저 바꿔 두면 좋은 설정 5개예요.

다섯 개 모두 무료 계정에서 돼요. 메모리는 무료에서 일부만 되고, 프로젝트는 무료에서 프로젝트 하나에 파일 5개까지예요. 따로 깔 것은 없어요. 챗GPT 웹(chatgpt.com)이나 앱에서 설정만 바꿔요.

핵심지어낸 답은 맞춤형 지침, 옛날 정보는 검색, 반복 설명은 프로젝트, 내 취향은 메모리, 학습 사용은 데이터 제어로 막아요.
STEP 01 가장 먼저
1

맞춤형 지침: "모르면 모른다고 말해" 적어 두기

맞춤형 지침은 모든 대화에 늘 적용되는 "나만의 규칙"이에요. 무료 계정은 1,500자까지 쓸 수 있어요.

  1. 챗GPT 웹에서 왼쪽 아래 내 이름(계정 메뉴)을 눌러요.
  2. 설정을 눌러요.
  3. 개인화를 눌러요. '맞춤 설정 사용' 같은 스위치가 꺼져 있으면 켜요.
  4. 맞춤형 지침 칸에 아래 상자 안 글을 통째로 붙여 넣고 저장해요.
  5. 이렇게 보이면 성공: 새 대화에서 "너는 나한테 어떤 규칙으로 답해?"라고 물으면 아래 내용을 말해요.
맞춤형 지침에 붙여 넣기
모르는 건 지어내지 말고 모른다고 말해 줘.
사실을 말할 때는 확실한 것과 추측을 나눠서 말해 줘.
최신 정보가 필요하면 검색해서 출처를 붙여 줘.
답은 결론부터, 짧고 쉬운 말로 해 줘.
지침은 '이렇게 해 달라'는 부탁이에요. 지어낸 답이 완전히 사라진다는 뜻은 아니에요. 휴대폰 앱은 메뉴 이름이 조금 달라요(예: 'ChatGPT 맞춤 설정'). 못 찾겠으면 마지막 단계를 봐요.
STEP 02 출처 붙이기
2

검색: 출처가 붙는 답 받기

  1. 글 쓰는 칸 왼쪽의 + 버튼을 눌러요.
  2. 검색(웹 검색)을 골라요. 또는 질문 끝에 "검색해서 출처 붙여 줘"라고 써요.
  3. 이렇게 보이면 성공: 답 밑이나 문장 옆에 출처(사이트 이름, 링크)가 붙어요.
출처가 붙어도 그 내용이 맞는지는 링크를 눌러 직접 확인하는 게 안전해요.
STEP 03 반복 설명 끝
3

프로젝트: 매번 처음부터 설명하지 않기

프로젝트는 채팅, 파일, 지침을 한곳에 모아 두는 폴더예요. 그 안에서 하는 대화는 같은 자료와 지침을 계속 써요.

  1. 왼쪽 사이드바에서 새 프로젝트를 눌러요.
  2. 이름을 정하고(예: "블로그 글쓰기"), 아이콘과 색을 골라요.
  3. 자료 파일을 올려요. 무료 계정은 프로젝트 하나에 파일 5개까지예요.
  4. 프로젝트 오른쪽 위 ••• 메뉴 → 프로젝트 설정 → 지침 칸에 이 프로젝트에서만 쓸 규칙을 적어요. 예: "내 블로그 말투는 해요체, 문단은 짧게."
  5. 이렇게 보이면 성공: 그 프로젝트 안에서 새 채팅을 열고 "이 프로젝트 자료로 글 하나 써 줘"라고 하면 올린 파일을 보고 써요.
프로젝트 지침은 그 프로젝트 안에서만 적용되고, 맞춤형 지침보다 먼저 적용돼요.
STEP 04 취향 기억
4

메모리: 내 일과 취향 기억시키기

  1. 설정 → 개인화 → 메모리로 가요.
  2. 메모리를 켜요.
  3. 대화에서 "앞으로 내가 블로그 글을 쓴다는 걸 기억해 줘"처럼 말하면 기억해요.
  4. 이렇게 보이면 성공: "나에 대해 뭘 기억하고 있어?"라고 물으면 기억한 내용을 말해요.
무료 계정의 메모리는 일부만 돼요(요금 페이지에 'Limited'로 표시). 기억한 내용은 같은 메뉴에서 보고 지울 수 있어요. 민감한 정보는 말하지 않는 게 좋아요.
STEP 05 가장 중요
5

데이터 제어: 내 대화를 학습에 안 쓰게 하기

  1. 설정 → 데이터 제어로 가요. 휴대폰 앱은 사이드바 → 내 프로필 → 설정 → 데이터 제어예요.
  2. 모두를 위한 모델 개선을 꺼요.
  3. 이렇게 보이면 성공: 스위치가 꺼져 있어요. 이후 새 대화는 모델 학습에 쓰이지 않아요.
  • 꺼 놔도 답에 좋아요·싫어요(엄지)를 누르면 그 대화 전체가 학습에 쓰일 수 있어요.
  • 음성 모드는 학습 설정이 따로 있어요. Codex도 설정이 따로 있어요.
  • 꺼도 이미 있는 채팅은 지워지지 않아요. 지우고 싶으면 채팅을 따로 지워요.
  • 아예 기록을 안 남기고 싶은 대화는 임시 채팅으로 해요. 기록에 안 남고, 메모리도 안 만들고, 학습에도 안 쓰여요. 다만 안전 목적으로 최대 30일은 보관돼요.
STEP 06 막히면
6

그래도 메뉴를 못 찾겠으면

챗GPT에 아래 글을 그대로 붙여 넣어요. 챗GPT가 설정을 대신 바꿔 주지는 못하지만, 내 화면에서 어디를 누르면 되는지 알려 줘요.

챗GPT에 붙여 넣기 ([ ] 채우기)
나는 [웹 / 아이폰 앱 / 안드로이드 앱]에서 챗GPT 무료 계정을 쓰고 있어.
[맞춤형 지침 / 메모리 / 데이터 제어의 모델 개선 스위치] 메뉴를 못 찾겠어.
지금 내 화면에서 어디를 눌러야 하는지 한 단계씩 알려 줘.
