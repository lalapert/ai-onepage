왜 한도가 빨리 줄어요?

클로드 코드는 말을 할 때마다 지금까지의 대화 전체를 다시 보내서 읽어요. 그래서 대화가 길어질수록 한 마디가 비싸져요.

다시 읽는 부분은 '캐시'라는 할인으로 싸게 읽어요. 그래도 공식 문서에 따르면 하루 종일 열어 둔 대화에선 한 줄 질문도 대화 전체만큼의 사용량을 가져가요.

핵심읽을 양 자체를 줄이면 돼요. 일이 바뀌면 /clear, 새는 곳은 /usage, 긴 명령 결과는 RTK.
STEP 01 시작 전에
1

준비물

준비물왜 필요해요?어디서 받아요?
Claude 유료 플랜(Pro 이상)Claude Code는 유료 플랜에서만 돼요. /usage의 '어디서 새는지' 화면도 Pro·Max 같은 구독 요금제에서 보여요.claude.ai 설정에서 내 플랜 확인
최신 Claude Code/usage에서 f 키로 고치는 기능은 v2.1.305 이상에서 돼요.데스크톱 앱은 다시 켜면 업데이트. 터미널은 claude update
(RTK를 쓸 때만) Homebrew 또는 wingetRTK를 까는 프로그램이에요.Mac: brew.sh · Windows: 기본으로 들어 있어요
STEP 02 가장 효과가 커요
2

일이 바뀌면 /clear

  1. 하던 일이 끝나고 다른 일을 시작할 때, 글 쓰는 칸에 /rename 오늘 한 일 이름을 먼저 쳐요. 나중에 이 대화를 다시 찾기 쉬워져요.
  2. 이어서 /clear를 치고 Enter를 눌러요.
  3. 아까 대화로 돌아가고 싶으면 /resume을 치고 목록에서 골라요.
  4. 이렇게 보이면 성공: 대화창이 비고, 새 대화가 시작돼요.
공식 문서에 "/clear는 비용이 들지 않는다(costs nothing)"고 적혀 있어요. /compact(대화 요약)도 있지만, 요약하려면 긴 대화를 한 번 다 읽어야 해서 그 자체가 큰 요청이에요. 이어서 할 일이면 /compact, 새 일이면 /clear가 나아요.
STEP 03 어디서 새는지
3

/usage로 보고 f 키로 고치기

  1. 글 칸에 /usage를 치고 Enter를 눌러요.
  2. 구독 요금제(Pro·Max 등)라면 최근 사용량을 어디에 썼는지가 %로 나와요. 스킬, 서브에이전트, 플러그인, 연결해 둔 MCP 서버별로 나눠서 보여 줘요.
  3. 그 아래 추천이 한 줄씩 나와요. 공식 문서 예시: 25% Trim ~/code/api/CLAUDE.md · 49k tokens per request (CLAUDE.md 파일이 요청마다 4만 9천 토큰을 차지하니 줄이라는 뜻이에요.)
  4. 아래에 f to fix 2 of 3 같은 안내가 보이면 f 키를 눌러요. 클로드 코드가 고칠 수 있는 것을 고쳐 줘요. 바꾸기 전에 무엇을 바꾸는지 먼저 보여 줘요.
  5. 이렇게 보이면 성공: d를 누르면 최근 24시간, w를 누르면 최근 7일로 바뀌어요.
%는 '그만큼 줄어든다'는 뜻이 아니라 '사용량의 그만큼에 해당하는 항목'이라는 뜻이에요. 이 컴퓨터에서 쓴 것만 세요. 다른 기기나 claude.ai 웹에서 쓴 건 안 들어가요.
STEP 04 하나씩
4

더 줄이기

  • 안 쓰는 연결 끄기: /mcp를 쳐서 연결된 서버 목록을 보고, 지금 안 쓰는 건 꺼요. 무엇이 자리를 차지하는지는 /context로 봐요.
  • CLAUDE.md 짧게: 대화를 시작할 때마다 읽는 파일이에요. 공식 문서는 200줄 아래로 두라고 해요. 특정 작업에만 필요한 설명은 스킬로 옮겨요.
  • 쉬운 일은 생각을 덜: 간단한 일은 /effort로 생각하는 정도를 낮춰요.
  • 콕 집어 부탁하기: "코드 좋게 해 줘"보다 "auth.ts의 로그인 함수에 입력 검사 넣어 줘"처럼 말하면 파일을 덜 뒤져요.
STEP 05 명령 결과가 긴 분
5

RTK 깔기(선택)

RTK는 클로드가 터미널 명령(git, ls, grep, 테스트 등)을 실행했을 때 나오는 긴 결과를 클로드가 읽기 전에 줄여 주는 무료 오픈소스 도구예요(깃허브 별 약 8.6만, 11/15 확인).

  1. 설치. Mac(또는 Homebrew가 있는 Linux): 터미널에서 brew install rtk / Windows: winget install rtk-ai.rtk
  2. 클로드 코드에 연결: rtk init -g
  3. Claude Code를 껐다가 다시 켜요.
  4. 이렇게 보이면 성공: 터미널에서 rtk gain을 쳤을 때 '아낀 양' 화면이 나와요. "command not found"가 나오면 이름이 같은 다른 프로그램이 깔린 거예요(설명서 경고).
이 방법이 어려우면 클로드에게 붙여 넣기
https://github.com/rtk-ai/rtk
이 도구를 내 컴퓨터에 설치하고 Claude Code에 연결해 줘. 설치하면서 뭘 하는지 쉬운 말로 알려 주고, 바꾸는 설정 파일이 있으면 먼저 보여 줘.
다 되면 rtk gain이 되는지 확인해 줘.

제가 직접 잰 값11/15, rtk 0.49, 연결 없이 명령마다 직접 비교, 결과 글자 양(바이트) 기준

  • grep (긴 줄이 섞인 검색)98% ↓
    702,532바이트 → 14,726바이트
  • ls -R (폴더 목록)62% ↓
    2,196바이트 → 835바이트
  • git log (커밋 30개)36% ↓
    12,742바이트 → 8,119바이트
  • git diff (바뀐 글 비교)2% ↓
    33,874바이트 → 33,078바이트
결과가 길게 나오는 명령일수록 많이 줄고, 원래 짧거나 꼭 필요한 내용(diff)은 거의 안 줄어요.
STEP 06 주의
6

꼭 알아 둘 점

  • RTK는 Anthropic이 아닌 곳(rtk-ai)에서 공개한 도구예요. 깔고 연결하면 클로드가 실행한 명령 결과를 RTK가 먼저 받아서 줄여요. 설치 이름(Mac brew install rtk, Windows rtk-ai.rtk)과 저장소 주소(github.com/rtk-ai/rtk)가 맞는지 확인하고, 처음엔 중요한 파일이 없는 폴더에서 써 보세요.
  • RTK가 줄이는 건 '명령 결과'뿐이에요. 설명서에도 "명령 결과 90% 감소가 비용 90% 감소는 아니다"라고 적혀 있어요. 클로드 코드가 파일을 읽는 기본 도구(Read·Grep·Glob)는 기본 설정에선 그대로 지나가요.
  • RTK는 Apache 2.0(무료)이고, 한 부품(엔진)은 BUSL 라이선스지만 그냥 쓰는 건 무료예요. Apache만 쓰고 싶으면 설명서의 rtk-oss 판을 받으면 돼요. 회사용 유료 상품(RTK Pro)이 따로 있지만 개인은 필요 없어요. 사용 통계는 기본으로 꺼져 있어요.
  • 한도는 계정 전체에 걸려요. 여러 대화를 동시에 돌리면 같이 줄어요.
  • 영상 속 숫자는 제 대화 하나의 기록이에요. 저는 아주 긴 대화를 오래 쓰는 편이라 숫자가 큰 편이에요. 사람마다 대화 길이와 설정이 달라서 숫자는 달라져요.
그래도 안 되면 Claude Code에 붙여 넣기 ([ ] 채우기)
클로드 코드 한도가 너무 빨리 줄어. /usage 결과는 이래: [화면 내용 붙여 넣기]
내 컴퓨터는 [Windows / Mac]이야.
어디서 많이 쓰는지, 무엇부터 줄이면 좋은지 쉬운 말로 한 단계씩 알려 줘. 설정을 바꾸기 전에는 먼저 물어봐.
