말 없는 구간 컷편집, 클로드 코드에 맡기기

무료 FFmpeg·Whisper로 쉬는 구간 자르기, 한국어 자막, 세로 9:16, 음량까지 한 번에

릴스는 찍는 것보다 말 없는 구간을 자르는 데 시간이 더 걸려요. 클로드 코드에 영상 파일 하나와 부탁 한 줄을 주면, 쉬는 구간을 찾아 자르고, 받아쓰기로 자막을 달고, 세로로 바꾸고, 소리 크기까지 맞춰 줘요. 11월 23일에 39초 녹화본으로 직접 돌려 보니 21초 세로 릴스가 나왔어요.

39초 → 21초 11/23 직접 돌림무료 도구 FFmpeg · Whisper클로드 코드 Pro 요금제 이상
2026년 11월 23일 확인 · Claude Pro 이상(클로드 코드) · Mac 또는 Windows · 편집할 영상 파일 · FFmpeg(LGPL) · Whisper(MIT, 별 11.3만) · faster-whisper(MIT)

어떻게 되는 거예요?

클로드 코드는 내 컴퓨터에서 명령을 대신 실행해 주는 클로드예요. 영상 편집은 이미 있는 무료 프로그램 두 개가 하고, 클로드 코드는 그 프로그램에 무엇을 시킬지 정해서 차례로 돌려요.

  • FFmpeg: 소리가 작은 곳(말 없는 구간)을 찾아 자르고, 세로로 바꾸고, 소리 크기를 맞춰요
  • Whisper: 오픈AI가 공개한 받아쓰기 AI예요. 남은 말을 한국어 자막 파일(.srt)로 만들어요
  • 클로드 코드: 두 프로그램을 순서대로 돌리고, 결과 파일을 만들어 줘요
핵심원본 파일은 그대로 두고 새 파일(after.mp4)을 만들어요. 마음에 안 들면 한 줄만 바꿔서 다시 시키면 돼요.
STEP 01 · 1단계
1

준비 (처음 한 번)

  1. 클로드 코드를 깔아요. Mac은 터미널에 brew install --cask claude-code, Windows는 winget install Anthropic.ClaudeCode. 터미널이 낯설면 Claude 데스크톱 앱에서도 클로드 코드를 쓸 수 있어요.
  2. 편집할 영상을 새 폴더 하나에 넣어요(예: 바탕화면의 영상 폴더). 처음엔 원본이 아니라 복사본으로 해요.
  3. 그 폴더에서 클로드 코드를 열고, 아래 글로 프로그램이 있는지부터 확인시켜요.
클로드 코드에: 준비 확인복사해서 붙여 넣기
이 컴퓨터에 ffmpeg와 faster-whisper가 깔려 있는지 확인해 줘.
없으면 내 컴퓨터(Mac/Windows)에 맞는 설치 명령을 먼저 보여 주고, 내가 허락하면 설치해 줘.
  1. 없다고 하면 클로드 코드가 보여 준 설치 명령을 읽어 보고 허락해요.
  2. 이렇게 보이면 성공: 클로드 코드가 ffmpeg 버전과 faster-whisper 설치를 확인했다고 말하면 성공이에요.
핵심클로드 코드는 명령을 실행하기 전에 허락을 물어요. 무슨 명령인지 읽어 보고 눌러요. Mac은 brew install ffmpeg, Windows는 choco install ffmpeg나 scoop install ffmpeg로 깔 수 있어요(Whisper 공식 안내).
STEP 02 · 2단계
2

한 줄로 편집 맡기기

파일 이름만 내 것으로 바꿔서 그대로 붙여 넣어요.

클로드 코드에: 컷편집 한 줄복사해서 붙여 넣기
[raw.mp4]에서 말 없는 구간 잘라 주고, 한국어 자막 넣어서 세로 릴스로 만들어 줘. 음량은 -14 LUFS로.
말 없는 구간은 소리가 -35dB보다 작은 0.6초 이상 구간으로 보고, 자른 곳 앞뒤로 0.15초씩 남겨 줘.
자막은 faster-whisper(small)로 받아 적고, 한 줄에 14자 안으로 끊어서 아래쪽에 넣어 줘.
결과는 after.mp4로 저장하고, 몇 초에서 몇 초로 줄었는지 알려 줘.
  1. 클로드 코드가 할 일을 정리해서 보여 주면, 명령마다 허락을 눌러요.
  2. 끝나면 같은 폴더에 after.mp4와 자막 파일 subs.srt가 생겨요.
  3. 이렇게 보이면 성공: after.mp4를 열었을 때 세로 화면에 자막이 나오고, 말 없는 구간 없이 이어지면 성공이에요.
STEP 03 · 3단계
3

보고 고치기

자막 글자를 먼저 끝까지 읽어 봐요. 받아쓰기는 이름·영어 단어를 틀리게 적을 때가 있어요.

클로드 코드에: 고치기복사해서 붙여 넣기
subs.srt에서 [틀린 단어]를 [맞는 단어]로 고치고 영상을 다시 만들어 줘.
자막 글자를 [더 크게 / 화면 가운데쯤으로] 옮겨 줘.
자른 곳 앞뒤 여유를 [0.3초]로 늘려 줘.
핵심가운데를 세로로 잘라 내는 방식이라 가로 화면 양옆은 잘려요. 화면 전체가 보여야 하면 "가로 화면을 그대로 두고 위아래를 흐린 배경으로 채워 줘"라고 해요.
STEP 04 · 11월 23일에 해 본 것
4

실제 결과

이 계정 프로필 링크 페이지를 가로로 녹화한 38.9초 영상(목소리는 AI 음성, 문장 사이를 일부러 쉼)으로 위 2단계를 그대로 돌렸어요.

  • 말 없는 구간 8곳(모두 합쳐 약 18초)을 찾아 잘라 21.0초가 됐어요
  • 받아쓰기 자막 11줄. 문장은 맞게 받아 적었고, 말 앞의 '어,'는 빠졌어요. 줄은 14자에서 기계적으로 끊겨요
  • 음량 -17.0 → -14.6 LUFS, 피크 -1.4 dBFS
  • 처리 시간 약 27초(그래픽카드 없는 클라우드 컴퓨터 CPU 기준)
핵심말 사이 쉬는 곳만 잘라요. '음', '어' 같은 말 버릇은 소리가 나서 남아요.
STEP 05 · 주의
5

꼭 알아 둘 점

  • FFmpeg는 FFmpeg 프로젝트(오픈소스, LGPL), Whisper는 오픈AI(MIT), faster-whisper는 SYSTRAN(MIT)이 만들었어요. Anthropic 프로그램이 아니에요. 설치할 때 이름을 확인하고, 처음엔 중요한 파일이 없는 폴더에서 복사본으로 해 보세요.
  • 클로드 코드는 유료예요. Claude 요금제 표에서 무료(Free)는 클로드 코드가 안 되고 Pro·Max부터 돼요(11/23 확인). 편집을 시킬 때마다 사용량을 써요.
  • 배경 음악이 계속 깔린 영상은 '말 없는 구간'을 소리 크기로 찾기 어려워요. 음악 없는 원본으로 먼저 자르고 음악은 나중에 넣어요.
  • 자막은 꼭 한 번 읽고 올려요. 받아쓰기는 사람 이름·상호·영어를 틀릴 수 있어요.
  • 영상 속 편집 전후 화면·자른 곳·자막·음량 값은 11/23에 실제로 돌린 결과예요. 원본 목소리는 AI 음성이에요.
