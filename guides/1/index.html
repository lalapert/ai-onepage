STEP 00 가장 쉬운 시작
0

AI에게 그대로 맡기기

아래 문장을 통째로 복사해 평소 사용하는 Codex, Claude Code, ChatGPT, Claude 또는 Grok에 붙여 넣으세요.

AI에게 붙여 넣기
OpenFilm을 설치하고 첫 영상을 만들 수 있도록 도와줘.
나는 컴퓨터 설치가 처음이니 쉬운 말로 설명해 줘.

먼저 네가 내 컴퓨터를 직접 조작할 수 있는지,
지금 작업 위치가 내 PC인지 클라우드인지 확인해 줘.
내 PC에 접근할 수 있고 내가 허용한 작업이라면 직접 진행해 줘.
접근할 수 없다면 실행했다고 말하지 말고,
내가 따라 할 수 있게 한 번에 한 단계씩 알려 줘.

1. https://openfilm.dev 와 공식 설치 안내를 최신으로 확인해 줘.
2. 내 컴퓨터가 Windows인지 Mac인지, CPU 종류가 무엇인지 확인해 줘.
3. 이미 설치되어 있으면 기존 프로그램을 활용해 줘.
4. 없다면 내 컴퓨터에 맞는 공식 다운로드 링크를 주고,
   설치가 가능한 권한이 있으면 필요한 승인 후 설치해 줘.
   직접 설치할 수 없다면 어떤 버튼을 눌러야 하는지 알려 줘.
5. 처음부터 Node.js나 ffmpeg를 따로 설치시키지 마.
   명령줄 방식이 필요할 때만 이유를 먼저 설명해 줘.
6. OpenFilm에서 사용 가능한 Codex 또는 Claude Code를 연결하도록 도와줘.
   Grok 일반 채팅 지원과 OpenFilm 직접 연동 여부는 구별해 줘.
7. 연결이 끝나면 세로 9:16 비율의 10초 연습 영상을 만들어 줘.
   배경은 밝은 크림색, 글자는 큼직한 검정색으로 하고
   “나의 첫 영상” → “AI로 쉽게 만들었어요” → “시작이 반이에요”
   순서로 천천히 나타나게 해 줘.
   이번 연습에는 글자와 도형만 쓰고 유료 미디어 API는 호출하지 마.
8. 미리보기와 MP4 저장을 도와주고, 실제 결과가 재생되는지 확인해 줘.
9. 설치 승인, 새 결제·구독, API 키 입력 또는 보안 설정 변경이 필요하면
   먼저 무엇을 하는지와 비용·위험을 설명하고 내 승인을 받아 줘.
   비밀번호나 API 키는 채팅에 붙여 넣으라고 하지 마.
10. 오류가 나면 완료한 것과 안 된 것을 구분하고,
    오류 해결 방법과 다음에 눌러야 할 버튼을 알려 줘.
복사 버튼을 누른 뒤 AI 채팅창에 붙여 넣으세요. 일반 채팅은 내 컴퓨터에 접근할 도구와 권한이 없으면 안내만 할 수 있어요. 로컬 Codex·Claude Code도 실제 접근 권한이 있어야 직접 작업해요. AI가 완료했다고 해도 실제 설치 화면과 영상 재생까지 확인해 주세요.
STEP 01 먼저 이것만
1

처음이라면 여기서 시작하세요

OpenFilm은 AI가 만든 영상을 보고 고치는 프로그램이에요. 처음에는 데스크톱 앱으로 시작하세요. 이 방법은 Node.js, ffmpeg, 터미널을 따로 준비하지 않아도 돼요. 공식 안내

  • 01 설치하기: 내 컴퓨터에 맞는 설치 파일 받기
  • 02 AI 연결하기: Codex 또는 Claude Code 연결하기
  • 03 영상 만들기: 10초 영상 완성 후 MP4로 저장하기
컴퓨터에서 따라 해 주세요. 휴대폰에 설치하는 앱이 아니에요. Windows는 바로 다음 STEP 02부터, Mac은 STEP 03만 따라 한 뒤 STEP 04로 가세요.
핵심오늘 할 일은 3가지예요: OpenFilm 받기 → AI 연결하기 → 짧은 영상 만들기.
STEP 02 Windows
2

Windows 설치 파일 받고 열기

설치 파일 받기

  1. 여기를 눌러 OpenFilm Windows 설치 파일 받기
  2. 다운로드가 끝날 때까지 기다려요.
  3. Chrome이나 Edge에서 Ctrl + J를 눌러요. 받은 파일 목록이 열려요.
  4. 목록에서 OpenFilm-Setup-x64.exe를 눌러요.
  5. 이렇게 보이면 성공: OpenFilm 설치가 시작돼요.

파일이 안 받아지면 공식 홈페이지에서 Download for Windows를 누르세요. 그래도 안 되면 공식 배포 목록에서 가장 위 버전의 Assets → OpenFilm-Setup-x64.exe를 고르세요. Source code는 고르지 않아요.

위 파일은 Windows x64용이에요. 내 PC가 ARM인지 모르겠거나 “이 앱은 PC에서 실행할 수 없습니다”가 뜨면 STEP 10 「막혔을 때」를 보세요.

설치하고 열기

  1. 설치 창이 뜨면 내용을 읽고 설치 / Install을 눌러요. 바로 설치되는 버전도 있어요.
  2. 설치가 끝나면 OpenFilm을 열어요.
  3. 자동으로 열리지 않으면 키보드의 Windows 키를 누르고, OpenFilm을 입력한 뒤 검색 결과를 눌러요.
  4. 이렇게 보이면 성공: OpenFilm 창과 프로젝트 / Projects 화면이 보여요. 여기까지면 프로그램 설치는 끝났어요.
보안 경고가 나오면 무조건 실행하지 마세요. 경고 문구와 받은 파일의 주소를 먼저 확인해요. 회사·학교 PC의 설치 제한은 관리자에게 확인하세요.
STEP 03 Mac
3

Mac이라면 여기부터

A. 내 Mac 종류 확인하기

  1. 화면 왼쪽 위 사과 모양을 눌러요.
  2. 이 Mac에 관하여를 눌러요.
  3. 칩: Apple M1 / M2 / M3 …처럼 나오면 아래 Apple Silicon용이에요.
  4. 프로세서: Intel …이라고 나오면 아래 Intel용이에요.

B. 내 Mac에 맞는 파일 하나만 받기

  • Apple Silicon용 OpenFilm 받기 (.dmg)
  • Intel Mac용 OpenFilm 0.2.7 받기 (.zip)

Intel 링크는 확인 당시 버전이에요. 나중에 더 새 버전이 필요하면 공식 배포 목록에서 x64-mac.zip으로 끝나는 파일을 찾아요. arm64는 Apple Silicon용이에요.

C. 받은 파일 열기

  1. Finder → 다운로드 폴더를 열어요.
  2. Apple Silicon이면 OpenFilm-arm64.dmg를 두 번 눌러요. 열린 창에서 OpenFilm 앱을 Applications / 응용 프로그램 폴더로 끌어다 놓아요.
  3. Intel이면 받은 .zip을 두 번 눌러 풀고, 나온 OpenFilm 앱을 응용 프로그램 폴더로 옮겨요.
  4. Finder → 응용 프로그램 → OpenFilm을 두 번 눌러요.
  5. 이렇게 보이면 성공: OpenFilm의 프로젝트 화면이 보여요. 이제 STEP 04로 가세요.
“손상됨”, “확인되지 않은 개발자” 같은 경고가 나오면 보안 설정을 끄거나 우회 명령을 붙여 넣지 마세요. 파일 출처와 정확한 경고부터 확인해요.
STEP 04 AI 연결 전에
4

한국어로 바꾸고, 화면이 잘 뜨는지 확인하기

영어 화면이 어렵다면 Settings → General → Language → 한국어를 선택해요. 한국어 화면에서는 설정 → 일반 → 언어예요.

AI를 연결하기 전에 예제부터 열어 볼 수 있어요.

  1. 예제 / Examples를 눌러요.
  2. 마음에 드는 예제 하나를 골라요.
  3. 이것으로 시작 / Start from this를 눌러요.
  4. 영상 화면의 ▶ 재생을 눌러요.
  5. 이렇게 보이면 성공: 예제가 재생돼요.
AI 이용권을 새로 결제하기 전에 편집기가 열리는지 확인하는 단계예요. 예제를 불러올 때는 인터넷이 필요해요.
STEP 05 AI 하나만
5

영상을 만들어 줄 AI 하나 연결하기

OpenFilm 설치와 AI 연결은 별개예요. OpenFilm 자체는 무료지만, 연결하는 AI의 이용료·사용량 제한은 따로 있어요. 이미 쓰는 AI가 있다면 그것부터 연결하세요. 요금·연결 방식 공식 안내

이미 Codex나 Claude Code를 쓰고 있다면

  1. OpenFilm에서 설정 / Settings을 열어요.
  2. 에이전트 / Agents를 눌러요. 여기서 에이전트는 “영상을 만들어 줄 AI”라는 뜻이에요.
  3. Codex 또는 Claude Code 옆의 연결 / Connect를 눌러요.
  4. 로그인하고 연결 / Sign in and connect가 나오면, 열린 해당 서비스의 로그인 창에서 로그인해요.
  5. 채팅에 표시 / Show in the chat가 꺼져 있으면 켜요.
  6. 이렇게 보이면 성공: 선택한 AI 옆에 연결됨이 보여요. 실제 영상 제작 가능 여부와 남은 사용량은 첫 요청에서 확인돼요.

AI 프로그램이 아직 없다면 다음 STEP 06을 보세요.

STEP 06 AI 프로그램이 없다면
6

AI 프로그램이 아직 없을 때

핵심둘 다 설치할 필요 없어요. 이미 쓰는 계정에 맞춰 하나만 고르세요.

ChatGPT 계정으로 Codex를 쓸 분

  1. ChatGPT 데스크톱 앱 공식 다운로드를 열어요.
  2. 내 컴퓨터용 Windows 또는 macOS 다운로드를 눌러요.
  3. 받은 설치 파일을 열어 설치한 뒤 앱을 열어요.
  4. 쓰던 ChatGPT 계정으로 로그인해요.
  5. 앱의 ChatGPT 선택 메뉴에서 Codex를 선택해요. 자세한 화면은 공식 시작 안내를 참고하세요.
  6. OpenFilm으로 돌아와 설정 → 에이전트 → 연결 다시 확인을 누르고 Codex → 연결을 눌러요.
ChatGPT 웹사이트에 로그인해 둔 것만으로 OpenFilm 연결이 끝나는 것은 아니에요. 연결 구성 요소를 못 찾으면 STEP 10의 오류 안내를 확인하세요. 계정의 Codex 이용 가능 여부와 한도도 확인해야 해요.

Claude 계정으로 Claude Code를 쓸 분

  1. Claude 공식 다운로드를 열어요.
  2. Desktop에서 내 컴퓨터용 Windows 또는 macOS 다운로드를 눌러요.
  3. 받은 설치 파일을 열어 설치한 뒤 Claude 앱을 열어요.
  4. 쓰던 Claude 계정으로 로그인해요.
  5. Claude 앱의 Code 탭을 한 번 열고 초기 준비가 끝날 때까지 기다려요.
  6. OpenFilm으로 돌아와 설정 → 에이전트 → 연결 다시 확인 → Claude Code → 연결을 눌러요.
  7. 별도 로그인 창이 뜨면 그 창에서 로그인해요. Claude 앱과 연결용 Claude Code의 로그인 상태가 다를 수 있어요.
Claude Code는 지원되는 유료 플랜이 필요해요. 업그레이드 화면이 뜨면 바로 결제하지 말고 기존 플랜으로 쓸 수 있는지 먼저 확인하세요. Claude 공식 시작 안내

“연결 구성 요소 설치”가 나오면

연결 구성 요소는 OpenFilm이 해당 AI를 실행할 때 쓰는 프로그램이에요.

  1. 해당 AI 줄의 연결 구성 요소 설치를 눌러요.
  2. 표시된 공식 설치 내용과 권한을 확인해요. 설치를 원할 때만 설치 프로그램 실행을 눌러요.
  3. 설치가 끝나면 연결 다시 확인 → 연결을 눌러요.
  4. 계속 안 되면 같은 줄의 ? 도움말에서 연결 안내를 확인해요.
API 키를 만드는 방법은 첫 설치에 꼭 필요한 과정이 아니에요. 모르는 키나 결제 화면이 나오면 멈추고 확인하세요.
STEP 07 드디어
7

첫 영상 만들기

  1. 프로젝트 / Projects → 새 프로젝트 / New project를 눌러요.
  2. 제목 없음 / Untitled 같은 빈 프로젝트가 열려요. 처음에는 화면이 비어 있어도 괜찮아요.
  3. 옆의 채팅 입력칸에서 방금 연결한 Codex 또는 Claude Code를 선택해요.
  4. 아래 상자 안의 글을 전부 복사해서 그 입력칸에 붙여 넣고 전송해요.
OpenFilm 채팅 입력칸에 붙여 넣기
OpenFilm으로 연습용 10초 영상을 만들어 줘.

화면 비율: 세로 9:16.
배경: 밝은 크림색.
글자: 검정색의 큼직한 한국어 글자.
0~3초: “나의 첫 영상”
3~7초: “AI로 쉽게 만들었어요”
7~10초: “시작이 반이에요”

글자는 천천히 나타나게 해 줘.
이번에는 음악, 내레이션, AI 이미지, AI 영상 생성 없이
글자와 도형만 사용해 줘.
외부 유료 API를 호출하지 말고, 새 결제나 키 입력이 필요하면 먼저 물어봐.
완성한 영상은 OpenFilm에서 미리 볼 수 있게 해 줘.

붙여 넣는 방법: Windows는 Ctrl + V, Mac은 ⌘ + V예요.

AI가 작업하는 동안 기다려요. 파일 수정이나 명령 실행 승인을 요청하면 내용을 읽고 이번 영상 제작에 필요한 작업인지 확인해요.

이렇게 보이면 성공: 화면에 내가 요청한 글자가 나타나고, 아래 시간 막대가 약 10초 길이로 생겨요. ▶를 눌러 재생해 보세요.

이 예시는 유료 미디어 생성을 피하도록 요청하지만, 코딩 AI 자체의 구독 한도나 API 사용량은 소비될 수 있어요.
STEP 08 말로 고치기
8

마음에 들게 고치기

같은 채팅칸에 아래처럼 짧게 말해요.

같은 채팅칸에 붙여 넣기
글자를 더 크게 해 줘.
한글이 화면 밖으로 잘리지 않게 해 줘.
마지막 문구를 “오늘부터 시작!”으로 바꿔 줘.

직접 바꾸고 싶으면 영상 속 글자를 두 번 눌러 수정할 수도 있어요. 편집기 사용법

STEP 09 저장
9

완성한 영상을 MP4 파일로 저장하기

  1. 내보내기 / Export를 눌러요.
  2. 비디오 파일 / Video file을 골라요.
  3. 코덱 선택이 보이면 H.264를 골라요. 첫 연습은 나머지 기본값을 유지해도 돼요.
  4. 저장 위치를 묻는 화면이 나오면 바탕 화면처럼 찾기 쉬운 폴더를 골라요.
  5. 내보내기를 시작하고 내보내기 완료가 나올 때까지 기다려요.
  6. 완료된 항목에서 파일 탐색기에서 보기 또는 Finder에서 보기를 눌러요.
  7. 나온 .mp4 파일을 두 번 눌러 재생해요.
  8. 이렇게 보이면 성공: OpenFilm 밖에서도 내 영상 파일이 재생돼요. 이게 최종 성공이에요.
STEP 10 막히면
10

막혔을 때는 이것부터 보세요

다운로드 링크가 안 열려요

공식 홈페이지의 Download 버튼을 다시 눌러요. 또는 공식 배포 목록의 가장 위 버전에서 Assets를 펼쳐요.

  • Windows: OpenFilm-Setup-x64.exe
  • Apple Silicon Mac: OpenFilm-arm64.dmg
  • Intel Mac: x64-mac.zip으로 끝나는 파일

Source code, .yml, .blockmap 파일은 처음 설치할 때 고르는 파일이 아니에요.

Windows에서 “이 앱은 PC에서 실행할 수 없습니다”가 떠요

  1. 시작 → 설정 → 시스템 → 정보를 열어요.
  2. 시스템 종류를 확인해요.
  3. x64 기반 프로세서인지, ARM 기반 프로세서인지 적어 둬요.

이 가이드의 Windows 파일은 x64용이에요. ARM PC에서의 동작은 이 가이드에서 확인하지 않았어요. 다른 사이트의 임의 설치 파일을 받지 말고, 시스템 종류와 오류 문구를 함께 보여 주세요.

AI가 목록에 없거나 “연결 구성 요소를 찾지 못했습니다”가 떠요

  1. 설치한 AI 앱을 직접 한 번 열고 로그인해요.
  2. Claude라면 Code 탭도 열어 준비를 끝내요.
  3. OpenFilm에서 설정 → 에이전트 → 연결 다시 확인을 눌러요.
  4. 연결 구성 요소 설치 또는 ? 도움말이 보이면 해당 AI의 안내를 확인해요.
  5. 이미 설치한 폴더를 알고 있다면 설치 폴더 직접 선택…으로 지정할 수 있어요.

Windows에서는 WSL 안에만 설치된 에이전트를 OpenFilm이 사용할 수 없다는 안내가 있어요. Windows 쪽 설치가 필요해요. 공식 연결 안내 문구

AI가 결제, 사용량 초과 또는 API 키를 요구해요

  • 사용량 초과: 해당 AI의 남은 사용량과 다음 초기화 시점을 확인해요.
  • 로그인 필요: 해당 서비스의 공식 로그인 창에서 로그인한 뒤 다시 연결해요.
  • 음성·음악·이미지 생성용 키 필요: 첫 연습에서는 그 기능을 빼고 글자와 도형만으로 만들어 달라고 해요.
  • 키가 꼭 필요한 작업을 하고 싶다면 비용부터 확인해요. 키를 일반 채팅이나 문서에 붙여 넣지 마세요.

화면이 비어 있거나 영상 저장이 안 돼요

  • 새 프로젝트는 처음에 비어 있는 것이 정상이에요. STEP 07의 문장을 채팅칸에 보내야 영상이 만들어져요.
  • AI가 아직 작업 중이면 완료될 때까지 기다려요.
  • Studio가 멈췄습니다가 나오면 OpenFilm 앱을 종료했다가 다시 열어요.
  • 웹브라우저 방식으로 열었다면 Chrome 또는 Edge에서 열어요.
  • 디스크 공간 부족이 나오면 저장 공간을 확보한 뒤 다시 내보내요.
계속 안 되면 오류 문장을 그대로 복사하거나 화면을 캡처해 질문하세요. 비밀번호, API 키, 개인 파일 내용은 가려 주세요.
STEP 11 안내받기
11

AI에게 한 단계씩 안내받고 싶다면

일반 ChatGPT · Claude · Grok 채팅에 넣는 문장

일반 채팅은 내 컴퓨터에 접근할 권한과 도구가 없으면 안내만 해 줄 수 있어요. “설치 완료”라는 답변만으로 실제 설치가 된 것은 아니에요.

일반 채팅에 붙여 넣기
나는 컴퓨터 설치가 처음이야.
OpenFilm을 설치하고 첫 영상을 만들고 싶어.

먼저 내가 Windows인지 Mac인지 물어봐.
그다음 한 번에 딱 한 단계만 알려 줘.
각 단계마다 다음 4가지를 꼭 적어 줘.
1. 눌러야 할 정확한 링크
2. 화면에서 눌러야 할 버튼 이름
3. 입력하거나 붙여 넣을 문장
4. 성공했을 때 보여야 하는 화면

공식 사이트 https://openfilm.dev 와
https://github.com/openfilm/openfilm/releases 에서
내 컴퓨터용 데스크톱 설치 파일을 확인해 줘.
처음부터 Node.js나 ffmpeg를 따로 설치시키지 마.

내가 “됐어”라고 답하면 다음 단계로 넘어가.
내 컴퓨터를 직접 조작할 도구가 없으면 그 점을 말하고,
실제로 실행하지 않은 작업을 완료했다고 말하지 마.
유료 플랜, API 키, 보안 경고가 나오면 먼저 설명해 줘.
Grok 일반 채팅도 설명을 도와줄 수는 있어요. 이것이 OpenFilm의 Grok 직접 연동을 뜻하지는 않아요.
STEP 12 명령줄 방식
12

내 컴퓨터의 Codex · Claude Code로 하기

이미 내 컴퓨터에서 실행 가능한 Codex · Claude Code를 쓰는 분용 문장이에요. 컴퓨터의 파일을 읽고 명령을 실행할 수 있는 로컬 작업에서 사용하세요. 클라우드 작업에서 실행하면 내 PC가 아닌 클라우드에 설치될 수 있어요. 도구·권한·계정 상태에 따라 직접 진행할 수 있는 범위가 달라요.

로컬 Codex · Claude Code에 붙여 넣기
내 컴퓨터에서 OpenFilm으로 첫 영상을 만들도록 도와줘.

먼저 현재 실행 위치가 내 PC인지 클라우드인지 확인해 줘.
내 PC에 접근할 수 없으면 멈추고 연결 방법만 안내해 줘.

1. https://openfilm.dev 와 공식 README를 확인해 줘.
2. OpenFilm 데스크톱 앱이 이미 있으면 그 앱을 활용해 줘.
3. 없으면 운영체제와 CPU 종류에 맞는 공식 다운로드 링크를 주고,
   설치·권한 승인이 필요한 단계는 설명한 뒤 내 확인을 받아 줘.
4. 명령줄 방식을 선택해야 한다면 먼저 이유를 설명해 줘.
   Node.js 22.2 이상, ffmpeg, 필요 시 git 상태부터 확인하고,
   없는 프로그램은 공식 설치 링크와 정확한 절차를 안내해 줘.
5. 명령줄 스킬 설치가 필요하면
   npx skills add openfilm/openfilm
   환경 점검은
   npx -y openfilm@latest doctor
   를 사용하되, 실행 전 필요한 승인을 받아 줘.
6. 준비되면 글자와 도형만 있는 10초 연습 영상을 만들고 미리보기를 열어 줘.
7. 유료 미디어 API, 새 구독, 키 입력, 보안 설정 변경은 먼저 물어봐.
8. 실패하면 오류를 숨기지 말고, 완료한 단계와 막힌 단계를 구분해 줘.

명령줄 방식에만 필요한 준비물의 공식 안내예요. 위 데스크톱 앱 순서로 진행했다면 따로 받지 않아도 돼요.

  • Node.js 설치 파일: LTS를 선택해요. OpenFilm 명령줄은 22.2 이상이 필요해요.
  • FFmpeg 공식 다운로드 안내: Windows 실행 파일은 그 페이지가 안내하는 Gyan 빌드에서 제공해요.
  • Git 설치 파일: Studio의 버전 저장 기능 등에 사용해요.
  • Homebrew 공식 사이트: Mac에서 명령줄 도구를 설치할 때 쓰는 선택 방법이에요.

“터미널을 열라는데, 어디예요?”

  • Windows: Windows 키 → 명령 프롬프트 검색 → 열기.
  • Mac: ⌘ + 스페이스 → 터미널 입력 → Enter.

도구가 이미 설치됐는지만 확인하려면 아래를 한 줄씩 붙여 넣고 Enter를 눌러요.

터미널에 붙여 넣기 (Node.js 확인)
node -v

성공: v22.2.0 이상에 해당하는 버전이 나와요.

터미널에 붙여 넣기 (ffmpeg 확인)
ffmpeg -version

성공: ffmpeg version으로 시작하는 여러 줄이 나와요.

터미널에 붙여 넣기 (Git 확인)
git --version

성공: git version으로 시작하는 숫자가 나와요.

“찾을 수 없습니다 / not recognized / command not found”가 나오면 설치가 안 되었거나 새 창에서 다시 열어야 하는 상태예요. 창을 닫고 다시 열어 확인하고, 계속 같으면 오류를 AI에게 보여 주세요. 보안 정책을 끄는 명령을 임의로 실행하지 마세요.
STEP 13 비용
13

돈이 드는 부분만 다시 확인

  • OpenFilm 자체: 무료, MIT 라이선스예요. OpenFilm 계정 없이 편집·내보내기를 할 수 있어요.
  • 영상을 작성하는 AI: Codex, Claude Code 등 선택한 서비스의 플랜·API 요금·사용량 제한을 따라요.
  • AI 목소리·음악·이미지·영상 생성: ElevenLabs, OpenAI, Google, fal 등 연결한 서비스에서 별도 비용이 생길 수 있어요.
  • 필요한 경우에만 설정 → 제공업체 / Settings → Providers에서 해당 서비스의 키를 연결해요. 비밀번호나 API 키를 노션 같은 문서에 보관하지 마세요.
