STEP 00 · 먼저 이것만

이게 뭐예요?

  • 클로드한테 유튜브 팀이 하는 일을 시키는 도구 묶음이에요. 대본 쓰기, 편집할 곳 찾기, 쇼츠 고르기 같은 일을 11가지로 나눠 놨어요.
  • 도구 하나하나를 스킬이라고 불러요. 스킬은 "이 일은 이렇게 해" 하고 클로드에게 미리 써 준 설명서 파일이에요.
  • 스킬을 깔아 두면, 클로드에게 /yt-script처럼 빗금(/)으로 시작하는 말을 쳐서 불러요.
  • 스킬은 무료예요. 회원가입도, API 키(다른 서비스에 들어가는 비밀번호 같은 것)도 필요 없어요.

STEP 02 · 처음 한 번
2

Claude Code 열기

  1. claude.ai/download에서 내 컴퓨터(Windows 또는 Mac)에 맞는 앱을 받아요.
  2. 받은 파일을 열어 설치하고, 앱을 켜서 로그인해요.
  3. 앱 왼쪽 위에 있는 Code 탭을 눌러요.
  4. 폴더를 고르라는 창이 뜨면, 바탕화면에 새 폴더(예: youtube-work)를 하나 만들어서 골라요.
  5. 이렇게 보이면 성공: 화면 아래에 글을 쓰는 칸이 생겨요.

터미널(까만 창에 글자로 명령을 치는 프로그램)을 쓸 줄 안다면 이렇게 해도 돼요.

  • Windows: PowerShell을 열고 irm https://claude.ai/install.ps1 | iex를 붙여 넣은 뒤 Enter
  • Mac: 터미널을 열고 curl -fsSL https://claude.ai/install.sh | bash를 붙여 넣은 뒤 Enter
  • 다 깔리면 claude라고 치고 Enter

첫 대본 만들기

  1. 글 칸에 이렇게 써요: /yt-script 다음 영상 아이디어: [내 아이디어 한 줄]
  2. 클로드가 영상 첫 문장(훅) 후보 5개와 점수를 보여 줘요.
  3. 마음에 드는 번호를 말하면 그걸로 대본을 써 줘요.
STEP 06 · 무엇이 있나
6

스킬 11개, 한 줄씩

  • /yt-plan: 내 시간에 맞춰 한 주 계획을 짜요.
  • /yt-script: 아이디어 하나로 첫 문장 5개와 점수, 대본을 줘요.
  • /yt-package: 제목과 썸네일을 한 쌍으로 점검해요.
  • /yt-edit: 자막 파일을 보고 쉬는 곳·군더더기·다시 찍은 곳을 찾아 "몇 분 몇 초를 자르세요" 목록을 줘요.
  • /yt-shorts: 긴 영상에서 쇼츠로 쓸 구간과 새 첫 문장을 찾아요.
  • /yt-chapters: 유튜브 규칙에 맞는 챕터(목차)를 만들어요.
  • /yt-seo: 설명글, 쓸 만한 태그, 노릴 검색어 3개를 줘요.
  • /yt-viral: 내 분야에서 뜨는 영상을, 그 채널 평소보다 몇 배 잘됐는지로 줄 세워요.
  • /yt-retention: 시청 지속 데이터를 보고 사람들이 빠지는 곳과 고칠 점을 알려 줘요.
  • /yt-comment: 댓글을 나누고 내 말투로 답글을 써 줘요. 고정할 댓글도 골라 줘요.
  • /yt-audit: 채널 전체를 보고 가장 먼저 고칠 것 하나를 알려 줘요.
STEP 07 · 주의
7

꼭 알아 둘 점

  • 영상을 대신 올려 주지는 않아요. 유튜브 업로드는 내가 직접 해요.
  • /yt-edit은 자막 파일(.srt)이 있어야 해요. 영상을 직접 자르지는 않아요. 자를 곳 목록만 주고, 실제 편집은 편집 프로그램에서 해요.
  • /yt-viral은 누구나 볼 수 있는 목록만 읽어요. 로그인해서 정보를 긁어 오지 않아요.
  • 훅 점수 매기기, 쉬는 곳 찾기 같은 일은 Claude Code에서 해야 제대로 돼요. 이 기능들은 컴퓨터에서 돌아가는 작은 프로그램(파이썬)을 써요. 컴퓨터에 파이썬 3가 없으면 클로드가 깔자고 물어볼 거예요(추정).
  • Claude 앱(채팅)만 쓴다면: 스킬 하나의 SKILL.md 내용을 대화 맨 위에 붙여 넣으면 그 방식으로 움직여요. 다만 위의 작은 프로그램은 못 써서 /yt-script, /yt-edit, /yt-retention은 약해져요.
