설치 (PowerShell·터미널)

PowerShell·터미널에 붙여 넣기복사해서 붙여 넣기
git clone https://github.com/Donchitos/Claude-Code-Game-Studios.git my-game
cd my-game
claude
  • Claude Code가 켜지면 /start를 입력해요. 지금 어디쯤인지(아이디어 없음, 막연한 생각, 기획 있음, 만드는 중) 묻고 맞는 순서로 안내해요.
  • 준비물: Claude Code(Pro 이상), Git, 파이썬 3. 게임 엔진(Godot·Unity·Unreal)은 따로 설치해요. Godot은 무료예요.
STEP 01 · 어떤 도구예요?
1

한눈에 보기

  • 무엇: Claude Code를 게임 스튜디오처럼 쓰게 해 주는 템플릿이에요. 에이전트 49명, 스킬 74개, 훅 15개가 들어 있어요(README).
  • 역할: 감독, 기획, 프로그래머, 아트·사운드, QA, 제작으로 나뉘어요.
  • 엔진 전문가: Godot 4, Unity, Unreal Engine 5.
  • 가격: 템플릿은 무료(MIT, GitHub 별 3.7만, 11/9).
STEP 02 · 주의
2

꼭 알아 둘 점

  • 꼭 맨 위 폴더(my-game)에서 claude를 켜요. src 같은 하위 폴더에서 켜면 훅, 금지 규칙, 먼저 묻는 권한 모드가 빠져요(README).
  • 파이썬 3가 없으면 설정이 조용히 기본값으로 돌아가요(README).
  • 사용량이 빨리 줄어요. 에이전트를 여럿 쓰는 만큼 Claude 사용 한도를 많이 써요(추정).
  • 처음엔 기본 모드(minimal)로 시작해요. 한 장짜리 기획서부터 가요. README는 문서를 많이 쓰는 모드가 더 좋은 게임을 보장하지 않았다고 써요.
STEP 03 · 이 순서대로
3

처음 쓰는 순서

  1. /start → 지금 단계 고르기
  2. 엔진 고르기(처음이면 무료인 Godot 추천)
  3. /brainstorm으로 한 장짜리 기획서
  4. 작은 기능 하나씩 만들고 실행해서 확인
