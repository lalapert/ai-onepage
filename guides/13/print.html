올라마가 느릴 때: 원인 찾기와 빨라지는 3가지

왜 느려요? 한눈에 보기

원인 확인: 터미널에 ollama ps를 쳐요. PROCESSOR 열이 100% CPU면 모델이 그래픽카드가 아니라 일반 메모리에서 돌고 있어요. 48%/52% CPU/GPU처럼 나뉘어 있어도 느려질 수 있어요(공식 문서: 가장 빠른 건 CPU로 넘기지 않는 것).

고치는 3가지:

  1. 모델을 한 단계 작게(예: gpt-oss:20b 14GB → gemma3:4b 3.4GB → gemma3:1b 806MB)
  2. 컨텍스트 길이를 늘려 놨다면 기본값으로. 길수록 메모리를 더 써요
  3. 처음 한 번 느린 건 모델을 불러오는 시간. 기본으로 5분간 메모리에 남아서 그 안에 다시 물으면 더 빨라요
핵심ollama ps로 원인을 보고, 모델 작게 · 컨텍스트 기본값 · 미리 불러 두기 순서로 고쳐요.

1

Claude Code에 원인 찾기 맡기기

Claude Code는 Pro 이상 유료 플랜에서 쓸 수 있어요(무료 플랜 미포함, 공식 문서 2026년 11월 6일 확인). 무료 플랜이면 이 단계는 건너뛰고 아래 '원인 확인'부터 순서대로 따라 하세요.

여는 법: Claude 데스크톱 앱 왼쪽 위 Code 탭 → 아무 폴더 선택. 또는 PowerShell·터미널에서 claude 입력.

  • Claude Code 설치(Windows PowerShell): irm https://claude.ai/install.ps1 | iex
  • Claude Code 설치(Mac): curl -fsSL https://claude.ai/install.sh | bash
Claude Code에 붙여 넣기복사해서 붙여 넣기
내 컴퓨터의 Ollama가 너무 느려. 원인부터 찾고 고치는 걸 도와줘. 한 단계씩 하고, 명령을 실행하기 전에 무엇을 하는지 먼저 말해 줘.
1. 내 운영체제, 메모리(RAM), 그래픽카드 이름과 그래픽카드 메모리(VRAM)를 확인해 줘.
2. 지금 쓰는 모델로 짧은 질문을 하나 보낸 다음, ollama ps 를 실행해서 PROCESSOR 열을 보여 주고 뜻을 설명해 줘. (100% GPU / 100% CPU / CPU와 GPU 나눠 씀)
3. 모델이 그래픽카드 메모리에 다 안 들어가면, 한 단계 작은 모델을 추천해 줘. 내려받기 전에 용량을 말하고 나에게 물어봐.
4. 컨텍스트 길이를 늘려 놨는지 확인하고(앱 Settings, 또는 OLLAMA_CONTEXT_LENGTH), 늘려 놨으면 기본값으로 돌리는 방법을 알려 줘. 바꾸기 전에 나에게 물어봐.
5. 이름 끝이 :cloud 인 모델은 내 컴퓨터가 아니라 서버에서 도니까 추천하지 마.
6. 바꾼 뒤 같은 질문을 다시 보내서 전보다 나아졌는지 같이 확인해 줘.

꼭 알아 둘 점

  • 속도는 컴퓨터 사양에 따라 달라요. 그래픽카드가 약하거나 없는 노트북은 작은 모델이 답이에요.
  • 작은 모델은 더 자주 틀려요. 긴 문서나 계산은 원문과 꼭 대조하세요.
  • 컨텍스트를 줄이면 긴 문서를 한 번에 다 못 읽을 수 있어요. 문서를 나눠서 물어보세요.
  • 모델을 메모리에 오래 두면(OLLAMA_KEEP_ALIVE) 그동안 메모리를 계속 차지해요. 다른 프로그램이 느려질 수 있어요.
  • 이름 끝이 :cloud인 모델은 서버에서 돌아요. 빠를 수 있지만 파일 내용이 밖으로 나가고, 크레딧·유료 플랜이 필요해요. 회사 문서는 로컬 모델로만.
  • 환경 변수를 바꾼 뒤에는 Ollama를 껐다 켜야 적용돼요. Windows는 작업 표시줄에서 Ollama를 종료한 뒤 시작 메뉴에서 다시 열어요(공식 FAQ).

STEP 05 · 처음 하는 분

원인 확인: 그래픽카드 메모리와 ollama ps

1) 내 그래픽카드 메모리 보기

  • Windows 11: 작업 관리자(Ctrl+Shift+Esc) → 성능 → GPU → '전용 GPU 메모리'
  • Mac(애플 칩): 그래픽 메모리를 따로 쓰지 않고 통합 메모리를 같이 써요. '이 Mac에 관하여'의 메모리 숫자를 봐요.

2) ollama ps로 원인 보기

  1. Ollama에서 아무 질문이나 하나 보내요(모델이 메모리에 올라가 있어야 보여요).
  2. PowerShell(Windows)이나 터미널(Mac)을 열고 ollama ps를 입력해요.
  3. PROCESSOR 열을 봐요.
  • 100% GPU · 그래픽카드에 다 올라감 → 정상. 그래도 느리면 아래 '컨텍스트 길이 되돌리기'
  • 48%/52% CPU/GPU처럼 나뉨 · 그래픽카드에 다 안 들어감 → 아래 '모델을 한 단계 작게'
  • 100% CPU · 그래픽카드를 안 씀 → 아래 '모델을 한 단계 작게'. 그래픽카드가 없으면 작은 모델이 답
STEP 06 · 고치기 1
6

모델을 한 단계 작게

  • gpt-oss:20b (약 14GB) → gemma3:4b로 · 내려받는 용량 3.4GB
  • gemma3:4b → gemma3:1b로 · 내려받는 용량 806MB
  • 앱: 채팅창 아래 모델 선택에서 골라요. 처음 쓰는 모델은 내려받기부터 해요.
  • 터미널: ollama run gemma3:4b
STEP 07 · 고치기 2
7

컨텍스트 길이 되돌리기

  • 앱: Settings의 컨텍스트 길이 슬라이더를 낮춰요(그래픽카드 메모리 24GB 미만이면 기본이 4k).
  • 환경 변수로 바꿨다면: OLLAMA_CONTEXT_LENGTH를 지우거나 낮춘 뒤 Ollama를 다시 켜요.
STEP 08 · 고치기 3
8

첫 질문이 느릴 때

  • 처음 한 번은 모델을 불러오느라 느려요. 기본으로 5분간 메모리에 남아요.
  • 미리 불러 두기: ollama run gemma3:4b "" (빈 질문으로 모델만 올려 둬요)
  • 더 오래 두기: 환경 변수 OLLAMA_KEEP_ALIVE를 예를 들어 30m으로. 그동안 메모리를 차지해요('꼭 알아 둘 점' 참고).

안 될 때

  • 작은 모델로 바꿔도 100% CPU · 그래픽카드가 있는지, 지원되는지 → 공식 GPU 문서(docs.ollama.com/gpu)에서 내 그래픽카드 확인
